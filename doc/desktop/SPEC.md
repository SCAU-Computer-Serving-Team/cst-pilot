# 桌面端与内置 TUI 规格

`desktop` 模块定义统一软件端主程序 `cst-pilot.exe` 的功能与交互规格（`crates/cst-client` 已落地，`crates/cst-desktop` 归属阶段 9 实施，`crates/cst-tui` 归属阶段 10 实施），通过本机客户端库连接公用后台服务 `cst-server`。静态设计、Shader 与整体设计以 [桌面端画布](../../design/cst-pilot-desktop.pen) 为最高规范，动效、令牌与交互行为以 [storybook.html](../../design/storybook.html) 为最高规范，文本规范见 [DESIGN.md](../../DESIGN.md)。客户端与窗口架构见 [ARCHITECTURE.md](ARCHITECTURE.md)，阶段实施细则见 [9.desktop.md](../rust/plan/9.desktop.md)。

## 窗口基线与启动约束

| 项目 | 规格要求 |
|---|---|
| 支持环境 | Windows 10/11 x64，启用 `PerMonitorV2` 多显示器 DPI 感知 |
| 窗口尺寸 | 默认 `1280×800` 逻辑像素，常规最小 `1024×640` 逻辑像素。启动时优先按显示器提示恢复并钳制在目标屏工作区内，越界移回该屏工作区正中，显示器未命中时回退主屏居中 |
| 管理员提权 | 启动入口强制校验管理员令牌。未提权时触发 Windows UAC 提权，拒绝或失败立即退出 |
| 单实例唤醒 | 同一工具包目录仅允许运行一个 `cst-pilot.exe` 窗口实例。重复启动时唤醒已有窗口置前并直接退出新进程 |
| 前置升级恢复 | 加载业务界面前先检查 `.state/update/`。存在未完成升级事务时交由独立更新器恢复，禁止在半替换状态下启动窗口 |

## 视图结构与三端协同

1. **窗口骨架**：采用左侧 `232px` 通顶可折叠侧栏（折叠宽度 `0px`）配右侧 `40px` 顶栏与居中工作区（正文与输入框最大宽度 `816px`）。
2. **同窗双视图切换**：顶栏预留图形界面（GUI）与终端界面（TUI，阶段 10 接入）切换入口。两个视图在同一进程窗口内共享客户端连接、当前激活会话以及未发送文本和图片草稿，切换零重连。
3. **功能完整覆盖**：原生承载欢迎主页、聊天工作台与 17 个开放工具卡片（含四类常驻特殊组件）。同步提供五档过滤分支树、会话导出与原生只读预览、`Ctrl+K` 快捷命令面板、四分类设置页及 CSTOA 登录页。
4. **`WebActive` 接管锁定**：点击顶栏打开 Web 后，后台切入 `WebActive` 模式并在系统默认浏览器打开单次票据链接。桌面窗口覆盖「网页端使用中」半透明锁定遮罩，禁止发起会话写操作，持续同步配置与模型变更，点击遮罩上的「退出网页端」按钮后解除锁定。
5. **安全退出联动**：点击窗口关闭按钮（`X`）或账号菜单退出时，若存在运行中会话、待处理收件箱、导出任务或内存待发草稿，先弹出退出确认框。确认后通知 `cst-server` 暂停队列、停止任务并在 5 秒预算内定稿遥测，双进程有序退出。

## 视觉、字体与着色器规范

1. **设计变量与主题**：静态组件、Shader 与基础变量定义以 [cst-pilot-desktop.pen](../../design/cst-pilot-desktop.pen) 为更高优先级；[storybook.html](../../design/storybook.html) 严格对应画布组件与变量（不得新增画布未定义的静态组件与变量），并规范动效与交互行为。支持跟随系统、浅色、深色三档切换，与 Web 主题和 TUI 主题独立保存。
2. **随包字体与回退**：界面正文加载双端共用的 `assets/fonts/SourceHanSansCN-VF.otf`（`Source Han Sans CN VF`），代码与等宽数值加载 `JetBrainsMono-{Regular,Medium}.ttf`。罕见扩展字符与符号走 DirectWrite 系统回退链。字体文件缺失或损坏时回退系统默认无衬线与等宽字体，不阻塞启动。
3. **动态背景与浮层材质分层**：
   - 主页与登录页支持三款预编译 D3D11 天空背景着色器（`blue-sky.glsl`、`night-sky.glsl`、`blue-hour.glsl`），帧率同步显示器原生刷新率。
   - 表面与浮层采用三档材质：普通按钮与特殊工具卡片使用实底多层合成（无背景模糊），悬浮菜单与通知使用无遮罩毛玻璃（`frosted-glass.glsl` 档 2），模态弹窗与快捷面板使用带模糊遮罩的毛玻璃（档 3）。
   - 离开着色器页面、窗口最小化或失焦、覆盖 `WebActive` 锁定遮罩、开启系统减少动态偏好及执行 `sys(gpu/sensor)` 硬件采样期间自动停帧。远程桌面（`SM_REMOTESESSION`）与软光栅驱动（`Microsoft Basic Render Driver`）回退单帧静态画面，显卡特性级不足时回退静态渐变与实色表面。

## 桌面配置与安全边界

1. **局部合并配置（`agent/home/desktop.json`）**：保存主题、默认视图、侧栏折叠态与常规窗口矩形。读写采用顶层 JSON 对象局部合并，未知字段原样保留，未知枚举回退默认值而不改写磁盘。文件语法损坏时回退内存默认值并禁止覆盖原文件。
2. **共享冷却提示（`.state/ui-hints.json`）**：首次完全缺少模型凭据的 24 小时自动弹窗冷却时间戳与 Web 端共用，避免双端重复打扰。
3. **密码内存清零**：BitLocker 恢复密码与 APIKEY 输入使用固定容量清零控件，提交或关闭时逐字节清零内存并临时禁用 IME 联想记录，严禁进入剪贴板历史、日志或普通状态快照。
4. **双进程在线升级**：设置页支持手动检查版本并弹出升级确认框，展示更新说明、下载校验进度与取消入口。确认重启后移交独立更新器同时替换 `cst-pilot.exe` 与 `cst-server.exe`，并对双进程执行健康检查与失败回滚。

## 验收条件

- 重复启动唤醒已有窗口，关闭窗口联动后台服务在规定时间内退出且不残留子进程。
- 中文输入法组合输入期间候选框准确跟随光标，按 `Enter` 选词不误触发消息发送或命令提交。BitLocker 密码框聚焦期间禁用输入法，失焦后恢复。
- 多显示器不同缩放比例（100% / 125% / 150% / 200%）拖动窗口、远程桌面连接与开启／退出 Web 模式下，布局、文字清晰度与状态同步保持正常。
