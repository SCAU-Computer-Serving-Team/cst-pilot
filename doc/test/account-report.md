## 账号链路覆盖

| 场景 | 验证结果 |
|---|---|
| 身份与额度位置 | 账号页、设置和菜单只显示身份；CSTOA 上下文面板显示额度，切换其他模型服务后不沿用 CSTOA 值 |
| 布局与操作 | 1440×1000 浅色、480×900 深色；键盘打开、Esc 关闭、面板边界与长姓名通过 |
| 数据与失败 | 零额度、缺失额度、格式错误、网络失败、HTTP 401/403 与 OA 19008 均有对应结果；额度故障保留姓名，可重试 |
| 缓存 | 60 秒上限、并发请求合并、强制刷新与真实 Pi 请求结束后的更新通过 |
| 退出与换账号 | 保留其他服务凭据，清空身份与额度；第二个浏览器同步退出；未收到 Web 事件的外部退出或换账号也能丢弃迟到资料 |
