## 当前通过链路

| 范围 | 结果与边界 |
|---|---|
| TUI接管与待机 | 保存后同ID接管；文字、/new、/quit、Ctrl+N/L/D/C、Esc不发送、不改写、不退出；强制关闭宿主仍结束服务 |
| 跨端共享 | 写权双向拒绝、释放后读取最新历史、原cwd真实read及文件接口、配置重读、凭据与思考状态恢复，详见专项报告 |
| 外观 | TUI与Web独立保存，Web缺省浅色；浅深六页面与字体/布局的本机链路覆盖 |
| 错误与断线 | 持续失联条、恢复撤下；401提供重新登录入口，技术详情默认折叠；重连不自动重发 |
| 输入与工具 | 提交确认丢失时保留ID和草稿，核查接受状态，真实read只执行一次；单工具独立返回、计时冻结，刷新与重开恢复 |
| 存储 | 原子替换有界重试，永久失败不确认接受、不重发模型/工具；损坏共享配置给出文件提示，修正后恢复 |
| 并行与队列 | 两场任务独立运行、停止隔离，停止暂停队列，恢复后不重放未确认模型结果 |
| 正常退出 | 账号退出与程序退出分开；取消不影响任务；确认后暂停队列、停止任务、保存清理，再关闭服务与待机宿主 |
| 动效 | 页面进入smooth-out、退出时间反向smooth-in；500ms前向、700ms返回主入场；稳定消息外层、独立输入框、自然完成、减少动态和缺少快照降级 |
| 编辑器与导航 | 标签光标、草稿、树、六地址与前进后退的自动链路覆盖；树测试等待当前轮次完整回复 |
| 发行资源 | 官方exe静态页、模型、真实read续答、退出冒烟；字体、许可和清单校验在干净装配中执行 |

受控慢目录工具只用于执行时序，不能用作WizTree扫描性能结论。自动化与一次窗口联调只覆盖具体链路，不扩展为全部设备或操作组合通过。
