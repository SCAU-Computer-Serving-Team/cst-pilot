## 自动覆盖

| 链路 | 验证结果 |
|---|---|
| 普通权限交互启动 | 优先请求管理员 WT；原进程不初始化状态、不启动第二份 Pi |
| 已提权终端 | 管理员 WT 留在原窗口，传统控制台优先转入 WT |
| 授权取消和失败 | 不以普通权限继续，不重复请求授权 |
| WT 不可用 | 未安装或启动请求失败时使用系统控制台 |
| 参数与工作目录 | 中文、空格、引号、空参数、尾部反斜线及含方括号的路径原样传递；提权时保留卷根目录 |
| 环境 | 配置与临时状态留在工具包；清除宿主凭据和开发端点覆盖；保留 PATH 白名单 |
| 运行时 | 官方 `.bin` 与开发 Node 两条路径的参数正确；实际 Pi 版本调用通过 |
| 管道调用 | 已提权时透传输入输出与退出码；未提权时提前报错，不另开 UAC 窗口 |
| 写入失败 | 状态目录不可写时停止启动 |
| 发行冒烟 | 未提权时提前失败，不复制发行树或请求 UAC |
