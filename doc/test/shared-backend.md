# 共享后端测试

验证 TUI 与 Web 的共享状态、独立主题及运行边界。行为依据见[会话运行](../web/SPEC/session-runtime.md)和[模型配置](../web/SPEC/auth.md)。

## 环境

- 使用项目锁定 Pi 版本的完整发行副本，保留全部 packages，在 Herdr 新邻居运行真实 TUI。
- 两个项目使用同一实验 home，同名文件分别放入不同标记。模型 HTTP 与 OA 可模拟，Pi、工具、文件、会话和浏览器真实。
- 直接编辑只用于隔离配置变更或故障注入。真实凭据、用户 home、原终端与生产遥测不参与实验。
- 分别记录运行中重读、重新打开、进程重启；RPC 代表内核与存储，不能替代 TUI 菜单或完整发行扩展。

## 矩阵

| ID | 范围 | 操作与判定 |
|---|---|---|
| S01 | 接管 | TUI 落盘→/web→Web 续答；ID、标题、消息和模型一致 |
| S02 | 模型保存语义 | 直接/model 与选择器 Enter 只更新会话，Ctrl+S 保存默认；Web 选择保存默认 |
| S03 | 新会话默认 | Web 保存→新 TUI 和新 Web 读取；旧会话保持当前模型身份 |
| S04 | 范围与循环 | Web 保存→运行中 TUI 重进菜单并多次循环，无范围外模型 |
| S05 | TUI 反向保存 | TUI 范围菜单 Ctrl+S→Web 重读清单与顺序 |
| S06 | 独立主题 | 实际 TUI 选浅深或 Automatic、Web 选浅深或 system，互不覆盖 |
| S07 | 配置写入 | Web 写外观不改 Pi 文件；共享设置按字段保存，不丢其他字段 |
| S08 | 模型目录与端点 | 更新 models.json→运行中重读→下一次实际请求使用新端点 |
| S09 | 离线目录 | models-store.json 独立更新，区分启动快照与重读 |
| S10 | 双向凭据 | Web 换测试密钥→TUI 实际使用；TUI 登录→Web 状态与实际请求一致 |
| S11 | 单服务退出 | 当前服务停止调用，其他服务授权保留 |
| S12 | 思考强度 | high 接管、Web 保存 low、TUI 重开；默认与模型档位分开 |
| S13 | 历史与名称 | TUI 保存→Web 改名与续答→退出后 TUI 重开，最新消息一致 |
| S14 | 历史目录 | Web 从 A 打开 B，实际 read 和@文件补全使用 B；前端不复用 A 的清单 |
| S15 | 双向写权 | TUI 持有时 Web 拒绝，Web 持有时 TUI 拒绝；原文件不变，释放后重开 |
| S16 | 上下文 | TUI、接管与新 Web 都禁用 AGENTS，保留 APPEND_SYSTEM |
| S17 | 技能与模板 | 相同技能实际展开；明确不支持的模板和命令按规格否决 |
| S18 | 工具集合 | 实际请求开放集合对照，页面不扩权 |
| S19 | 损坏配置 | 文件类别提示、不泄露原文、修正后恢复、不使用旧凭据外发 |
| S20 | Web 局部数据 | 草稿、图片、inbox 与已落盘历史的归属分别核查 |
| S21 | 工具共享资源 | 命令目录、扫描资源与遥测独立核对；实验遥测关闭 |
| M01 | 人工动效检查 | 按当前设计核对方向、曲线、时长与延迟；自动链路只判断切换完成和交互恢复 |
| M02 | 自然播放 | 不暂停、不 seek，ready→finished 完整结束并清理状态 |

## 自动化与判定

```powershell
npm run test:web:shared-audit --prefix agent
npm run test:web:e2e --prefix agent
```

前者验证独立 Pi 进程、共享文件、真实工具和独立外观；后者验证浏览器链路。两项均纳入 CI，失败保留为失败。Herdr 测试另按真实操作记录证据；未执行、模拟外部服务与完整实机验收分别标注。
