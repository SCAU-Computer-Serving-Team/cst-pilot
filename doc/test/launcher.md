# 启动器测试

验证 `pi.cmd`、PowerShell 启动器、管理员授权、Windows Terminal（WT）承载及便携环境隔离。

## 自动测试

从仓库根目录执行：

```powershell
node --test pack/test/launcher.test.mjs
```

测试使用临时工具包和授权模拟，实际执行参数转发、运行时调用、标准输入输出与退出码。测试不请求真实 UAC 授权，不读取用户凭据。

| 范围 | 判定 |
|---|---|
| 权限分支 | 未提权时先授权，不初始化运行状态；取消或失败后停止，不重复请求 |
| 终端承载 | 根据权限与 WT 可用性选择窗口，不能重复启动 Pi |
| 参数与目录 | 中文、空格、引号、空参数、尾部反斜线及卷根目录原样传递 |
| 环境隔离 | 使用工具包配置和临时目录，清除宿主凭据与开发端点覆盖 |
| 运行时 | 开发与发行入口接收相同参数，保留退出码 |
| 管道 | 已提权时透传输入输出；未提权时直接失败，不另开授权窗口 |
| 写失败 | 状态目录不可写时停止启动 |
| 发行冒烟 | 提权前不复制发行树或启动诊断，正式产物不保存测试状态 |

## 实机与发行验证

1. 使用干净发行副本双击 `pi.cmd`，同意 UAC，核对 Pi 与诊断子进程权限。
2. 取消 UAC，确认无残留 Pi；跨账户授权时核对原工作目录和工具包配置。
3. 分别在管理员 WT、系统控制台、未安装 WT 的环境验证窗口选择与回退。
4. 验证 TUI、Web 接管、待机、正常退出与进程清理。

模拟授权只覆盖启动分支。真实弹窗、跨账户行为和完整发行副本分别记录环境与结果。记录放仓库外当天临时目录，不进入发行包。
