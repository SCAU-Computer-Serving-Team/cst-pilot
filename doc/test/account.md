# CSTOA 账号测试

验证 OAuth 与 APIKEY 的登录、本人资料、额度、动态模型和退出。业务依据见[账号规格](../auth/README.md)与[Web 登录规格](../web/SPEC/auth.md)。

## 自动测试分工

| 入口 | 职责 |
|---|---|
| `npm run test:oauth --prefix agent` | 设备授权、轮询、续期、模型目录、缓存和凭据隔离 |
| `npm run test:web --prefix agent` | 账号与额度 API、零值、查询失败、授权流程与凭据边界 |
| `npm run test:web:shared-audit --prefix agent` | TUI/Web 共用配置、跨进程恢复与单服务退出 |
| `npm run test:web:e2e --prefix agent` | 浏览器登录、资料与额度展示、模型切换、刷新和退出 |

浏览器测试先[构建 Web](web-e2e.md#执行)。OA 和模型使用本机模拟服务；Pi、存储、HTTP 和浏览器保持真实，不读取用户登录态。

## 核对项目

| 场景 | 判定 |
|---|---|
| OAuth | 取消、拒绝、过期与减速状态明确；成功保存凭据，续期按 Pi 规则执行 |
| APIKEY | 通过固定 OA 接口校验归属；额度为零可登录，错误凭据不覆盖已有凭据 |
| 本人资料与额度 | 两类凭据读取对应成员；零值有效，未知不补零，资料与额度故障分别呈现 |
| 模型目录 | 保留原始模型 ID；目录增删、成功空目录、失败缓存和重试符合规格 |
| 换凭据与退出 | 不复用其他账号目录；只清除当前服务，保留其他 Provider |
| 请求与展示 | 实际推理使用对应凭据和地址；结束后刷新额度及缓存统计，刷新不重复发送 |
| 持久化与安全 | 重启恢复配置；浏览器存储和响应不包含密钥或令牌 |

## 真实服务验证

使用获准的测试账号与隔离 home，分别验证首次设备授权、动态码、已有凭据续期和 APIKEY。跨成员、充值、真实零额度及中断消费按需单独安排。

额度余额用于核对账号展示。会话扣点按请求账单核对，方法见[遥测测试](telemetry.md)；并发请求或充值时不能用余额差归因。

真实手机操作、生产凭据和实际扣费须单独记录，模拟结果只覆盖自动链路。日志、截图和临时凭据放仓库外当天临时目录，不提交身份原文或密钥。
