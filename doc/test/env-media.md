# 移动介质验证

这里的介质指**工具包所在介质**；扫描目标卷可以不同。先执行 [公共组 B01–B35](README.md#公共测试组-b01b35)，再验证速度、文件系统标注和换盘缓存。

## 样本选择

| 介质 | 主要观察 |
|---|---|
| USB 2.0 U 盘 | 低速启动、导出和随机读取 |
| USB 3.0/3.2 U 盘、PSSD | 主流与高速基线 |
| USB 移动机械硬盘 | 随机读取耗时、桥接信息 |
| SD 卡与读卡器 | 枚举方式、文件系统和拔插 |

FAT32、exFAT、NTFS 至少各记录一种介质。不要为验证而格式化或覆盖机主介质；大文件场景使用已有文件或事先准备的测试样本。

## 差异项

| ID | 操作 | 独立核查 | 通过条件 |
|---|---|---|---|
| M01 | 冷调用 disk usage，目标 Kit | 独立计时并记录文件量 | 慢速耗时如实记录；成功、超时或降级状态明确，不静默返回部分全量 |
| M02 | 非 NTFS 卷 disk usage 与 ls | Get-Volume 核对文件系统 | usage 不误标 MFT；ls 的 index 仅表示缓存，不代表 MFT |
| M03 | NTFS 可移动卷 disk usage | 文件系统、权限和独立扫描 | 是否可走快速路径有证据，失败时说明降级 |
| M04 | 含大文件目录的 usage | 文件字节数 | ≥4 GiB 文件在支持它的文件系统中统计正确；FAT32 不具备此样本时记不适用 |
| M05 | 机械盘目标的 usage | 独立计时 | 耗时、下界和拒绝访问说明完整 |
| M06 | 扫描停止后，换插介质并复用盘符，再 ls | 对照新卷身份与文件 | 不返回旧卷缓存；身份不可得时不复用。物理操作另行安排 |
| M07 | SD 卡的 disk info | Get-Disk、读卡器和卷信息 | 总线按实际枚举返回，不强制要求 USB；文件系统准确 |
| M08 | pi.cmd 到可交互状态 | 独立计时 | 分别记录界面出现和可用时间，区分运行时启动与模型请求等待 |

写保护或只读介质另按 [PE 的 P09](env-pe.md#差异项) 检查临时目录失败路径。工具降级不代表整个 pi 环境无需写入。
