# Web 端到端验收

Web 功能以完整用户链路验收。浏览器、HTTP 服务、Pi 内核、会话和配置持久化使用真实实现；单元测试、类型检查与画布约束仅提供辅助证据。

## 验收链路

| 链路 | 操作 | 判定要求 |
|---|---|---|
| 消息与工具 | 首页输入 → 发送响应丢失 → 保留草稿 → 重试 → Pi 执行 read → 模型续答 → 刷新 | 一条用户消息、一次真实工具结果；侧栏及时归入今天；刷新恢复历史；工具与正文同级 |
| 会话管理 | 右键管理 → 多选／日期整组选中 → 取消／确认 → 成功、运行冲突或断线 | 多选不导航或下移列表；管理动作与新对话同高且无数量；确认立即隐藏并退出；失败恢复会话与原地址，保留后续导航；真实记录与附件删除，浅深与半屏可用 |
| 弹出通知 | 删除成功／失败 → 分支当前叶提示 → 断线与恢复 → 关闭 | 通知不越界、不重叠、不抢焦点；长文可换行，关闭只影响所选通知，浅深及窄屏可用 |
| 通知生命周期 | 显示 → 键盘查看详情 → Esc → 关闭 → 断线恢复 → 切换减少动态 | 详情可通过键盘打开与关闭；关闭后停止交互和播报，最终清理；恢复连接撤下断线提示，减少动态时功能可用 |
| 错误与退出 | 401／模型失败 → 展开技术详情 → 断线恢复 → 空闲／运行中退出 → 取消／确认 | 错误分类与恢复入口正确；详情默认收起且可展开；运行数与退出后果真实，取消不停止任务，确认后保存并退出；浅深与半屏无溢出，恢复不重发 |
| 分组与管理 | 普通 → 管理 → 日期组选择／清除 → 完成 → 减少动态 | 隐藏勾选框不参与键盘或辅助技术导航；管理时恢复；日期组互不串选，半选可补齐，退出清空选择；减少动态时操作可用 |
| 单工具计时与返回 | 并行 read 与受控慢目录工具 → read 先返回 → ls 继续 → 刷新 → 两工具完成 → 重开 → 下一轮复用调用 ID | 每次调用独立开始、完成和冻结计时，先完成的结果及时展示；刷新与重开恢复真实时间，跨轮不串结果 |
| 首轮完成状态 | 主页发送纯正文消息 → 延迟完成 → 第二轮 → 刷新 → 关闭并重开会话池 | 完成后真实耗时冻结并持久化，刷新与重开保持相同；每轮完成后更新缓存命中率，无需刷新；后续轮次保留手动展开选择 |
| 模型双端配置 | 网页设置搜索、启用范围与顺序 → 打开输入框模型菜单 → 选择模型 → 新 Pi 进程与模型循环 | 设置页保留搜索，输入框无搜索栏；默认模型、范围和顺序一致 |
| 设置页面 | 分类导航 → 添加服务与搜索 → 模型勾选、键盘排序、自动保存 → 写入失败回滚 → 主题 → 密钥失焦保存 → 多步骤授权 → 移除确认 → 半屏 | 深链接与历史导航可用；凭据不进入浏览器存储；Web 主题独立；连续保存复用通知；通知保持在可用主区；半屏侧栏占位且不遮挡内容，手机宽度侧栏浮层且可点击遮罩收起，主区不被挤窄 |
| Provider 持久化 | 网页填写密钥与服务地址 → 停止并重启 Web → 新 Pi 进程与网页分别发消息 | 两端使用保存的地址，登录与配置不因重启丢失 |
| 配置增删改 | 保存外部模型配置 → 新 Pi 进程读取 → 网页重新进入 | 删除项不再出现，新增与改名项按新范围展示 |
| 专属扫码 | 账号页扫码 → 取消 → 再次扫码 → OA 批准 → 返回账号页 → Web 重启 → 退出 | 取消不建立登录态；成功与退出影响同一份凭据；退出保留其他 Provider |
| CSTOA APIKEY | 账号页进入密钥登录 → 保存 → 返回账号页 → 读取模型与积分 → 侧栏退出 | 固定 OA 地址；浏览器存储不含密钥；桌面浅色与窄屏深色均可用 |
| 标记与光标 | 命令补全 → TAG → 继续输入 → 草稿刷新 → 移除 → 文件引用发送 | TAG 后可继续输入和删除正文；草稿与模型请求只包含规范标记及正文，移除无残留 |
| 原生 APIKEY | 页面进入 Pi 要求的秘密、账号 ID 等步骤 → 完成 → 返回来源页 | 多步交互完成，未绕过 Pi 保存和校验逻辑 |
| 详细内容 | 展开工具分组、工具卡、原始数据和长思考内容 | 原始数据可展开，长思考内容完整可见 |
| Markdown 渲染 | 流式正文 → 完成 → 浅深主题 → 窄屏 → 放大 | 标题、列表、引用、代码和表格正确渲染；完成时不丢失或重复正文，长内容不导致页面横向溢出 |
| 分支操作 | 消息进入树页 → 导航、不总结、总结、自定义总结、取消 | 页面与后端位置一致；分支关系与 Pi 一致；分支起始行与单链内容图标对齐；长摘要不遮挡角色或当前位置 |
| 独立主题与导航 | 核对 Web 不改 Pi 主题 → 切主题 → 主页发送 → 进入工作台 → 返回 → 侧栏进退 → 窄屏 → 减少动态 | 消息与导航保持可用，主题独立保存，侧栏可见状态与交互一致，窄屏无溢出；减少动态直接切换 |

## 视觉验收

页面切换的逐帧曲线、快照层级、圆环阴影与固定像素由设计变更时人工验收。自动测试保留导航、发送、键盘打开与关闭面板、窄屏可用性和减少动态，不以截图帧数或 CSS 原文判断功能正确。上下文面板的键盘与窄屏验收由 `account.e2e.ts` 覆盖。

## 共享后端专项

跨端共享文件、运行中重读、原会话 cwd 与单写权见[专项矩阵](shared-backend.md)。`npm run test:web:shared-audit --prefix agent` 执行独立 Pi 进程、HTTP、文件、工具、写权、上下文与独立主题验收，并纳入 CI。

真实 TUI 菜单和快捷键通过 Herdr 邻居验证，RPC 仅用于内核与存储。完整发行扩展配置必须单独验证，基本 SDK 链路通过不能替代。

## 实机与发行验证

| 场景 | 方法与判定 |
|---|---|
| TUI 接管与待机 | 实际终端执行 `/web`，核对会话、HTTP 与单写权；待机时文字、内置命令和退出快捷键不能改写会话或终止宿主 |
| 系统输入 | 使用真实 Windows 输入法、剪贴板图片和 Explorer 拖拽，核对组合输入不误发、草稿恢复与只接受一次；CDP 模拟单独标注 |
| 多会话与队列 | 多标签和两场会话同时运行，核对提交顺序、编辑排序、插话、停止隔离与暂停恢复 |
| 进程退出 | 运行中切页、刷新和关标签不取消；服务重启不自动重放；强杀后核对已接受输入与附件恢复 |
| 加载与可读性 | 多次测冷／热加载、字体就绪和模型可用时间；在实际浅深窗口自然播放，检查对比度及减少动态 |
| 目标环境 | 按[环境要求](Testlist.md)验证最低浏览器、系统版本、低端显卡和高刷屏，记录实际 CSS 视口与页面缩放 |
| 真实授权与发行 | 按[账号测试](account.md)、[启动器测试](launcher.md)验证真实授权；使用保留全部扩展的干净发行副本完成完整链路 |

## 外部依赖与隔离

- 外部模型与 OA 令牌端点使用本机 HTTP 模拟服务。模型可发出真实工具调用，工具结果由 Pi 执行产生，不注入产品内部状态代替执行。
- 单工具时序另用测试扩展提供受控等待的目录读取；Pi 派发、事件、read 与目录读取均实际执行。该用例验证并行返回时序，不代表 WizTree 整盘扫描耗时。
- 故障只注入传输边界，例如丢弃已接受消息的响应。重试后检查用户可见结果与公开会话接口，不以内部函数调用次数验收。
- Chrome 使用隔离配置。会话、凭据与设备数据放测试 home，不读取或改动开发者的实际登录态。常规动效固定 `prefers-reduced-motion: no-preference`，减少动态用例再显式切换；环境报告记录浏览器版本与系统原始偏好。点击前移入鼠标并等待控件位置稳定，覆盖悬停时控件移动的情况。
- 跨端自动测试启动独立 Pi CLI/RPC 进程，验证与 TUI 共用的内核和存储。TUI 原生按键界面、手机登录与 TOTP 仍需人工联调，RPC 验证不代替这些步骤。
- 刷新率时间推进的模拟测试为辅助证据。物理高刷屏、低端显卡与最低 Chromium 版本的实测单独记录。

## 执行

1. `npm run build --prefix src/web/frontend`。
2. `npm run test:web:e2e --prefix agent`。
3. 按场景核查日志、截图和报告。测试文件顺序执行，避免多个 Pi 与 Chrome 实例并发耗尽内存。

产物目录为 `CST_WEB_TEST_TMPDIR/<日期>/`；未设置时使用本机临时盘。消息、共享配置、会话管理和分组进退测试分别保存截图与报告；`account-profile/` 包含上下文面板，`ui-regressions/` 包含浅深模型菜单，`settings-ui/` 包含设置页浅深和半屏截图。

CI 在构建完成后执行同一入口，并上传页面截图与报告，不上传测试 home 或凭据。
