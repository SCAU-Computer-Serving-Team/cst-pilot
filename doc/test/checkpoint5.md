# Checkpoint 5 联调计划

更新：2026-10-07。本轮按用户授权修复已复现问题，并继续执行测试与联调。未执行或仅模拟的项目不标为验收完成。

## 判定与隔离

- 通过：完整用户链路符合对应 SPEC，具有环境、输入、实际结果与证据。
- 问题：预期与实际不一致；报告复现步骤、影响和证据；已授权修复项须重新执行原链路，未授权范围不扩大。
- 待查：只有代码线索或局部现象，尚不能确定为缺陷。
- 未验证：缺少设备、真实凭据或操作环境，说明限制。

使用隔离 home、浏览器配置与测试会话。外部模型和 OA 可模拟，Pi 实例、HTTP、存储、工具和页面保持真实；模拟网络与 IME 单独标注。运行中的机主服务、凭据和真实会话不纳入实验。

## 执行顺序

1. 记录源码基线和修复范围，先核对设计与失败证据，再执行回归。
2. 执行已有端到端与接口回归，复用真实链路证据。
3. 执行非headless浏览器和隔离TUI/发行副本联调，按矩阵逐项记录。
4. 单独列出缺陷、待查与未验证项，关联本机证据，未验证项目不关闭；完成的修复关联重新验收证据。

执行记录保留在当天临时目录，不提交隔离home、授权数据、录屏及浏览器profile。Checkpoint5仍以[MVP](../web/MVP.md#八实施-checkpoint)的验收标准判定。
