# 产品规格

CST Pilot 是计算机维护队（CST）的便携式现场诊断 Agent。维修队员在机主电脑上从 U 盘启动本工具，通过只读诊断工具定位软硬件故障，生成修复命令清单或执行受控的 BitLocker 操作。

早期 MVP 围绕官方 `pi.exe` 通过扩展改造构建，并引入本机 Web 界面解决部分机主系统终端乱码的问题。当前项目以 Rust 全栈重写作为长期架构，由本机后台服务统一支撑 GPUI 桌面端、窗口内置 TUI 与本机 Web 三端界面。

## 诊断与检索需求

诊断查询保持只读，不修改系统配置、服务状态或机主文件。会话固定开放 17 个白名单工具（10 个诊断与交付工具，叠加 `read`、`fffind`、`ffgrep` 与 4 个联网检索工具），禁用通用命令执行与文件写入工具。行为与接口见 [diagnostics/SPEC.md](diagnostics/SPEC.md) 与 [diagnostics/API.md](diagnostics/API.md)。

| 编号 | 需求 | 解决的问题 | 对应工具 |
|---|---|---|---|
| R1 | 进程盘点：CPU 与内存占用排行 | 定位高消耗进程 | `sys(proc)` |
| R2 | GPU 状态：每进程引擎利用率与显存，独显附温度与功耗 | 排查显卡负载与显存占用 | `sys(gpu)` |
| R3 | 传感器：可读温度、风扇、电压与频率线索 | 排查过热或降频迹象 | `sys(sensor)` |
| R4 | 整机概况：CPU、内存、页面文件、内核池、机型与开机时长 | 获取整机基础负载与硬件背景 | `sys(overview)` |
| R5 | 开机自启盘点：注册表、启动文件夹、自启服务及禁用状态 | 盘点开机自动拉起的程序 | `startup` |
| R6 | 事件日志查询：错误警告、开关机与蓝屏、崩溃、服务故障、磁盘与登录审计 | 回溯系统历史异常 | `eventlog` |
| R7 | 设备与驱动状态：异常设备、核心硬件、外设与条件查找 | 核验设备识别与驱动版本 | `driver` |
| R8 | 存储分析：目录直接子项大小浏览、卷空间、物理盘、SMART 与目录占用排行 | 分析磁盘健康度与空间占用 | `ls`、`disk` |
| R9 | 受控文件读取与联网检索：拦截本地凭据与内网地址，支持 TUN 代理环境检索技术资料 | 安全查阅机主日志与外部知识 | `read`、`fffind`、`ffgrep`、`web_search` 等 |

## 命令交付需求

常规修复由队员手动执行。模型通过 `command_plan` 保存和修订方案，队员核对后由 `runbook_deliver` 导出至工具包产物目录，同时提供 `runbook` 单步生成纯文本清单。命令分档与写法由 [runbook SKILL](../app/skills/runbook/SKILL.md) 约束。

| 编号 | 规则 |
|---|---|
| D1 | 单次调用产出一份清单，每条命令包含执行环境（`cmd` / `powershell`）、管理员要求、功能与影响说明、单行命令正文 |
| D2 | 清单写入按日期归档的产物目录，单步清单带当天唯一递增序号与标题。传入已有序号时原地替换该份清单 |
| D3 | 命令按风险分为安全（`safe`）、较安全（`low`）与需确认（`confirm`）三档，同档合并输出 |
| D4 | 仅生成 `.txt` 文件，编码固定为 UTF-8 BOM + CRLF。禁止生成 `.bat`、`.cmd`、`.ps1` 等可执行脚本 |
| D5 | 正文禁用 Markdown。文件头一行概括标题、风险档与时间，每条命令按固定四行正文加空行分隔，命令行独占一行且无前缀 |
| D6 | 每条命令写明功能与影响。不可逆或可能丢失数据的操作必须标明后果 |
| D7 | 功能相近的多条操作合并为一条单行命令 |
| D8 | 高风险且不可逆无退路的操作禁止写入任何清单 |
| D9 | 工具返回文件绝对路径与条目数，支持通过可信后端接口调用系统记事本打开已交付文件 |
| D10 | 写入失败（只读介质、空间不足、版本或序号冲突）返回结构化错误，禁止静默失败或在工具包产物目录外落盘 |

## BitLocker 执行需求

BitLocker 工具开放只读查询及受控的恢复密码解锁、完整解密能力。细则见 [diagnostics/SPEC.md](diagnostics/SPEC.md#bitlocker状态解锁与解密)。

| 编号 | 规则 |
|---|---|
| B1 | `status` 实时查询全部可枚举卷或指定盘符，保留 Windows 原始状态码与采集错误 |
| B2 | `unlock` 使用 48 位恢复密码解锁指定卷，默认走本地界面独立隐藏输入通道。AI 填参路径须在本地确认传输边界 |
| B3 | `decrypt` 默认处理全部可枚举卷或指定盘符。经本地确认固定目标清单后逐卷发起后台解密，进度通过 `status` 复查 |
| B4 | 本地输入的恢复密码不进入模型上下文、会话记录、日志或遥测。AI 填参在落盘前脱敏。异常中断后先实时复查卷状态，禁止自动重放命令 |

## 软件内升级需求

工具包支持在 U 盘或本地目录内直接联网检查并原位升级，规格见 [release/SPEC.md](release/SPEC.md#rust-软件内升级)。

| 编号 | 规则 |
|---|---|
| U1 | 启动后在后台非阻塞检查一次远端签名清单，发现新版本仅展示非打扰提示。安装操作须由用户在本地明确确认 |
| U2 | 升级包必须通过编译期官方 Ed25519 公钥对清单与 `SHA256SUMS` 的双重验签及全树文件哈希核验 |
| U3 | 严格隔离只读程序区与持久用户数据区，升级过程保留全部个人凭据、会话历史、遥测队列与已交付产物，按缺失字段合并预置配置 |
| U4 | 由独立更新器在原进程退出后按预写事务逐文件备份并替换，拉起新版执行 15 秒只读健康检查。检查失败或中断重启时自动逆序回滚 |

## 三端界面与通道需求

系统提供 GPUI 桌面端、窗口内置 TUI 与本机 Web 三个操作界面，共用同一个本机后台服务 `cst-server`。通道协调见 [server/SPEC.md](server/SPEC.md)，桌面端规格见 [desktop/SPEC.md](desktop/SPEC.md)，Web 规格见 [web/SPEC.md](web/SPEC.md)。

| 界面端 | 承载形态 | 定位与分工 |
|---|---|---|
| GPUI 桌面端 | `cst-pilot.exe` 默认图形视图 | 原生 GPU 加速桌面工作台，无需依赖机主浏览器版本即可完整操作诊断、会话管理与设置（阶段 9 已实现） |
| 内置 TUI | `cst-pilot.exe` 同窗口终端视图 | 与桌面图形视图在同一窗口内切换，共享客户端连接、激活会话与未发送草稿（阶段 10 接入） |
| 本机 Web | 系统浏览器访问 `127.0.0.1` | 由软件端触发打开（或独立 Web 模式直接拉起），支持多标签页并发、只读预览及会话长图／离线网页导出 |

跨端协同要求：

1. **通道互斥与配置同步**：默认处于软件端活跃态（`AppActive`）。开启 Web 模式（`WebActive`）后锁定软件端的会话写操作，仅在软件端确认退出 Web 后解除锁定。模型目录、默认设置与登录状态在三端间实时同步。
2. **多会话后台托管**：后台服务统一托管活跃会话与持久化输入收件箱。切换页面、刷新网页或关闭浏览器标签页均不中断后台正在运行的模型推理与诊断任务。
3. **外观独立持久化**：三端共用会话历史、模型配置与认证凭据。三端各自的外观主题、默认入口与桌面窗口尺寸位置按端独立保存，互不覆盖。

## 键盘友好交互需求

现场维修常在触控板不便、窄桌面或远程桌面环境下进行。桌面端与本机 Web 端把键盘友好交互作为正式产品特性，让队员通过方向键与少量快捷键即可完成日常排查与管理，详细方案与全应用改造范围见 [阶段 9.4 键盘友好交互设计](rust/plan/9.4.keyboard-navigation.md)。

| 编号 | 规则 |
|---|---|
| K1 | 全应用用 `↑↓←→`、`Enter` / `Space` 与 `Esc` 完成列表游走、菜单切换、折叠收展及弹窗确认。不引入单字母模式或自定义改键 |
| K2 | 全局保持「输入态」「浏览态」「浮层与弹窗态」三态闭环。按 `Ctrl+J` 直达当前主输入框，按 `Esc` 逐层退出浮层、停止生成或退出输入态回到浏览态 |
| K3 | 方向键选中态默认采用外扩 `3px` 四角折线，可在常规设置切为 `3px` 边轨游标，不改变控件内部底色。切换执行 `180ms ease-out` 滑移，鼠标移动 `>= 4px` 自动隐退，减少动态回退 `0ms` 瞬切 |
| K4 | 中文输入法组合态拥有最高优先级，组合期内方向键、`Enter`、`Tab` 与 `Esc` 全部交还输入法。Web 端避开浏览器保留快捷键 |

## 全局约束

- **支持环境**：Windows 10/11 x64。裁剪镜像、特殊介质与 Windows PE 按实际系统能力降级并明确报告错误。Web 现代版与会话导出要求本机安装 Chromium 111 及以上的 Edge 或 Chrome。
- **零宿主安装**：仅使用随包分发的原生程序与诊断组件，不在机主系统安装运行环境或内核驱动。
- **管理员启动**：桌面窗口保持当前用户普通权限运行，保障全局截图热键与资源管理器文件拖放正常响应；后台服务 `cst-server` 启动时统一校验管理员令牌并通过 Windows UAC 请求提权，取消或拒绝授权时直接退出。独立调试入口 `cst-server --standalone-web` 按当前终端权限运行并如实报告权限降级。
- **写入边界**：所有持久化配置、会话记录、运行期状态、扫描临时文件与交付产物均限制在工具包目录内部（具体目录映射见 [ARCHITECTURE.md](ARCHITECTURE.md#存储与状态归属)），不在机主系统目录遗留业务数据。
- **性能与输出**：常规原生诊断秒级返回，耗时目录扫描受时间预算与取消信号控制。所有工具输出结构化 JSON，明确区分业务数据、口径说明（`notice`）、部分降级（`degraded`）与整次错误（`isError`）。
