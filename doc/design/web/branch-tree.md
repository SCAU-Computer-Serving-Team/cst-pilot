# 分支树实现

本页定义可见树计算、几何绘制与 Pi 对照。行为见[分支树规格](../../web/SPEC/branch-tree.md)，画布和视觉规则见 [DESIGN.md](../../../DESIGN.md)。

## 数据处理

`app/tree/branch-tree.ts` 将后端 `getTree()` 数据转换为行。原始条目的 `parentId` 和 children 保持不变，过滤只生成展示副本。

1. 在原始树计算当前路径及深度优先序号，保存为 `activePath` 与 `traversalOrder`；当前路径子树优先，其余按时间。
2. 隐藏条目的可见后代接到最近可见祖先。
3. 展示保留原始遍历序号，不因隐藏当前叶或祖先而改按后代时间排序。
4. 计算每行的缩进、连接符列、祖先竖线、父行与后代区间。
5. 应用折叠集合；搜索匹配展示行，不修改原始树。

## 几何算法

| 字段 | 规则 |
|---|---|
| `indent` | 根为 0；可见分叉的子条目 +1；段首的第一代再 +1；其余持平 |
| `showConnector` | 仅真实分叉的子条目绘制 |
| `connectorColumn` | 实际缩进 −1，非负 |
| `gutters` | 段首把所在列及是否非末位传给后代 |
| `subtreeEnd` | 深度优先后代区间末尾，用于折叠 |
| 可折叠 | 有可见子条目，且为根或父条目有多个可见子条目 |

段首为根或分叉的子条目。多根以虚拟根计算，展示整体左移一级；不绘制虚拟根连接符，但各根内部的分叉正常绘制。

同一连接列可由多个分叉使用。竖线只在非末位兄弟的子树内延续，末位入口以后留空；单子链不逐条绘父子线。

## 绘制

| 项 | 取值与位置 |
|---|---|
| 行 | 高 40，左右 36 |
| 缩进槽 | 宽 32，起点 36+32c |
| 方框 | 10×10，列左缘，行内居中 |
| 竖线 | 宽 2，位于方框中心，贯穿行高 |
| 内容 | 角色图标与角色列固定，不因摘要变长而收缩或换行；摘要使用剩余宽度并省略 |
| 折叠 | 行尾控件与隐藏数量，不把方框当按钮 |
| 当前叶 | 行底色与右侧「当前位置」；标记参与行布局，摘要使用剩余宽度，长摘要不遮挡标记 |

TUI 的连接符使用 `├─`、`└─` 与 `│`，Web 使用方框与竖线；结构一致，形状不同。TUI 的活动路径标记覆盖全部祖先，当前 Web 只对叶显示当前位置。此项属于表达范围差异，几何对照不验证活动路径标记。

颜色、字体与跨页控件取 DESIGN 和工具规范，不在规格重复维护。

## 可读性边界

同列方框便于发现同级入口，竖线便于发现后续兄弟；折叠、过滤和省略后，单个标记不足以说明完整父子关系。首次使用者理解度需要独立测试，自动结构对照不作该结论。

需要进一步增强时优先考虑选中路径、关联父节点与短悬停标签，避免增加常驻说明。本轮保持既有方框与竖线形态。
