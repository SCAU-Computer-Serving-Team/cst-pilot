# 流式呈现实现

本页定义流式增量、Markdown 分段与滚动跟随。行为见[聊天工作台](../../web/SPEC/chat-workspace.md)，动效取值见 [DESIGN.md](../../../DESIGN.md#动效)。

## 轮次与过程头

按用户条目 ID 保持轮次身份。轮次有助手内容或正在运行时挂载助手组件，过程头随组件保持，工作时长与过程内容的多少分别处理。

运行结束只更新完成文案、冻结计时与折叠状态。最终正文仍在过程区外显示；纯正文、思考或工具回复采用同一状态交接，用户的手动展开选择保留。刷新后的历史时长按条目时间近似。

## 流式渲染策略

流式期间每帧只重解析增量尾部：正文按安全分割点切成「已定稿前缀 + 流式尾段」，前缀 memo 缓存（含代码高亮），尾段跳过代码高亮，消息结束后整块重渲染一次性高亮。分割规则见 `app/conversation/markdown-split.ts`（未闭合代码块、列表/表格/引用延续不切）。

播放节奏用追赶式步进（opencode desktop 方案，`app/data/stream-player.ts`）：流式期间每 24ms 步进一批，步长随积压分档（2/4/8/最多 256 字），终点吸附词边界；后端帧间隔抖动被整流为匀速流，积压大时自动加速追赶；消息结束立即放行剩余。

长会话不能一次渲染全部消息。

滚动容器铺满主区：侧栏右侧整块区域都能滚动。内容列 1120px 在主区内居中，是滚动容器的子元素。滚动条不显示。

滚动跟随：用户往上翻时停止自动跟随，出现「回到底部」按钮。回到底部后恢复跟随。按钮盒高 32、圆角 6、内边距 0 12、图标 14 与文字相隔 4；浅色白底加中性 6 描边、深色中性 2 底加中性 7 描边，文字取中性 11，悬停提到正文色。
