# 流式呈现实现

本页定义流式增量、Markdown 分段与滚动跟随。行为见[聊天工作台](../../web/SPEC/chat-workspace.md)，动效取值见 [DESIGN.md](../../../DESIGN.md#动效)。

## 轮次与过程头

按用户条目 ID 保持轮次身份。轮次有助手内容或正在运行时挂载助手组件，过程头随组件保持，工作时长与过程内容的多少分别处理。

运行结束只更新完成文案、冻结计时与折叠状态。最终正文与特殊组件保持可见，中间正文、思考和普通工具进入过程段。每段过程独立维护展开选择；纯正文、思考或工具回复都保留整轮工作时长入口。刷新后的历史时长按条目时间近似。

## 流式渲染策略

流式期间每帧只重解析增量尾部：正文按安全分割点切成「已定稿前缀 + 流式尾段」，前缀 memo 缓存（含代码高亮），尾段跳过代码高亮，消息结束后整块重渲染一次性高亮。分割规则见 `app/conversation/markdown-split.ts`（未闭合代码块、列表/表格/引用延续不切）。

定稿前缀与尾段直接渲染到同一个 `.markdown` 容器，不增加分段包装。标题、段落和列表的相邻规则跨分割点生效；字号、字距、行高与块间距在流式和完成态保持一致。数值见 [Markdown 块间距](../../../DESIGN.md#markdown-块间距)。

播放节奏由 `app/data/stream-player.ts` 控制：每 24ms 步进，字符数随积压缩放为 1–12，终点吸附词边界。消息结束后停止步进，通过最终快照展示剩余内容。

SSE 的 `write(false)` 表示帧已接收且发送缓冲超过高水位，正常大帧继续发送。客户端未发送积压超过 8 MiB 时才结束订阅，重连使用已有回放或 reset；长思考与工具结果不能因正常缓冲导致正文等待重连。

连接每 20 秒发出一次可观察的心跳，连续 45 秒没有业务事件或心跳才重建订阅。等待本地输入、慢工具与空闲会话不按业务帧静默时间判定断流；重连不重发用户操作。

长会话不能一次渲染全部消息。

滚动容器铺满主区：侧栏右侧整块区域都能滚动。内容列 1120px 在主区内居中，是滚动容器的子元素。滚动条不显示。

滚动跟随：用户往上翻时停止自动跟随，出现「回到底部」按钮。回到底部后恢复跟随。按钮盒高 32、圆角 6、内边距 0 12、图标 14 与文字相隔 4；浅色白底加中性 6 描边、深色中性 2 底加中性 7 描边，文字取中性 11，悬停提到正文色。
