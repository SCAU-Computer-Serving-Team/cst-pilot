# Web 运行实现

本页定义会话实例、共享服务与输入持久化。行为见[会话运行规格](../../web/SPEC/session-runtime.md)，SDK 装配依据见[Pi 能力](../../web/research/pi-capability.md#运行承载)。

## 共享资源

TUI 与 Web 共用 `agent/home`，Web 运行层按会话 ID 管理实例。会话池仅创建一份共享服务，各会话复用 `settingsManager` 与 `modelRuntime`，Provider 注册和配置读写保持一致。

| 资源 | 影响 | 处理 |
|---|---|---|
| `settings.json`、`auth.json` | 设置写入在文件锁内重读，按字段合并；AuthStorage 按 revision 懒加载 | Pi 提供文件协调 |
| `sessions/` | 同一记录只能有一个写入实例 | TUI 释放并销毁后 Web 才打开 |
| `outbox/` | 并发命令写入可能重复序号 | 进程级序号队列 |
| 遥测 | 每场会话累计，销毁前定稿 | `deleteSaved` 与 `close` 调用定稿，见[发送端](../../telemetry/sender/SPEC.md) |


## 模型与配置

Web 与 TUI 使用 Pi 同一套存储：`settings.json` 保存 scoped 范围与顺序，`models.json` 保存服务和模型配置，`models-store.json` 保存模型目录，`auth.json` 保存凭据。进入模型与登录页面时重读共享文件，并合并并发刷新；可用性直接取 Pi，不增加 Web 专属过滤。首页和工作台选择模型都保存到同一份默认模型设置；工作台调用 Pi `setModel({ persist: true })`，首页无需创建会话即可保存。

`web-inbox/created-times.json` 保存新会话日期。会话清单合并磁盘记录与运行实例的首条消息、名称、更新时间和执行状态；全局事件通知创建、消息、执行与树变化，侧栏合并短时通知并丢弃过期请求。

## 输入与生命周期

- HTTP 服务器、Web 会话池、占用表与跨实例协调状态放进程级容器，扩展重载不重复创建。
- 收件箱、写入回执与创建时间索引使用临时文件加原子替换；短暂EPERM/EACCES/EBUSY最多重试5次、总等待375ms。保留旧文件，不重发模型或工具；其他错误和永久不可写继续失败。
- 每个会话只有一份收件箱与调度者；接受、序号、状态和投递失败原因持久化。不得同时交给项目队列与 Pi 底层队列。
- TUI 接管时先切到独立待机会话并销毁旧写入实例，再以 SDK 打开原记录。空会话由 Web 创建；未落盘内容先拒绝接管。
- 停止暂停队列，后端重启不重放未确认结果；空会话在首个 assistant 完成前以收件箱保存身份与输入。
- 运行实例仍在写入或有待处理输入时保留占用。离开页面只注销订阅；实例停止写入并完成销毁后才释放。
- Web退出先设置停止接收操作状态，暂停全部已接受队列，再abort运行实例；停止失败不销毁仍在写入的实例。保存清理完成后响应浏览器，再调用待机宿主shutdown。退出失败保留原因并允许重试。

## 图片与草稿

- 后端已接受图片按 SHA-256 保存原字节，同一会话共享内容文件；引用限制在所属会话。删除会话清理附件目录。
- 草稿文本与图片引用按 sessionStorage 的标签页和会话命名空间隔离；IndexedDB 保存图片字节。
- localStorage 只发布 hash 引用与更新时间，Web Locks 存活锁保护其他页面。写入、引用与回收共用串行锁。
- 异步添加批次先持有引用，完成或失败再释放。退出更新引用时间；刷新宽限 60 秒。
- 缺少 Web Locks、存储不可读、引用损坏或存活页尚未发布引用时暂停删除。启动、删除与发送成功触发回收。

## 请求缓存

项目文件清单限深 6 层、最多 4000 条，缓存 30 秒；额度查询按端点和凭据缓存 60 秒。资源按内容哈希使用长缓存，页面入口重验证。
