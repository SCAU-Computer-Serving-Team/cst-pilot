# Web 运行实现

本页定义共享服务、写权、会话装配与输入持久化。行为见[会话运行规格](../../web/SPEC/session-runtime.md)，API 依据见[Pi 能力](../../web/research/pi-capability.md)。

## 状态与文件

| 文件或资源 | 归属 | 读取与写入 |
|---|---|---|
| `settings.json` | Pi：默认模型、范围、思考档位、TUI 外观 | 设置写入按字段合并；模型菜单、循环与新输入前重读 |
| `models.json`、`models-store.json` | Pi 模型与目录 | 调用 Pi ModelRuntime 刷新；后续请求使用更新的端点 |
| `auth.json` | Pi 凭据 | 使用 Pi 认证，不增加 Web 密钥存储或登录协议 |
| `web-settings.json` | Web 外观 | 独立保存 light/dark/system，缺省 light；每次读取，串行原子替换 |
| `sessions/` | Pi 会话 | 本版本实例按 home 和会话 ID 取得独占写权 |
| `web-inbox/` | Web 已接受输入、回执与附件 | 每会话一份收件箱和调度者，持久化后才确认接受 |
| 草稿 | 浏览器标签页 | sessionStorage 与 IndexedDB；未接受内容不写 Pi 历史 |
| `outbox/`、扫描资源、遥测 | 工具与扩展 | 各自维护访问协调，限制见对应设计 |

## 运行协调

`agent/home/extensions/runtime/` 负责 TUI 与 Web 的写权和重读。Pi0.85.1 没有让扩展获取当前 AgentSession 的入口，因此适配公开 `bindExtensions`，登记当前实例，再包装本实例的 `prompt`、`cycleModel` 和 `dispose`。不访问 SDK 私有字段，不修改 SDK 或官方可执行文件；重载复用进程级登记。

| 阶段 | 处理 |
|---|---|
| Web 创建或重开 | 构造 SDK 会话前取得写权；失败不改原记录 |
| TUI 绑定 | SDK 绑定时取得写权；恢复选择器先检查目标持有状态 |
| Windows 写权 | 使用规范 home 与会话 ID 的 SHA-256 命名管道；无 TCP 端口竞争，不提供读写接口 |
| 冲突 | Web 返回409 `session_owned`；TUI 明确提示并拒绝打开 |
| 释放 | 实例销毁或进程结束由内核释放，不依赖心跳超时抢占或删除残留锁文件 |
| TUI 待机 | 原始输入由Web拦截；运行协调不刷新配置、不分发模型菜单，损坏配置也不改变待机行为 |
| TUI 菜单 | 模型菜单与范围菜单提交前、模型选择快捷键触发前重读，再分发原输入 |
| 循环与输入 | 重读 Pi 设置、模型目录和范围；更新当前模型的后续端点，不修改全局默认 |

单模型范围循环会选中该模型。显式 CLI `--models` 优先，当前会话模型与新会话默认的保存动作见[模型规格](../../web/SPEC/auth.md#当前模型与默认模型)。共享配置损坏给出文件类别，不暴露配置原文；修正后下一次读取恢复。

协议只协调加载该扩展的本版本实例。外部脚本或独立 Pi 不应并发改写被持有的 JSONL。其他平台使用本机监听锁兼容路径，正式发行环境为 Windows x64。

## 会话装配

Web 进程只创建一份共享 `settingsManager` 和 `modelRuntime`，每个会话有独立资源加载器、UI 桥与工具执行记录。已保存会话以记录中的 cwd 创建服务，实际相对路径工具与文件补全均使用该目录；新会话采用 Web 启动目录。

资源加载明确禁用 AGENTS，仅加载工具包技能目录。`APPEND_SYSTEM.md` 由 Pi 加载，范围与 `pi.cmd` 一致。Web 工具集合由后端白名单控制，页面不能扩大权限。

`/web` 等待 TUI 空闲，再切到独立待机会话并销毁旧实例，之后打开原记录。未落盘对话拒绝接管，空会话由 Web 创建。分支在独立 SessionManager 上创建，源会话 ID、目录与写权保持不变；保留 SDK 的延迟落盘规则。

Web 会话池按 ID 复用同一实例。离开页面只取消订阅，服务退出前仍持有写权；持有者退出后，另一端重新打开并读取磁盘最新内容。

## 输入与退出

- 收件箱、回执、创建时间索引及 Web 外观使用临时文件和原子替换。短暂 EPERM/EACCES/EBUSY 最多5次、累计等待375ms；保留旧文件，不重发业务，永久失败继续返回错误。
- 接受序号、投递状态和失败原因落盘。输入只由一份调度者投递，停止暂停队列，重启不重放未确认模型结果。
- 单工具按助手消息时间戳与调用 ID 记录开始、结束、结果和耗时；结束即冻结，跨轮复用 ID 隔离。Pi 自定义条目不进入模型上下文，缺少真实记录的历史工具不估算时间。
- SSE 与 UI 桥共享本实例状态，全局事件同步列表、配置和凭据变化。新会话日期由 `created-times.json` 保存，过期请求不覆盖新列表。
- Web 退出停止接受输入，暂停队列、abort任务、完成保存与清理，再响应并关闭待机宿主。停止失败保留实例和原因，允许重试。
- 删除与退出在销毁前定稿遥测；遥测边界见[发送端](../../telemetry/sender/SPEC.md)。

## 图片与草稿

已接受图片按 SHA-256 保存原字节，引用限制在所属会话，删除会话清理附件。标签页草稿由 sessionStorage 隔离，IndexedDB 保存图片字节；localStorage 只发布引用与更新时间。

Web Locks 存活锁和串行引用操作保护其他页面。异步添加持有引用，退出更新时间，刷新宽限60秒；存储、锁或引用无法确认时暂停回收。

## 请求缓存

项目文件清单按 cwd 缓存30秒，限深6层、最多4000条；前端补全缓存随会话隔离。额度按端点和凭据缓存60秒，静态资源按内容 hash 缓存，页面入口重验证。
