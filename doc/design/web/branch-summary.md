# 分支总结实现

本页定义跨页待办、Pi 调用与取消接线。行为与接口见[分支总结规格](../../web/SPEC/branch-summary.md)，画布视觉取 [DESIGN.md](../../../DESIGN.md)。

## 调用边界

`session.navigateTree(targetId, { summarize, customInstructions })` 先从当前叶收集离开的分支并总结，再移动叶指针和写入总结条目。总结和导航必须同次完成，提前移动指针会改变总结范围。

树页记录目标和模式；聊天页发起总结请求。地址参数由 `app/tree/branch-summary.ts` 拼装和解析，作为可刷新的待办，不增加独立全局状态。

## 前端接线

| 位置 | 实现 |
|---|---|
| 树页 | 确认三选项；不总结直接导航，其他模式带参数回聊天 |
| 聊天页 | summarize 立即请求，custom 等待输入；成功或取消后清参数 |
| 编辑器 | 自定义标记存在时提交走总结，移除后只清待办 |
| 生成中 | 正文尾部状态与取消按钮，不提前切到目标历史 |
| 历史 | branch_summary 条目转为独立消息块 |

取消接口不排在总结持有的会话写锁后，否则无法及时取消。取消信号自身幂等，不重复发起导航；取消结果与冲突错误分别处理。

## 视觉状态

主画布包含确认、自定义、生成中与完成的浅深帧。确认态允许使用带模糊遮罩的树页快照，其余状态使用可编辑的聊天页副本。

确认卡片宽 424；选项高 42。状态与标题行高 32，图标 18，展开三角紧跟标题，时间靠右。总结原文复用工具原文块，标记复用命令标记；取值仍由 DESIGN 与规范板维护。

## 验证

`agent/home/extensions/web/test/branch-summary.e2e.ts` 覆盖选择、总结、自定义标记、移除与取消，并检查面板关闭规则。等待初始页面导航及历史加载后取计数基线，避免加载时序误判新增消息。

构建后运行浏览器测试，产物位于 `CST_WEB_TEST_TMPDIR/<日期>/branch-summary/`。模型响应在测试中延迟，用于观察生成中状态；真实网络联调单独进行。
