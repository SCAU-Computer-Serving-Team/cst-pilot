# 便携发行方案

发行继续使用官方 Pi 可执行文件、白名单装配和预构建 Web 静态资源。现场只需解压并运行 `pi.cmd`，不安装 Node、Python 或 npm，不下载开发依赖。

## 组成与取舍

| 部分 | 方案 | 理由 |
|---|---|---|
| Pi | 固定官方0.85.1可执行文件及配套资源，逐文件核验hash | 保持官方SDK与内置运行时一致，不重编译Pi |
| 第三方JS扩展 | 固定esbuild0.25.10预打包，共享Pi包保持external | 减少大量node_modules小文件，避免多个SDK实例 |
| 原生扩展 | 只保留Windows x64必需原生依赖及许可 | DLL与原生模块不强行内联 |
| Web前端 | 每次装配前从当前源码重建，再校验字体和引用资源 | 防止带入旧产物；发行不包含前端源码、测试或构建工具 |
| Web后端与项目扩展 | 保留当前精简TS扩展文件，由官方程序加载 | 现有后端单文件实验仅省14文件，无需为此增加正式构建分支 |
| 外部诊断程序 | 保留PowerShell、WizTree和LHM资源 | 遵循零宿主安装和现有工具能力边界 |
| 配置 | 生成默认浅色设置与离线模型目录，已保存选择继续生效 | 不复制开发机密钥、真实会话或运行日志 |
| 校验 | 干净树、资源/许可、SHA256SUMS、冒烟副本、ZIP解压复核 | 测试运行态与发布目录分开，禁止压缩使用过的目录 |

官方可执行文件已实测使用Bun1.3.14及Node兼容接口24.3.0。前端开发用Node只留在构建机；浏览器负责运行静态页面。

## prev0.5预览包

`prev0.5` 为现场试用版本，不等同完整MVP或正式发行验收。TUI页眉读取包内VERSION；VERSION、ZIP名称和BUILD-INFO版本一致，BUILD-INFO记录源码提交及是否包含未提交改动。

```powershell
node\node.exe pack\pack.mjs --official <官方0.85.1目录或ZIP> --out <新输出目录> --version prev0.5 --zip
```

装配拒绝覆盖非空目录，ZIP不能跳过冒烟。原始干净包保持不运行；实际TUI、浏览器、工具、待机与安全退出验证在另一个副本中完成。

## 发布前检查

1. 当前前端、后端、画布、类型、字体与发行脚本检查。
2. 独立发行副本的首次/再次启动、只读工具开放集合、模拟模型续答。
3. 完整扩展配置下，实际TUI启动Web、待机文字/命令/快捷键拦截、已保存会话接管。
4. 非headless浏览器中的真实read、401、断线恢复、并发队列、取消退出与确认退出。
5. ZIP清单与解压后逐文件hash一致；没有项目AGENTS.md、密钥、会话、缓存与实验占位配置；保留APPEND_SYSTEM.md作为运行指令。

Windows系统输入法、真实图片剪贴板与Explorer拖拽、Windows10/最低Chromium111、跨机与实际U盘、生产OA及供应商授权需另行验证。预览包允许试用，不把这些项目标为通过。
