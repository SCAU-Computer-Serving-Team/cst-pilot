# 运行时与协调规格

`runtime` 模块负责工具包的管理员授权启动、便携运行环境隔离、TUI 与 Web 的会话接管、跨进程会话单写权协调，以及双端共享配置与独立主题管理。内部实现见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 管理员启动与终端承载

`pi.cmd` 通过随包 `launcher.ps1` 校验权限并建立便携运行环境。未取得管理员权限时通过 Windows UAC 请求提权；取消、拒绝或提权失败时直接退出，禁止以普通权限继续运行。

| 启动场景 | 行为要求 |
|---|---|
| 普通权限交互启动 | 请求 UAC 授权，提权后优先在新开的管理员 Windows Terminal（`wt`）窗口运行 |
| 已提权的 Windows Terminal 会话 | 留在原窗口直接运行，不新开窗口 |
| 已提权的传统控制台 | 优先转入管理员 `wt` 窗口 |
| 未安装 `wt` 或启动 `wt` 失败 | 回退使用系统控制台，不安装终端软件或修改系统默认终端配置 |
| 取消或拒绝 UAC | 立即退出，不重复弹窗 |
| 管道调用（RPC、打印、自动冒烟） | 调用方必须已提权，保留原标准输入输出连接且不转入 `wt`；未提权时直接报错退出 |

启动器附加约束：

1. `pi.cmd` 保持纯 ASCII 字符，避免中文系统 CMD 按 ANSI/GBK 解析批处理时出错。
2. 提权跨越用户账户时，保留发起启动时的原工作目录与命令行参数，并将配置目录固定指向工具包 `agent/home`，不使用管理员个人目录。
3. 每次启动时若存在 `wiztree/WizTree3.ini`，将其重命名为 `WizTree3.ini.bad`，使 WizTree 按当前机器显示器重建窗口与 DPI 状态，同时在备份中保留可能存在的捐赠授权码。
4. 缺少随包 `pwsh/pwsh.exe`，或工具包 `.state/` 无法创建与写入时，启动报错并退出。只读、写保护和空间不足的介质需要先解决写入问题。

## TUI 与 Web 接管

TUI 负责程序启动；执行 `/web` 命令后，会话操作交由本机 Web 界面承担，TUI 留在原进程内转为待机宿主。

| 阶段 | 行为要求 |
|---|---|
| 发起 `/web` | 编辑器有未提交内容、或当前会话有未落盘的对话内容时拒绝切换并提示原因；启动服务后等待当前 TUI 任务空闲 |
| 原会话移交 | 已落盘会话先由 TUI 释放写权并切入独立待机会话，再由 Web 会话池打开原记录；空会话由 Web 直接新建 |
| TUI 待机期间 | 允许编辑文本，仅执行 `/web` 重新打开已有 Web 服务；其他文字、内置斜杠命令、模型菜单与退出快捷键不触发会话操作 |
| 宿主窗口关闭 | 操作系统直接关闭宿主终端窗口仍会结束整个 Pi 进程；Web 正常退出走账号菜单的“退出 CST Pilot” |

Web 默认监听 `127.0.0.1:52831`。端口已被占用时启动失败并提示，TUI 保持可用；Web 静态文件缺失时需先构建前端或使用完整发行包。

## 会话单写权与多会话并行

1. **单写权互斥**：每场会话同一时刻仅允许一个写入实例（TUI 或某一个进程的 Web 会话池）持有，且同一会话同时只执行一轮模型调用。
2. **跨端冲突处理**：当会话仍由 TUI 或其他进程持有时，Web 打开或修改该会话返回 HTTP `409`（`session_owned`），TUI 恢复选择器同样提示占用并拒绝打开。
3. **多标签页共享**：同一 Web 服务下的多个浏览器标签页可同时查看并向同一会话提交输入，由后端收件箱按确认顺序串行投递；任一标签页均可请求停止当前轮次。
4. **多会话隔离**：Web 支持多个会话同时在后台运行，各自的消息流、上下文、输入队列与停止操作相互独立；页面切换、刷新、断连或关闭标签页均不取消后台执行。
5. **目录继承**：打开已保存历史会话时，使用会话记录中的 `cwd` 作为工具相对路径与 `@` 文件补全的基准目录；新建会话使用启动工作目录。

## 共享配置与独立主题

| 配置项 | 归属文件 | 同步与隔离规则 |
|---|---|---|
| 默认模型、启用范围、思考强度 | `agent/home/settings.json` | TUI 与 Web 共用；打开模型菜单、循环模型或发送新输入前重读磁盘最新配置 |
| 自定义服务与模型目录 | `models.json`、`models-store.json` | TUI 与 Web 共用；修改后刷新 `ModelRuntime`，作用于后续模型请求，不打断正在进行的调用 |
| 模型服务凭据 | `agent/home/auth.json` | TUI 与 Web 共用；单服务退出仅清除该服务凭据 |
| TUI 主题 | `agent/home/settings.json` | TUI 独占，默认 `light/dark` 跟随终端浅深模式 |
| Web 主题 | `agent/home/web-settings.json` | Web 独占，支持 `light` / `dark` / `system`，缺省 `light`；与 TUI 互不覆盖 |

### 模型选择保存边界

| 操作入口 | 当前会话模型 | 新会话默认模型 |
|---|---|---|
| TUI `/model provider/id` 或选择器 `Enter` | 更新 | 保持原值 |
| TUI 模型选择器 `Ctrl+S` | 更新 | 持久化保存 |
| Web 工作台选择模型 | 更新 | 保持原值 |
| Web 主页选择模型 | 仅用于本次新建会话 | 保持原值 |
| Web 模型偏好中的默认模型 | 保持原值 | 持久化保存，与 TUI 共用 |

发行默认模型为 `deepseek/deepseek-flash`。启动与恢复保留指定的服务和模型身份，缺少凭据时等待配置；禁止自动改用其他已配置服务。显式 CLI 模型参数与手动模型循环保留。

单模型启用范围下执行模型循环会选中该唯一模型，禁止循环到范围外；显式传入 CLI `--models` 参数时以 CLI 范围为准。范围中的失效项不阻止打开模型菜单；无匹配项时沿用 Pi 的空范围语义。共享配置文件损坏时提示文件类别与修正方式，禁止在错误信息中暴露配置原文或凭据。

TUI 本地命令不做模型或凭据预检，`/web`、`/model`、`/login` 在模型不可用时仍可执行。扩展命令分发后才重读发送配置；实际模型调用的错误由 Pi 原生处理。

## 验收条件

- 未提权交互启动触发 UAC，取消授权立即退出且不创建 `.state`；提权后特殊字符参数与原 `cwd` 完整保留。
- TUI 执行 `/web` 后原会话在 Web 中无缝续答；关闭网页后可回到终端再次输入 `/web`，复用原服务与会话，不中断后台任务。待机终端仅执行 `/web`，其他命令和退出快捷键均被拦截。
- 当前模型缺少凭据、已移除或启用范围失效时，TUI 本地命令仍可执行；发送时显示 Pi 原生错误。
- TUI 与 Web 双向写权互斥生效，持有者释放后另一端可重新打开并读取最新历史。
- 在一端修改模型范围、默认模型、自定义服务或凭据后，另一端在下一次菜单打开、模型循环或输入前读取最新状态；两端切换主题互不影响。
