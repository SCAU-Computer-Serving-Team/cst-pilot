# 使用情况遥测

发送端默认启用，同一会话统计发送到 CSTOA 与 Tim 的 `timserver_1`。两个接收端使用 OA 内省核验身份，并分别存储、确认。契约版本为 0.1。

两端每日同机备份已启用；真实队员双端入库、异机备份与完整恢复仍待验收。

当前验证依据见[接入与遥测验证](../test/telemetry-report.md)。账号姓名展示与遥测上传独立：遥测身份由 OA 内省返回的学号和设备标识决定。

## 运行条件

| 条件 | 行为 |
|---|---|
| `telemetry.json` 启用且配置端点 | 采集会话统计，轮次结束保存草稿，会话结束定稿 |
| CSTOA 有效访问令牌 | 同时向 CSTOA 与 Tim 两个端点异步上传，各自确认 |
| 未登录或令牌过期 | 本地保存，后续会话开始或结束时尝试补发 |
| 网络故障或服务端暂不可用 | 保留队列，不影响诊断 |
| `enabled=false` | 不累计遥测、不写遥测记录、不上传、不探测管理员身份；修改后重启生效 |

每个端点各有最多 200 条的独立待发队列，追加时淘汰最旧记录。一端失败或停采不影响另一端，单端点队列在启动时迁移到两端。

正常退出等待定稿落盘，不等待网络响应。强杀恢复依赖已完成轮次的草稿；写盘失败和队列淘汰允许丢失。

## 采集边界

只上传会话聚合统计；逐次请求记录保留在本地。字段与隐私边界由[信息收集契约](../contract.md)定义。报错原文是可能包含敏感片段的例外，服务端按保留期清理。
