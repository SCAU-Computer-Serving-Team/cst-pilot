# 使用情况遥测

发送端默认启用，同一会话统计发送到 CSTOA 与 Tim 的 `timserver_1`。两个接收端校验安装签名或 OA 凭据，并分别存储、确认。契约版本为 0.1。

安装身份独立于 OA 登录；进程存活时每 30 秒重试，队列写入使用跨进程锁。发行实机与运维边界见[可靠性缺口](../test/telemetry-report.md#可靠性缺口)。

当前验证依据见[接入与遥测验证](../test/telemetry-report.md)。账号姓名展示与遥测上传独立：安装与环境来自会话快照，OA 内省仅提供上传时的账号和登录标识。

## 运行条件

| 条件 | 行为 |
|---|---|
| `telemetry.json` 启用且配置端点 | 采集会话统计，轮次结束保存草稿，会话结束定稿 |
| CSTOA 有效访问令牌 | 优先使用 OA 上传，学号与登录标识仅表示上传者 |
| 未登录、令牌过期或被拒 | 使用持久安装密钥签名上传，两端独立绑定公钥与确认 |
| 网络故障或服务端暂不可用 | 保留队列，启动、定稿及运行期间每 30 秒尝试补发 |
| `enabled=false` | 不累计遥测、不写遥测记录、不上传、不初始化安装身份、不探测系统；修改后重启生效 |

每个端点各有最多 200 条的独立待发队列，追加时淘汰最旧记录。一端失败或停采不影响另一端，单端点队列在启动时迁移到两端。

正常退出等待定稿落盘，不等待网络响应。强杀恢复依赖已完成轮次的草稿；写盘失败和队列淘汰允许丢失。

## 采集边界

只上传会话聚合统计；逐次请求记录保留在本地。字段与隐私边界由[信息收集契约](../contract.md)定义。报错原文是可能包含敏感片段的例外，服务端按保留期清理。
