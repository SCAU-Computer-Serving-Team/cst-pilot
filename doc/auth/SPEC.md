# 认证与模型服务规格

`auth` 模块管理 CSTOA 团队认证、内置多服务商登录与自定义兼容服务，同步提供动态模型目录、启用范围与额度点查询。内部架构见 [ARCHITECTURE.md](ARCHITECTURE.md)，接口定义见 [API.md](API.md)。

## CSTOA 登录与模型接入

队员通过手机 OAuth 设备码扫码或 CSTOA AI Console 创建的 APIKEY 使用团队模型服务。两种方式共用 `cstoa` Provider、成员身份与积分展示，同一时刻保留最近登录的一种凭据。

| 项目 | 规格要求 |
|---|---|
| OAuth 调用链 | `客户端 -> OA 代理 (/api/agent/llm/v1) -> New API 网关 -> 模型`，内部网关密钥留在服务端 |
| APIKEY 调用链 | `客户端 -> New API 网关 (/v1) -> 模型`，使用队员绑定的个人密钥 |
| 登录形态 | TUI 仅展示授权说明与完整授权链接，不自动打开机主浏览器。桌面端与 Web 将完整授权链接渲染为二维码并显示倒计时，隐藏单独的设备授权码。扫码后在手机 OA 页面完成动态验证码确认 |
| 默认有效期 | 访问令牌默认有效期 24 小时，默认不下发刷新令牌，到期后提示重新授权 |
| 记住 7 天 | 可选开启，下发 7 天刷新令牌（从首次授权起算，轮换不重置总时长）。重放旧刷新令牌时服务端吊销该设备授权 |
| 换机与临时故障 | 登录态与设备标识文件随工具包保存，不绑定电脑硬件或盘符。临时网络与刷新故障保留仍未过期的访问令牌继续使用，实际过期或服务端返回 `401/403/invalid_grant` 时要求重新登录 |
| 动态模型目录 | 登录成功后预取，后台每 30 秒及发送输入前按有效期检查，成功缓存 5 分钟，失败退避 30 秒。切换账号、切换登录方式或退出登录时立即清空旧目录 |
| 官方能力对齐 | 保留网关返回的原始模型 ID，按模型 ID 或别名复用内置官方目录中的上下文窗口、输出上限及多模态与思考能力，本地估算价格置 `0`。未知模型使用保守默认参数 |
| 积分计算 | New API quota 与额度点 `1:1`（10,000 额度点对应 ¥1），由网关在推理时扣除。APIKEY 可用积分取成员余额与密钥剩余额度的较小值 |

### CSTOA 安全边界

1. **不可信宿主假设**：机主系统与 FAT/exFAT U 盘按可能被复制设计。OA 密码、TOTP 动态码与授权确认仅在队员手机完成，支持服务端随时按设备吊销。
2. **凭据隔离**：登录凭据（`agent/home/auth.json`）与自定义服务密钥（`agent/home/models.json`）均受路径守卫封锁，禁止进入客户端本地存储、HTTP 响应、日志或发行包。
3. **业务解耦**：无报修单上门不影响登录与模型调用，模型消费统一挂队员个人额度。

## 多服务与自定义模型服务

| 范围 | 规则 |
|---|---|
| 服务列表与能力 | 按服务商实际支持的密钥或 OAuth 方式展示登录入口。设置主页置顶 `cstoa` 并列出已配置或凭据失效的服务，添加服务页支持搜索与展开全部 |
| 多服务共存 | 不同服务商凭据独立共存。退出某一服务仅清除该服务凭据，保留其他服务登录态 |
| 登录入口与返回 | 登录页固定提供 `cstoa / OAuth / APIKEY` 三个入口。CSTOA 登录成功跳转账号页，其他服务按受限本机来源路由返回。取消或关闭仅中止未完成流程，保留已有凭据 |
| 自定义服务 | 三端共用 `agent/home/models.json`，支持 `openai-completions`、`openai-responses`、`anthropic-messages`、`google-generative-ai` 四种协议。新建模型默认上下文窗口 `262,144`，最大输出取当前目录众数（空目录回退 `16,384`） |

## 模型目录热更新与启用范围

1. **离线基线下的显式更新**：运行环境保持 `PI_OFFLINE=1` 关闭通用程序检查，仅由模型目录服务显式发起刷新。设置页「更新模型」支持跳过有效期强制拉取。单个服务商刷新失败保留已有缓存，不打断正在执行的对话。
2. **损坏缓存自动重建**：`models-store.json` 解析损坏时先回退内置离线目录并在后台重拉，写回缓存时备份损坏文件并原子重建。`auth.json`、`models.json` 与 `device.json` 损坏时拒绝修改并保留原文件。
3. **默认模型与启用范围**：发行默认模型固定为 `deepseek/deepseek-flash`，缺少凭据时保留身份并提示配置。界面区分全选可用模型（默认全启用）与显式清空全部模型。模型排序顺序同步用于各端列表与循环切换。

## 验收条件

- CSTOA OAuth 扫码与 APIKEY 均可完成登录并同步动态模型目录。界面准确展示学号、姓名与额度点，切换账号或退出时立即清除旧目录与额度缓存。
- 工具包跨电脑移动后直接复用已保存凭据与 `device.json`。临时网络抖动不清空登录态，实际过期或服务端吊销时准确返回重新登录提示。
- 自定义服务增删改具备并发版本冲突保护。运行中会话所属的自定义服务禁止修改配置或删除，内置服务禁止在运行期修改服务地址，已保存密钥对外始终只返回掩码状态。
