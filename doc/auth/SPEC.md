# 认证与模型服务规格

`auth` 模块负责 CSTOA 团队认证（设备码 OAuth 与 APIKEY）、Pi 原生多服务认证、自定义兼容模型服务配置，以及模型启用范围与积分展示。内部实现见 [ARCHITECTURE.md](ARCHITECTURE.md)，接口定义见 [API.md](API.md)。

## CSTOA 登录与模型接入

队员通过手机 OAuth 设备码授权或 CSTOA AI Console 创建的 APIKEY 使用团队模型服务，两种方式共用 `cstoa` Provider、成员身份与积分展示，同一时刻保留最近登录的一种凭据。

| 项目 | 规格要求 |
|---|---|
| OAuth 调用链 | `Pi -> OA 代理 (/api/agent/llm/v1) -> New API 网关 -> 模型`；内部网关密钥留在服务端 |
| APIKEY 调用链 | `Pi -> New API 网关 (/v1) -> 模型`；使用队员绑定的个人密钥 |
| 登录形态 | TUI 显示授权网址与 6 位数字码（不自动打开机主浏览器）；Web 登录面板直接将 `verification_uri_complete` 渲染为二维码并显示倒计时 |
| 默认有效期 | 访问令牌有效期 2 小时，默认不下发刷新令牌；进入刷新窗口后提示重新授权 |
| 记住 7 天 | 可选开启，下发 7 天刷新令牌（从首次授权起算，轮换不重置总时长）；重放旧刷新令牌时服务端吊销该设备授权 |
| 动态模型目录 | 登录成功后预取；进入模型界面或发送输入前检查，成功缓存 5 分钟，失败后间隔 30 秒重试；换账号或登录方式时清除旧目录 |
| 模型标识与能力 | 保留网关返回的原始模型 ID；已知模型复用 Pi 目录能力元数据，未知模型使用保守默认参数；服务端返回空目录时移除旧模型 |
| 积分计算 | New API quota 与额度点 `1:1`（10,000 额度点对应 ¥1），由网关在推理时扣除；APIKEY 可用积分取成员余额与密钥剩余额度的较小值 |

### CSTOA 安全边界与既有决定

1. **不可信宿主假设**：机主系统与 FAT/exFAT U 盘权限均按可能被复制设计；OA 密码、TOTP（Authenticator 强制校验）与授权确认仅在队员手机完成，支持服务端随时按设备吊销。
2. **凭据与设备标识**：Pi 登录凭据保存在 `agent/home/auth.json`，自定义服务的 API key 可保存在 `agent/home/models.json`；`device.json` 仅作设备标识，不赋予权限。浏览器存储、HTTP 响应与日志严禁输出密钥或令牌。工具包具有管理员权限，文件读取与检索能力不构成系统沙箱，应避免将凭据文件交给模型读取。
3. **业务解耦**：无报修单上门不影响登录与模型调用；模型用量统一挂队员个人额度并标记“维修”用途。

## 多服务与自定义模型服务

| 范围 | 规则 |
|---|---|
| 服务列表与能力 | 读取 Pi `ModelRuntime` 的 `supportsApiKey` 与 `supportsOAuth`；设置主页置顶 `cstoa` 并列出已配置或凭据失效的服务，添加服务页支持搜索与展开全部 |
| 多服务共存 | 不同 Provider 的凭据共存；退出某一服务（含退出 CSTOA）仅清除该服务凭据，保留其他服务登录态 |
| 登录页与返回 | `/login` 固定提供 `cstoa / OAuth / APIKEY` 三个入口；CSTOA 登录成功跳转 `/account`，其他服务按合法来源返回；取消或 `Esc` 结束未完成流程并保留原凭据 |
| 自定义服务 | TUI 与 Web 共用 `agent/home/models.json`，支持 `openai-completions`、`openai-responses`、`anthropic-messages`、`google-generative-ai` 四种协议；新建模型默认上下文窗口 `256K (262144)`，最大输出取现有目录 `maxTokens` 众数（同频取小，空目录回退 `16384`） |

## 启用模型范围

1. **双端同步**：可用清单取 Pi `getAvailable()`。设置页勾选、拖拽或 `Alt + ↑/↓` 排序、全选、清空后立即保存，顺序用于模型循环；输入框模型面板仅按保存顺序展示启用范围内的模型，不设搜索栏。
2. **全选与清空语义**：全选全部可用模型或点击“恢复默认”时将 `settings.json` 的 `enabledModels` 归一为 `null`（沿用 Pi 默认全启用）；清空全部选择时在 `web-settings.json` 记录独立空范围标记（避免与 Pi 默认语义冲突）。

## 验收条件

- CSTOA OAuth 扫码与 APIKEY 均可完成登录、拉取动态模型目录、显示学号姓名与额度点，并在换账号或退出时立即隔离旧目录与资料。
- 原生 Pi OAuth（Anthropic、Codex、OpenRouter 等）本机回调、手动回贴与设备码流程正常保存凭据，弹窗拦截或跨源隔离不影响原页面更新。
- 自定义服务增删改与配置版本冲突校验生效，已有 APIKEY 在界面与接口中始终只显示“已保存”掩码。
