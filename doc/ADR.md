# 架构决策记录（ADR）

自 `2026-11-19` 起记录跨模块长期架构决策。单条正文严格控制在 150 字以内，文件清单与实施细节写入对应设计文档。已推翻或过期的决策直接删除。

## 书写规则

1. 单条含 `日期 / 状态` 元数据行，以及 `结论`、`依据`、`放弃` 三项正文。
2. 三项正文合计可见字符不超过 150 字（不含标题、`日期 / 状态`、字段标签与 Markdown 符号）。
3. 编号单调递增（`ADR-NNN`），删除旧条目不复用编号。

## ADR-001：保留 `pi-core` 上游能力，按 Feature 条件编译重型子系统

- **日期 / 状态**：`2026-11-19` · 已拍板（阶段 8.5 实施）
- **结论**：保留 `pi-core` 上游 `1.5.0` 能力。`pi-runtime` 按可选 Feature 隔离编译 QuickJS 等重型子系统，`cst-kit` 与 `cst-server` 默认关闭。
- **依据**：日常构建脱离 `rquickjs` 编译链，保留上游回归测试与较低同步成本。
- **放弃**：删除上游子系统（增加后续同步成本）。

## ADR-002：诊断核心留在单包 `cst-kit`，抽离 `cst-os` 与 `cst-updater`

- **日期 / 状态**：`2026-11-19` · 已拍板（阶段 8.5 实施）
- **结论**：诊断核心留在 `cst-kit`，按 `cst-kit -> cst-updater -> cst-os` 抽离基础库与更新器。
- **依据**：`cst-client` 禁用 `pi-*` 却共用 UAC、锁与 `server.json`。更新器脱离 `pi-*` 与 `wmi`。
- **放弃**：拆多 crate（跨包改动多）。全留单包（客户端复制锁逻辑）。

## ADR-005：桌面与 Web 共用单文件原版思源黑体可变字体，删除子集构建管线

- **日期 / 状态**：`2026-11-19` · 已拍板
- **结论**：双端共用单文件原版 `assets/fonts/SourceHanSansCN-VF.otf`，导出 HTML 跳过中文字体内嵌，删除 Python 子集管线。
- **依据**：单文件覆盖 30,926 码位与全字重，消除双端重复打包、生僻字混排与导出膨胀。
- **放弃**：GB2312 六文件子集（易漏字且维护构建管线）。

## ADR-006：阶段 11 采用单文件便携引导器与直观子目录分发

- **日期 / 状态**：`2026-11-20` · 已拍板（阶段 11 实施）
- **结论**：阶段 11 以单文件便携引导器分发，释放后根部仅留主程序与直观子目录，去除 Pi 遗留路径，保留文档功能、设计一致性与签名推送更新。
- **依据**：兼顾单文件下载、零宿主残留沙箱与原位增量升级，避免运行期释放组件触发杀软误报。
- **放弃**：系统级 MSI（跨账户目录错位且留凭据）；运行期自释放单文件（杀软拦截风险高）。

## ADR-007：桌面端使用外部 `winapp ui` 和 PowerShell 脚本调试

- **日期 / 状态**：`2026-11-20` · 已拍板（阶段 9.1 实施）
- **结论**：桌面端仅补充标准 GPUI 无障碍属性，由外部 `winapp ui` 与 `scripts/dev/desktop-{secret,record}.ps1` 完成交互调试与录制。
- **依据**：桌面端构建与启动无需 `winapp`、PowerShell 脚本或 FFmpeg，Cargo 依赖保持不变。GPUI 按需构建无障碍树。
- **放弃**：应用内嵌调试端口（增大体积与攻击面）；绑定 `gpui-agent` 库（引入代码耦合与维护成本）。

## ADR-008：桌面端保留整数像素 ClearType 渲染，对 GPUI `Div` 容器缩放采用等价动效替代

- **日期 / 状态**：`2026-11-21` · 已拍板
- **结论**：桌面端不修改 `vendor/gpui-pre` 为 `Div` 增加子树仿射缩放矩阵。图标按钮采用 GPUI 原生 `Svg` `Transformation::scale(0.92)`，复选框采用 `canvas` + `PathBuilder::stroke` 真路径描边，悬停/聚焦采用 `150ms` 颜色与阴影插值，浮层/弹窗采用位移淡入、`d^3` 阴影渐强与 `150ms` 无交互退场，列表重排采用 `FLIP` 位置补偿。
- **依据**：GPUI 文本光栅化与命中测试均建立在整数像素坐标系，强行缩放整棵 `Div` 子树会破坏 DirectWrite ClearType 清晰度并引入事件逆变换风险。
- **放弃**：在 `vendor/gpui-pre` 侵入式改造 `Div` 仿射变换与命中矩阵。

## ADR-009：工作区 `dev` 配置开启依赖二级优化与包内一级优化

- **日期 / 状态**：`2026-11-21` · 已拍板
- **结论**：根 `Cargo.toml` `[profile.dev]` 设 `opt-level = 1` 并保持 `debug = 0`，`[profile.dev.package."*"]` 设 `opt-level = 2`。
- **依据**：零优化下 GPUI 布局、DirectWrite 与毛玻璃 SDF 耗时达 `16–136ms` 触发明显掉帧；优化依赖后主屏与浮层交互降至 `2–3ms`。
- **放弃**：保持全量 `opt-level = 0`（本地开发启动即卡顿）。

## ADR-010：阶段 9.2 提前隔离目录结构并脱离 `agent/home` 与 `PI_*`

- **日期 / 状态**：`2026-11-22` · 已拍板（阶段 9.2 实施）
- **结论**：启用 `app/`、`data/`、`artifacts/`、`.state/` 四区与 `CST_PILOT_ROOT`，切断 `agent/home` 与 `PI_CODING_AGENT_DIR`；Web 静态产物按 `embed-web` 内嵌，保持双二进制，不做旧版迁移，旧 Node 入口留至阶段 11 清退。
- **依据**：消除配置与锁冲突，分离只读程序区与数据区，简化更新器白名单与 U 盘分发。
- **放弃**：自动迁移旧数据、9.2 合并单二进制或延后至阶段 11 隔离。

## ADR-011：工作区直接分支新会话，排队栏采用纯图标插话与回填编辑

- **日期 / 状态**：`2026-11-23` · 已拍板
- **结论**：对话页点击分支或执行 `/fork` 按目标回复节点直接派生新会话并跳转，删除派生选择弹窗。排队栏插话改用无框上箭头图标，编辑在校验版本删除后回填主输入框。
- **依据**：省去分支二次弹窗，统一排队行右侧图标层级，复用主输入框多行编辑与草稿保护。
- **放弃**：保留派生选择弹窗与排队行内单行输入框。

## ADR-012：桌面端拆分为 `Ctrl+P` 与 `Ctrl+O` 双快捷面板，移除分支树与侧栏快捷键

- **日期 / 状态**：`2026-11-23` · 已拍板
- **结论**：桌面端移除 `Ctrl+K`、侧栏搜索框提示与分支树快捷键，改为 `Ctrl+P`（命令与导航）和 `Ctrl+O`（会话与近期导出），导出项以资源管理器选中打开。
- **依据**：分离动作执行与目标打开意图，消除分支树键位冲突，降低单面板混排噪声。
- **放弃**：单面板 `Ctrl+K` 混排；分支树继续占用 `Ctrl+O`。

## ADR-013：Web 画布合并单文件并与桌面端同源设计规范

- **日期 / 状态**：`2026-11-24` · 已拍板
- **结论**：工具画布并入 `cst-pilot-web.pen`，复用桌面 50 变量、`mode` 轴、`LKIQI`、母版、着色器与 `01–07` 布局；去窗控、TUI、更新与容器圆角，留 44px 收起页头与三断点。

## ADR-014：移除 WizTree，存储诊断改用纯 Rust MFT 与 Win32 IOCTL

- **日期 / 状态**：`2026-11-24` · 已拍板（阶段 9.3 实施）
- **结论**：Rust 发行移除 `WizTree`。并行 Win32 遍历兜底，过实盘门禁的提权 NTFS 用 `ntfs-ng` 读 `$MFT`；`disk` 优先 Win32 IOCTL，WMI 兜底。
- **依据**：去许可与写盘风险，省 18.8 MB；本机隔离对照遍历快 6.6–40×，IOCTL 快 20–499×。
- **放弃**：随 Rust 包发 WizTree；用 GPLv3 工具。

## ADR-015：会话用量与缓存命中率改由只读分支接口计算，双端主动拉取

- **日期 / 状态**：`2026-11-25` · 已拍板
- **结论**：新增只读 `GET /api/sessions/:id/usage`，按当前活动分支重置边界后最后一条有效助手回复计算缓存命中率；双端按事件主动拉取。
- **依据**：消除跨分支与压缩前累计污染，冷读不改写文件或占槽位，只读接口无双端写竞态。
- **放弃**：整场累计 `SessionStats`；经 SSE 推送内联用量。

## ADR-016：双端方向键选中态采用无底色滑移指示器，支持四角与游标切换

- **日期 / 状态**：`2026-11-25` · 已拍板（阶段 9.4 实施）
- **结论**：双端方向键导航默认外扩四角折线，常规设置支持切换左侧游标；条目内部底色不变，切换执行 `180ms` 滑移，鼠标移动 `>=4px` 隐退。
- **依据**：避免键盘选中态与悬停或当前行底色冲突，统一桌面端与 Web 端动效曲线及偏好落盘。
- **放弃**：修改条目内部底色；仅保留单一静态选中样式。
