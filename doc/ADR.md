# 架构决策记录（ADR）

自 `2026-11-19` 起记录跨模块长期架构决策。单条正文严格控制在 150 字以内，文件清单与实施细节写入对应设计文档。已推翻或过期的决策直接删除。

## 书写规则

1. 单条含 `日期 / 状态` 元数据行，以及 `结论`、`依据`、`放弃` 三项正文。
2. 三项正文合计可见字符不超过 150 字（不含标题、`日期 / 状态`、字段标签与 Markdown 符号）。
3. 编号单调递增（`ADR-NNN`），删除旧条目不复用编号。

## ADR-001：保留 `pi-core` 上游能力，按 Feature 条件编译重型子系统

- **日期 / 状态**：`2026-11-19` · 已拍板（阶段 8.5 实施）
- **结论**：保留 `pi-core` 上游 `1.5.0` 能力。`pi-runtime` 按可选 Feature 隔离编译 QuickJS 等重型子系统，`cst-kit` 与 `cst-server` 默认关闭。
- **依据**：日常构建脱离 `rquickjs` 编译链，保留上游回归测试与较低同步成本。
- **放弃**：删除上游子系统（增加后续同步成本）。

## ADR-002：诊断核心留在单包 `cst-kit`，抽离 `cst-os` 与 `cst-updater`

- **日期 / 状态**：`2026-11-19` · 已拍板（阶段 8.5 实施）
- **结论**：诊断核心留在 `cst-kit`，按 `cst-kit -> cst-updater -> cst-os` 抽离基础库与更新器。
- **依据**：`cst-client` 禁用 `pi-*` 却共用 UAC、锁与 `server.json`。更新器脱离 `pi-*` 与 `wmi`。
- **放弃**：拆多 crate（跨包改动多）。全留单包（客户端复制锁逻辑）。

## ADR-003：字体子集改用静态补充字表，停止扫描旧 TypeScript 诊断目录

- **日期 / 状态**：`2026-11-19` · 已拍板（阶段 8.5 实施）
- **结论**：字体构建停扫 `agent/home/extensions/diagnostics`，改读 `font-extra-chars.txt`，仅哈希解析后的字符集。
- **依据**：已内置 GB2312 6,763 字。该旧目录仅多出 `≥≈`，Rust 源码为 0。
- **放弃**：扫描 Rust 源码（注释会失效缓存并触发缺字报错）。

## ADR-004：旧 Web 静态目录延后至阶段 11 随发行树统一迁移

- **日期 / 状态**：`2026-11-19` · 已拍板
- **结论**：保留 `agent/home/extensions/web/static/` 默认路径，延后至阶段 11 随纯 Rust 发行树一起迁移。
- **依据**：旧版更新器白名单不含新顶层目录，提前改路径会导致存量工具包在线升级被白名单拦截，并波及发布与 E2E。
- **放弃**：阶段 9 前迁往新目录（触发存量升级拦截并增加双路径维护成本）。
