# Web 界面规格

`web` 模块提供本机回环浏览器操作界面，覆盖会话管理、对话与工具展示、分支树导航、模型与凭据配置。前端与服务端实现见 [ARCHITECTURE.md](ARCHITECTURE.md)，页面地址与 HTTP/SSE 契约见 [API.md](API.md)，视觉令牌见 [../../DESIGN.md](../../DESIGN.md)，认证与模型配置规则见 [../auth/SPEC.md](../auth/SPEC.md)，会话接管与单写权见 [../runtime/SPEC.md](../runtime/SPEC.md)。

## 浏览器基线与分发

| 项目 | 要求 |
|---|---|
| 现代版基线 | Windows 10/11 x64 桌面浏览器，Chromium 111 起（Tailwind v4 + React 19 + HeroUI v3） |
| 兼容版基线 | Chromium 86（360 安全／极速浏览器 13 等旧壳），共用 React 19 与路由，单独构建 Tailwind 3.4 样式（避免 Chromium 86 丢弃 `@layer`、`:where()` 与 `var(--x,)` 空回退），列入后续迭代 |
| 响应式窗口 | 聊天页侧栏在 `≤960px` 时改为浮层展示；设置页在 `761–960px` 保留侧栏宽度，`≤760px` 改为浮层，点击遮罩收起 |
| 静态分发 | 构建产物随发行包预置，单一 Pi 进程内 HTTP 服务同时承载静态资源与 `/api/*` 接口，现场无需构建或联网加载 CDN |
| 主题与首屏 | Web 主题独立保存在 `web-settings.json`（默认浅色），首屏通过服务端注入 `<html data-theme>` 避免深色闪烁 |

## 导航、会话管理与全局反馈

1. **真实地址导航**：所有页面使用真实 URL（见 [API.md](API.md#页面地址空间)），支持复制链接、新标签页打开、刷新与前进后退；未命中静态资源时明确报错，仅对 HTML 导航请求回退页面入口。
2. **最近会话与批量管理**：
   - 侧栏“最近”按更新时间倒序显示最多 20 个会话，标题、会话文字与“查看全部”均为 16px，支持折叠。点击“查看全部”进入 `/sessions`；完整列表按“今天、最近一周、最近一个月、更早”分组，组内倒序，两个列表实时同步。分组按浏览器本地自然日计算，最近一周与最近一个月分别覆盖含今天的近 7 天和近 30 天，每条会话只进入最近的一个组，空组省略；页面跨日后自动更新分组。
   - 右键单条会话点“管理”进入多选模式，支持单选、全选与取消全选。侧栏全选仅作用于最近列表；全部会话页全选作用于完整列表，并提供显式管理与删除按钮。
   - 确认删除后立即乐观隐藏选中项并退出管理模式；若删除当前会话则先跳回主页，失败项恢复原位置（运行中或被另一端占用的会话拒绝删除）。折叠最近列表或切换页面时结束未提交的管理。
3. **全局通知与失联提示**：
   - 弹出通知与断线提示固定在侧栏右侧主内容区域顶部中央（距顶 20px），不将侧栏计入水平居中；普通通知有效展示 2.6 秒（悬停、聚焦或页面隐藏时暂停计时）。
   - SSE 与健康检查共同驱动断线持续提示条，恢复连接后自动撤下并重取状态，不自动重发写入请求。
4. **会话预载**：Web 页面启动后，按更新时间倒序预载最近七天内的最多 10 个会话。命中缓存时立即显示正文，后台同步最新状态；切页不显示“正在读取会话”，不闪现上一会话。缓存仅保留在当前标签页内存，删除会话时清除。
5. **重新打开**：关闭浏览器标签页或窗口后，后台服务与任务继续运行。回到待机终端输入 `/web` 可重新打开网页，复用原服务与会话。
6. **安全退出**：账号菜单“退出 CST Pilot”在确认框中展示当前运行任务数；确认后暂停队列、停止任务、等待保存与遥测定稿，再关闭 Web 服务与待机终端。聊天自动跟随滚动不关闭账号菜单；移动菜单入口的滚动与 `Esc` 可关闭菜单。

## 模型目录更新

添加服务页标题右侧提供“更新模型”按钮。点击后显示“更新中…”并禁用重复点击；完成后提示成功，部分失败或超时提示保留已有目录并可重试。后端目录变化通过全局 SSE 通知设置页和输入框自动重取模型，无需刷新浏览器。

## 模型选择与缺少凭据

1. **明确选择**：发行首次进入显示 `deepseek/deepseek-flash`；保留指定模型身份，不显示自动选择，不因缺少凭据、启用范围或目录变化而选取其他模型。
2. **独立默认值**：设置的“模型偏好”页提供可搜索的新会话默认模型选择器，与 TUI 共用设置。输入框切换仅用于当前会话或本次新建会话，保存默认值不影响已有会话。
3. **配置提示**：所选服务缺少凭据时，同一标签页仅自动弹窗一次，切页和刷新不重复提示；主动发送时仍检查凭据，缺少时再次提示。消息和图片留在草稿中，配置完成返回来源页，不自动发送。
4. **历史保留**：恢复会话沿用记录中的模型；服务或模型不再可用时保留历史并提示手动选择。
5. **合并入口**：首页与工作台共用双行主菜单，分别进入启用模型列表和思考强度列表。三种视图固定宽 224px，主菜单与列表以双向左右滑动衔接，高度同步连续过渡；列表只显示后端支持的选项，以背景标记当前项。选择成功后返回主菜单，失败保留列表与已确认值。首页选择随本次创建传入新会话，不改默认设置。
6. **键盘与收起**：列表支持方向键、Home 和 End 移动焦点，Enter 确认。列表内按 Esc 返回主菜单并聚焦对应行；主菜单按 Esc 关闭并恢复入口焦点。点击外部或页面滚动直接关闭，列表内部滚动保留面板。减少动态偏好下立即调整高度。

## 聊天工作台

### 对话流与过程折叠

一轮对话包含一条用户消息及后续全部助手消息。最后一条正文与特殊工具组件常驻可见；中间正文、思考内容与普通工具调用归入可折叠过程区：

| 状态或部位 | 展示与交互要求 |
|---|---|
| 过程头 | 首段运行中显示“工作中 N 秒”，完成后保留并更新为“已工作 N 秒”，历史无计时记录时显示“已完成”；自动折叠遵循用户选择。特殊组件后的过程按实际内容显示“思考过程”或“处理过程”，空段不显示入口；普通工具按已结束／总调用数显示进度，未完成调用不显示为已完成，独立特殊组件与读取图片不计入普通工具数量 |
| 思考块 | 折叠显示“已思考”，首次展开时渲染完整内容，不设内部滚动条 |
| 运行反馈 | 状态文字按字位自左向右扫过，中心最强、相邻次之、隔一字最弱；浅色提亮，深色压暗。特殊组件右下角反光为约占组件面积 40% 的柔边三角形，越向内越淡。完成后停止，页面隐藏与离屏时暂停，减少动态时使用原色静态状态 |
| 流式连续性 | 追加段落、工具阶段切换与定稿保持已读正文连续；结束事件直接承接完整内容，慢速快照与重连不先清空正文，已读文字不重播入场 |
| 代码块复制 | Markdown 围栏与缩进代码块、思考和总结原文、工具原始输出及技术详情提供常驻复制图标；已有命令复制入口保留，不重复添加。复制保留缩进、空行与换行，不包含按钮、反馈文字或 Markdown 围栏；流式阶段复制点击时的当前内容，失败时提示手动复制或重试；行内代码不添加按钮 |
| 末尾操作与菜单 | 本轮最后一条助手消息末尾提供“复制”与“从此处分支新会话”；标题栏消息菜单提供“分支树”和“导出会话”；“分享”为置灰的计划功能 |
| 内容宽度 | 正文、工具卡与输入框共用居中列，最大宽度 1144px，左右边缘对齐。主区两侧至少各留 24px，窗口宽度 ≤960px 时至少各留 16px；表格不超出正文列 |
| 滚动跟随 | 滚动区铺满主区；用户上翻停止自动跟随并显示“回到底部”，点击或滑到底部恢复跟随 |
| 工作台边界 | 外壳高度固定为可见窗口；长内容仅在右侧页面内部滚动。侧栏铺满窗口，切页复用同一实例并保持静止 |

### 会话导出

1. **选项与快照**：从消息菜单进入导出页，可选择 PNG / HTML、日间 / 夜间文档主题及思考／工具结果包含项。默认主题跟随当前页面，两项过程内容默认省略。生成时重新读取当前分支全部对话，包含 `/tree` 导航后的状态；归档日期与快照时间统一取生成时刻，不提供日期或范围选择。
2. **保存与复用**：固定创建时的消息快照，后端后台生成并保存至 `artifacts/<日期>/sessions/`，目录内直接放 PNG 或 HTML。文件名由标题、快照日期时间及 PNG 分页号组成，重名追加组号，不覆盖已有文件。网页、自行调用 API 与分享共用任务和文件读取接口；页面关闭后继续生成，重启后保留已完成的登记。
3. **文件内容**：保留提问、回复、附图、代码和表格，省略侧栏、输入框、账号与动作控件。长 PNG 分图，HTML 内嵌样式、字体和附图并支持原生过程折叠；两种格式沿用聊天组件与主题。已有 BitLocker 脱敏规则用于导出副本。
4. **失败边界**：选项与保存路径必须校验；生成失败清理半成品并返回可重试状态，文件被修改或移走时明确提示。任务数量、超时和输出大小有限制，详见 [API](API.md#会话导出接口)。
5. **生成性能**：无排队时，PNG 与 HTML 以 10 秒内完成生成和落盘为目标。性能回归覆盖短会话与 500 段含代码长会话，两种格式分别验证冷启动与浏览器复用，保留两倍清晰度、完整正文和离线字体。
6. **运行兼容与隔离**：使用随包 `puppeteer-core` 控制已安装的 Edge / Chrome，现场不下载浏览器。每个任务的页面与存储互相隔离；缺少浏览器、启动失败或版本不兼容时返回可操作错误，兼容边界见 [API](API.md#会话导出接口)。
7. **保存结果**：前端仅展示已保存数量与可点击目录，不展示文件名列表。点击目录由后端校验并打开本机文件管理器，失败仅重试打开操作，不重新导出。
8. **页面转场**：从消息菜单进入、返回对话、通过侧栏切换工作台页面以及浏览器前进后退，均对右侧整页播放入退场，侧栏不参与切页位移。跳转独立登录页时保留导出内容退场。直达导出页播放一次入场；原生快照与局部入场不重复。减少动态时直接呈现，无快照能力时保留局部入场；只读文档 `/_export` 不播放页面转场。

### 输入收件箱与图片附件

后端先将接受的消息与图片持久化至 `web-inbox/` 并分配序号，确认后前端才清空草稿：

| 机制 | 规则 |
|---|---|
| 投递模式 | 会话空闲且无待处理项时直接投递；运行中支持“排队”（空闲后每轮投递一条）与“插话”（下一个模型调用边界投递，不打断当前输出） |
| 队列操作 | 未投递项支持拖拽重排、编辑（出队回填输入框）、删除与转为插话，操作均携带队列版本校验（过期返回 409） |
| 停止与失败 | 点击停止（或空输入按 `Esc`）终止当前轮次并暂停队列，发送新消息恢复；投递失败项停留在队列并保留重试、编辑与删除入口；进程重启后恢复队列但禁止自动重放未确认结果的请求 |
| 图片草稿 | 支持选择或粘贴 PNG、JPEG、GIF、WebP，单次原始字节合计不超过 12 MiB；未发送草稿与图片按标签页隔离并在同页刷新后恢复，跨标签页通过引用计数与存活锁防止误删 |
| 图片预览 | 消息附图、工具返回图片与待发送缩略图支持点击或键盘打开居中大图；图片按原始比例适配视口，点击图片、空白处、关闭按钮或按 `Esc` 收回，关闭后恢复原入口焦点与滚动位置 |
| 上下文与额度 | 三横线图标独立打开上下文面板，面板展示窗口占用比例；展开面板按当前服务按需查询额度（CSTOA 额度点、DeepSeek 余额、OpenCode Go 三窗口），不后台轮询 |

## 命令与功能对应

Web 输入框通过 `/` 或 `Tab` 打开命令与技能补全，通过 `@` 打开会话 `cwd` 文件补全。输入法组合输入（IME）期间按 `Enter` 仅选词，不触发选中或发送。

| TUI 命令 | Web 承载方式 | 行为规则 |
|---|---|---|
| `/new`、`/resume`、`/name` | 侧栏控件与右键菜单 | 新建对话、切换历史会话、重命名 |
| `/model`、`/thinking`、`/scoped-models` | 输入框菜单与设置页 | 切换当前模型与思考强度；设置页独立选择新会话默认模型、启用范围与顺序 |
| `/login`、`/logout` | `/login`、`/settings`、`/account` | 多服务登录与单服务独立退出 |
| `/compact` | 斜杠行内标记 | 选中后内嵌为行内标记，后续输入作为压缩额外提示词提交 |
| `/skill:<name>` | 斜杠行内标记 | 覆盖 8 个诊断技能（`bitlocker`、`disk`、`driver`、`eventlog`、`ls`、`runbook`、`startup`、`sys`），提交后由后端展开技能正文 |
| `/fork` | 消息末尾按钮 + 斜杠命令 | 打开派生选择面板（列出全部用户消息，默认选中末条），确认后在所选消息前分支并预填该消息文本 |
| `/tree` | 消息菜单 + 斜杠命令 + 独立视图 | 斜杠选中即跳转 `/s/<id>/tree`，不留行内标记 |
| `/export` | 消息菜单与导出页 | 预览、选择格式与主题及过程包含项，保存 PNG 或离线 HTML |
| `/share` | 消息菜单置灰项 | 后续复用导出 API，发布与销毁规则待定 |
| `/reload`、`/trust`、`/import`、`/debug`、`!cmd` | 否决 | Web 端不开放扩展重载、项目信任切换、外部导入、调试日志与 Shell 直通 |

## 分支树与分支总结

### 分支树（`/s/<id>/tree`）

1. **五档过滤**：默认视图（隐藏 `label`、`custom`、`model_change`、`thinking_level_change`、`session_info` 五类设置条目）、无工具、仅用户、仅标记、全部。隐藏条目的可见后代重挂至最近可见祖先，保持原始深度优先次序（当前叶所在路径优先，其余按时间）。
2. **几何语义**：方框表示真实分叉的子分支入口（同级入口同列），竖线仅在非末位兄弟子树内延续，单子链不画连接线；段首且含可见后代的行支持折叠／展开。
3. **选择与快捷键**：`↑/↓` 移动游标，`Ctrl+O` / `Shift+Ctrl+O` 循环切换过滤档位，`Enter` 或点击非当前叶条目弹出分支总结三选项确认卡片。

### 分支总结

选择目标条目后提供三种模式：**不总结**（直接导航，目标为用户消息时正文回填输入框）、**总结**（跳回聊天页携带 `?branch=<entryId>&mode=summarize` 立即生成分支总结并导航）、**用自定义提示词总结**（携带 `mode=custom` 在聊天输入框显示标记，提交提示词后总结并导航）。生成期间支持随时取消，取消后保持原分支位置不变且不新增条目。

## 工具调用与卡片

Web 覆盖全部 17 个开放工具（10 个诊断扩展工具、`pi-web-access` 4 个工具、`pi-fff` 2 个工具、内置 `read`）。单工具调用独立计时并在完成时冻结。

| 类别 | 适用工具 | 呈现与交互规则 |
|---|---|---|
| 普通工具卡片 | `disk`、`driver`、`eventlog`、`ls`、`startup`、`sys(proc/gpu/io/sensor)`、`bitlocker(status)`、`source_check`、`fetch_content`、`get_search_content`、`ffgrep`、`fffind`、`read` | 连续调用合并为“已完成检查 · N 次工具调用”折叠行；展开后显示各工具状态行，再点击展开卡片（采用**概览组**、**排行组**或**原文块**三主模板之一，底部附原始数据开关；`read` 图片先展示图片再展示绝对路径） |
| 特殊内嵌组件 | `bitlocker(unlock/decrypt)`、`sys(overview)`、`command_plan`、`runbook_deliver`、`runbook`、`web_search` | 与回复正文同级常驻，不进入过程折叠或工具计数行 |

特殊内嵌组件行为：

- **`bitlocker unlock/decrypt`**：通过会话绑定的待处理接口展示目标卷、恢复保护器 ID、隐藏恢复密码输入框（支持查找恢复密钥外链）或固定解密目标确认按钮；已消费、过期或取消的请求不可重复提交。
- **`sys overview`**：常驻展示 CPU、内存、机型与开机时长，次级字段收进详情折叠区。
- **命令方案与交付**：`command_plan`、`runbook_deliver` 与 `runbook` 共用常驻组件，展示结果中的命令、环境、说明与复制按钮。方案显示版本和“待核对，尚未导出文本”；交付成功后显示文件名打开链接，后端按请求去重。刷新、压缩和重开会话保持历史版本内容；写入失败时不显示打开链接。
- **`web_search`**：单行展示检索状态与加载圆弧，点击展开查询关键词列表。

## 仪表盘

`/dashboard` 列入后续功能迭代（见 [../TASKS.md](../TASKS.md#功能迭代)），计数与呈现规格如下：

1. **计数单位与记录**：每行对应主 Agent 的一次逻辑模型调用，工具执行与单次 HTTP 重试不拆分为多行。计划中的本地记录包含会话 ID、请求序号、发起时间、响应耗时、首个非空增量等待时间、最终状态、错误码、结束原因及模型用量；记录不上传，存储和保留规则见[待办](../TASKS.md#功能迭代)。
2. **页面区域**：顶部供应商／模型／日期范围筛选（默认近 14 天）；概览区展示总 Token、调用次数、按 CNY / USD 分列的估算费用、缓存命中率 `cacheRead / (input + cacheRead + cacheWrite)`；按日堆叠柱趋势图；分页请求日志表与 CSV 导出。
3. **呈现红线**：缺失值显示 `—`（禁止补 `0`）；明确的零保留为 `0`；未配置有效价格显示“未定价”（禁止显示 `$0.00`）；不同币种严禁直接相加。
