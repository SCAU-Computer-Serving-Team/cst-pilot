# Web 界面规格

`web` 模块提供本机回环浏览器操作界面，连接 `cst-server` 后台服务，覆盖会话管理、对话与工具展示、分支树导航、会话导出及模型与凭据配置。前后端实现结构见 [ARCHITECTURE.md](ARCHITECTURE.md)，页面路由与 HTTP/SSE 契约见 [API.md](API.md)，动效、令牌与交互行为见 [storybook.html](../../design/storybook.html)（其静态组件与变量严格对应 `.pen` 设计稿且 `.pen` 优先级更高），静态设计见对应 `.pen` 画布，文本规范见 [DESIGN.md](../../DESIGN.md)，认证规则见 [../auth/SPEC.md](../auth/SPEC.md)，通道门禁与单写权见 [../server/SPEC.md](../server/SPEC.md)。

## 浏览器基线与分发

| 项目 | 要求 |
|---|---|
| 现代版基线 | Windows 10/11 x64 桌面浏览器，Chromium 111 起（Tailwind v4 + React 19 + HeroUI v3） |
| 兼容版基线 | Chromium 86（360 安全／极速浏览器 13 等旧壳），共用 React 19 与路由，单独构建 Tailwind 3.4 样式，列入后续迭代 |
| 响应式窗口 | 聊天页侧栏在 `≤960px` 时改为浮层展示。设置页在 `761–960px` 保留侧栏宽度，`≤760px` 改为浮层，点击遮罩收起 |
| 静态分发 | 构建产物随发行包预置，由本机 `cst-server` 同时承载静态资源与 `/api/*` 接口，现场无需构建或联网加载 CDN |
| 主题与首屏 | Web 主题独立保存在 `web-settings.json`（默认浅色），首屏通过服务端注入 `<html data-theme>` 消除深色闪烁 |

## 导航、会话管理与全局反馈

1. **真实地址导航**：所有页面使用真实 URL（见 [API.md](API.md#页面地址空间)），支持复制链接、新标签页打开、刷新与前进后退。未命中静态资源时明确报错，仅对 HTML 导航请求回退页面入口。整页打开和刷新播放一次入场，站内切页沿用各页转场，减少动态时直接呈现。
2. **最近会话与批量管理**：
   - 侧栏“最近”按更新时间倒序显示最多 20 个会话，标题、会话文字与“查看全部”均为 16px，支持折叠。点击“查看全部”进入 `/sessions`。完整列表按浏览器本地自然日分为“今天、最近一周、最近一个月、更早”四组，每条会话只进入最近一组，空组省略，跨日自动重分组。
   - 通过右键、触控长按或键盘菜单键（`Shift+F10` / `ContextMenu`）打开单条会话菜单，可执行重命名、单条删除或进入多选管理。重命名与删除确认使用非阻塞原生 `<dialog>` 模态框。已卸载弹窗的迟到响应不影响新弹窗。
   - 确认删除后立即乐观隐藏选中项并退出管理模式。删除当前会话时先跳回主页，失败项恢复原位置（运行中或被占用的会话返回 `409`）。折叠列表或切页时结束未提交的管理态。
3. **全局通知与断线提示**：
   - 弹出通知与断线提示固定在侧栏右侧主内容区顶部中央（距顶 20px），普通通知有效展示 2.6 秒（悬停、聚焦或页面隐藏时暂停计时）。
   - SSE 与健康检查共同驱动断线持续提示条，恢复连接后自动撤下并重取最新状态，不自动重发写请求。
4. **会话预载**：取得会话列表后，按更新时间倒序预载最新最多 10 个会话（分两批、每批最多 5 路并发），命中内存缓存时立即显示正文并在后台同步最新状态，切页不闪现旧正文。
5. **通道待机与重新打开**：后台处于 `AppActive`（软件端活跃或已在软件端退出 Web 模式）时，网页关闭活跃 SSE 连接并展示通道待机提示，保留当前标签页未发送草稿与图片。关闭浏览器标签页不中断后台任务。软件端重新打开 Web 或独立 Web 模式下可直接恢复操作。
6. **安全退出**：独立 Web 模式下账号菜单“退出 CST Pilot”在确认框中展示当前运行任务数，确认后暂停队列、停止任务，等待遥测定稿后关闭后台服务。

## 模型目录更新

添加服务页标题右侧提供“更新模型”按钮，点击后显示“更新中…”并禁用连点，完成或部分失败均通过顶部通知反馈并保留可用缓存。后端目录或服务变更通过全局 SSE 自动通知设置页与输入框重取模型，无需刷新页面。

模型偏好页提供“刷新”重取模型与启用范围，保留勾选与排序。筛选的服务被移除后自动切回“全部”。

## 模型选择与缺少凭据

1. **明确选择**：发行首次进入固定显示 `deepseek/deepseek-flash`，不因缺少凭据、启用范围或目录变化自动改选其他模型。
2. **独立默认值**：模型偏好页提供可搜索的新会话默认模型选择器，与软件端共用设置。输入框切换仅作用于当前会话或本次新建会话。
3. **缺凭据自动提示**：完全没有配置任何服务凭据时自动弹窗提示，通过服务端 `/api/ui-hints/missing-key-prompt/claim` 在桌面、TUI 与 Web 三端共享 24 小时冷却窗口（首次接入时若本地 `localStorage` 存有旧时间戳则单向合并上报并清理本地键）。主动发送缺凭据模型时始终拦截提示，保留输入框草稿与图片，配置完成后返回原页面且不自动发送。
4. **双级合并选择器**：首页与工作台共用宽 224px 的右下锚点双行主菜单，双向左右滑动进入启用模型列表或思考强度列表，高度同步连续过渡。支持方向键、`Home`、`End`、`Enter` 与逐级 `Esc` 焦点恢复。

## 聊天工作台

### 对话流与过程折叠

一轮对话包含一条用户消息及后续全部助手消息。最后一条正文与特殊工具组件常驻可见。中间正文、思考内容与普通工具调用归入可折叠过程区：

| 状态或部位 | 展示与交互要求 |
|---|---|
| 过程头 | 首段运行中显示“工作中 N 秒”，完成后保留并更新为“已工作 N 秒”，历史无计时记录时显示“已完成”。特殊组件后的过程按实际内容显示“思考过程”或“处理过程”，空段省略。普通工具按已结束／总调用数显示进度，特殊组件与读取图片不计入普通工具数量 |
| 思考块 | 折叠显示“已思考”，首次展开时挂载渲染完整内容，不设内部滚动条 |
| 运行反馈 | 状态文字按字素自左向右流光扫过，特殊组件右下角带柔边反光。完成后停止，隐藏页与离屏时暂停，减少动态时保持原色静态 |
| 流式连续性 | 追加段落、工具阶段切换与定稿保持已读正文连续，结束事件原位承接完整内容，慢速快照与重连不闪空 |
| 代码块复制 | Markdown 围栏与缩进代码块、思考和总结原文、工具原始输出及技术详情提供常驻复制按钮。复制保留原始换行与缩进，不含围栏或按钮文字 |
| 末尾操作与菜单 | 本轮末条助手消息末尾提供“复制”与“从此处分支新会话”。标题栏消息菜单提供“分支树”、“导出会话”与置灰占位的“分享” |
| 内容宽度与滚动 | 正文、工具卡与输入框共用最大 `816px` 居中列，桌面两侧至少留 `24px`（`≤960px` 留 `16px`）。外壳固定为窗口高度，长内容仅在右侧内部滚动，用户上翻停止自动跟随并展示“回到底部”。超过 80 条消息时按完整用户轮边界滑窗增载 |

### 会话导出

1. **选项与快照**：导出页提供 PNG / HTML 格式、浅色 / 深色文档主题及“包含思考过程”、“包含工具调用结果”选项（两项默认关闭）。生成时统一按同一本机时刻固定当前分支脱敏快照与归档日期，不提供手动日期或轮次选择。
2. **后台保存与完整性**：产物保存至 `artifacts/<日期>/sessions/`，按标题、快照日期时间及分页号排他命名，重名整组递增组号。离开页面继续后台生成。读取已导出文件时校验 SHA-256，文件被修改或移走时明确报错。
3. **排版与离线交互**：长 PNG 自动按切点分图（2 倍高清）。离线 HTML 内嵌样式、轻量等宽代码字体与附图并启用严格 CSP（跳过中文字体 Base64 内嵌以保持轻量体积），过程、思考与工具分组支持原生 `<details>` 离线展开，特殊工具保留折叠详情与检索词入口并移除执行按钮。未闭合的 BitLocker 强杀复查结果在导出文档中保持与聊天页一致的未知状态展示。
4. **浏览器隔离与性能**：后端通过 `Chromiumoxide` 按需复用本机已安装的 Edge 或 Chrome（要求主版本 ≥111），每任务使用独立 `BrowserContext` 并拦截一切非同源静态资源请求，空闲 30 秒自动回收。短会话与 500 段长会话在无排队时均以 10 秒内完成为目标。
5. **预览交接与目录打开**：切换选项时保留旧预览并在后台渲染新 iframe，字体与附图就绪后以 250ms 淡入衔接并保持滚动位置。保存完成后仅显示文件数量与目录打开按钮，点击由后端校验真实目录并拉起系统资源管理器。

### 输入收件箱与图片附件

发送前先在当前标签页保存输入与图片引用并立即清空编辑器，聊天页展示乐观气泡，首页待会话创建完成后跳转展示。

| 机制 | 规则 |
|---|---|
| 乐观发送与失败恢复 | 本地保存成功后立即上屏。同会话按序提交，前条失败或结果未知时暂停后续本地提交。明确拒绝项提供重试、编辑、移除与配置密钥入口 |
| 结果待确认（`uncertain`） | 断线、超时或进程重启遗留 `delivering` 条目时只做只读回执核对，不自动重发。显式重试沿用原消息 ID |
| 排队与插话 | 空闲时直接投递。运行中支持排队（`queue`）与插话（`steer`，在下一模型调用边界优先进入）。未投递项支持拖拽重排、编辑、删除与转插话（均校验队列 `version`） |
| 图片草稿与预览 | 支持选择、粘贴或拖入 PNG/JPEG/GIF/WebP（单次原始字节合计 ≤12 MiB），跨标签页通过引用计数与存活锁防误删。聊天、工具与草稿图片共用居中原比例缩放预览 |
| 上下文与额度 | 三横线图标打开上下文占用面板，展开时按需查询当前服务额度（CSTOA 额度点、DeepSeek 余额、OpenCode Go 三窗口） |

## 命令与功能对应

输入框在行首输入 `/` 打开命令与技能补全（按 `Tab` 或 `Enter` 确认高亮项），输入 `@` 打开会话 `cwd` 文件补全。中文输入法组合输入期间按 `Enter` 仅选词，不触发补全确认或发送。

| 命令 | Web 承载方式 | 行为规则 |
|---|---|---|
| `/new`、`/resume`、`/name` | 侧栏控件与右键菜单 | 新建对话、切换历史会话、重命名 |
| `/model`、`/thinking`、`/scoped-models` | 输入框菜单与设置页 | 切换当前模型与思考强度。设置页保存默认模型、启用范围与排序 |
| `/login`、`/logout` | `/login`、`/settings`、`/account` | 多服务登录与单服务独立退出 |
| `/compact` | 斜杠行内标记 | 内嵌标记并将后续输入作为压缩附加说明提交 |
| `/skill:<name>` | 斜杠行内标记 | 覆盖 8 份诊断技能，提交后由后端展开技能正文 |
| `/fork` | 消息末尾按钮 + 斜杠命令 | 打开派生选择面板（默认选中末条用户消息），确认后在该消息前分支并回填正文 |
| `/tree` | 消息菜单 + 斜杠命令 + 独立视图 | 跳转 `/s/<id>/tree` |
| `/export` | 消息菜单与导出页 | 预览并导出会话 PNG 或离线 HTML |
| `/share` | 消息菜单置灰项 | 后续复用导出接口，发布与销毁规则见[待决议题](../TASKS.md#工程与安全边界) |

Web 端不开放扩展重载、项目信任切换、外部文件导入，也不提供调试日志与 Shell 直通命令。

## 分支树与分支总结

1. **五档过滤与几何语义**：`/s/<id>/tree` 提供默认视图、无工具、仅用户、仅标记、全部五档过滤。隐藏节点的可见后代重挂至最近可见祖先，方框标示真实分叉入口，竖线仅在非末位兄弟子树内延续，段首支持折叠。
2. **导航与分支总结**：支持 `↑/↓` 移动游标与 `Ctrl+O` 循环切换过滤档位。选中非当前叶条目弹出**不总结**、**总结**、**用自定义提示词总结**三选项卡片，生成期间可随时取消并保持原叶节点不变。

## 工具调用与卡片

Web 覆盖全部 17 个开放工具，单工具调用独立计时并在结束时冻结：

| 类别 | 适用工具 | 呈现与交互规则 |
|---|---|---|
| 普通工具卡片 | `disk`、`driver`、`eventlog`、`ls`、`startup`、`sys(proc/gpu/io/sensor)`、`bitlocker(status)`、`source_check`、`fetch_content`、`get_search_content`、`ffgrep`、`fffind`、`read` | 连续调用合并为“已完成检查 · N 次工具调用”折叠行。展开后采用概览组、排行组或原文块模板展示，底部附原始数据开关。`read` 图片先展示图片再附绝对路径 |
| 特殊内嵌组件 | `bitlocker(unlock/decrypt)`、`sys(overview)`、`command_plan`、`runbook_deliver`、`runbook`、`web_search` | 与正文同级常驻展示，不进入过程折叠或普通工具计数 |

特殊内嵌组件行为：

- **`bitlocker unlock/decrypt`**：展示目标卷、保护器 ID、隐藏恢复密码输入框或固定解密目标确认按钮。格式错误保留原请求可修正重试，已消费、超时或异常中断的请求分别展示对应终态或“结果未确认”复查状态。
- **`sys overview`**：常驻展示 CPU、内存比例条、机型与开机时长，次级字段收进详情折叠区。
- **`command_plan` / `runbook_deliver` / `runbook`**：按风险分档展示命令、执行环境、说明与单条复制按钮。方案显示版本号与待核对状态，已交付清单显示可点击打开系统记事本的文件名链接。
- **`web_search`**：默认直接检索返回结果，单行展示状态图标、运行角标柔光与关键词数量，点击展开查询关键词列表。

## 仪表盘

`/dashboard` 列入[功能迭代](../TASKS.md#功能迭代)，规格要求如下：

1. **计数单位**：每行对应主 Agent 的一次逻辑模型调用，工具执行与单次 HTTP 自动重试不拆分为多行。记录仅存本机，不上传遥测服务器。
2. **页面分区**：顶部提供服务商、模型与日期筛选（默认近 14 天），中部展示总 Token、调用次数、按 CNY / USD 分列的估算费用与缓存命中率，下部展示按日堆叠柱趋势图与分页请求日志及 CSV 导出。
3. **数值红线**：缺失值显示 `—`（禁止补 `0`），明确零值显示 `0`，无价格模型显示“未定价”，不同币种禁止直接相加。
