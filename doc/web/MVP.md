# MVP 要做的内容

状态：待实现。产品待决事项见[待决议题](../issues.md)，待补画布见 [Todo](../Todo.md#todraw-画布)。更新：2026-09-23。

[PRD](../PRD.md) 的 W1–W9 定义 Web 的总体目标。本文划定首版交付范围，兼容版与仪表盘列在后续阶段；具体行为引用各规格。

**MVP 只做现代版**：Chromium 111 起，Tailwind v4，直接使用 HeroUI v3（`@heroui/react` + `@heroui/styles`）。首版使用后台管理员账号的 API KEY；后续接入 OAuth。两种凭据在 Web 中对应同一种模型服务登录态，有效期按各自机制处理。功能验证后再接入发行包。

**前端严格按设计稿实现。** 页面结构、布局、字号、图标、色值与浅深主题对照 [cst-pilot-web.pen](../../src/web/design/cst-pilot-web.pen)、[cst-pilot-tools.pen](../../src/web/design/cst-pilot-tools.pen)；取色依据 [cst-pilot-colors.pen](../../src/web/design/cst-pilot-colors.pen)，跨页面视觉规则以 [DESIGN.md](../../DESIGN.md) 为准。交互和数据行为以 SPEC 为准；画布中属于后续阶段或已被 MVP 排除的入口不显示。直接使用 HeroUI v3 承载现成控件及交互，按设计稿定制样式；诊断字段行、排行行等库中没有的结构才由项目组件组合。缺画布的 MVP 交互先补浅深设计，再实现前端。

## 八、实施 checkpoint

按顺序完成；每个 checkpoint 验收后再进入下一阶段。接口细节、异常语义和画布缺口仍以对应 SPEC、[工程验证](issues.md)及 [Todo](../Todo.md#todraw-画布)为准。

| 阶段 | 实现内容 | 验收标准 |
|---|---|---|
| 1. 工程与设计基座 | 建立前端工程、扩展入口、单一 HTTP 服务器和静态资源服务；接入 HeroUI v3、主题、字体、色值及首页/聊天页/登录页的共用外壳。先验证官方二进制下的 SDK 装配与长驻资源边界。 | `/web` 在开发环境启动并打开本机页面；`/api/state` 可读，刷新深链接仍返回页面，缺失资源不会返回页面。浅深主题首屏无闪烁；三个现有页面的布局与画布逐项对照，使用 HeroUI 组件，未以截图替代界面。 |
| 2. 会话接管与并行 | 实现 TUI 待机、进程级容器、按会话 ID 管理的 Web 实例、占用与销毁；接管已落盘会话，空会话新建。 | `/web` 后 TUI 留在同一进程且不能通过输入改写会话或退出；已落盘会话仅有一个写入实例。两场会话可同时执行，停止 A 不影响 B；页面切换、刷新及关标签不取消仍在运行的任务。 |
| 3. 接口与输入收件箱 | 完成会话、消息与图片、队列、事件流、模型、API KEY 登录、设置、扩展提问等 MVP 接口；实现服务端持久化、去重、版本冲突与同源安全边界。 | 两个页面向同一会话提交时按后端确认顺序执行且不重复；队列编辑/排序/插话、停止暂停、写入失败和重启后不自动重放均可验证。事件流断线能续传，超出保留范围能全量重取；凭据不进入浏览器存储或响应，会话间工具权限不扩大。 |
| 4. 页面与卡片 | 先补分支树、设置、API KEY 登录、补全面板、排队组件、图片、扩展提问及操作栏画布；实现五个页面和命令对应交互。按逐工具设计完成通用内容组、例外卡片与实时/历史共用映射。 | 五个地址可直接打开、刷新、前进后退；首页、工作台、树、设置、登录页的浅深主题与画布一致。消息、思考、工具、markdown、图片、队列及快捷键可操作；开放的 14 个工具均按逐工具设计展示；无法解析的结果使用通用原文回退。成功、执行中、中断、整次失败、部分降级与截断不会混淆。 |
| 5. 联调与 MVP 验收 | 对照 SPEC 补齐空会话、并发、恢复、断线、写失败与模型失效场景；在实际浏览器逐页核查设计稿、键盘/输入法、动效与可读性。 | 从 TUI `/web` 启动到登录、建会话、诊断、排队、停止、恢复、派生、导出及退出，均可由 Web 完成；Chromium 111 起的实际窗口验收通过。在 1920×1080 实际浏览器窗口逐页对照浅深画布，检查布局、排版、颜色与关键交互状态；动画遵循 DESIGN.md 并支持减少动效。前端构建、类型检查和项目检查通过。发行包验收留到后续阶段。 |

## 验收

| 项 | 标准 |
|---|---|
| 替代 TUI | 在开放能力范围内，会话管理、模型与凭据配置、扩展交互都能在 Web 完成 |
| 会话接管 | `/web` 后 TUI 留在 Pi 进程内待机，Web 接管已落盘的原会话；TUI 输入不能修改会话或退出程序 |
| 登录态 | API KEY 可用于模型调用；状态与退出操作可在 Web 完成，失效时明确提示重新登录 |
| 现代版 | 在 Chromium 111 起的浏览器上跑完整个交互 |
| 本地运行 | 开发环境可用预构建页面产物运行；现场零安装在发行接入阶段验收 |
