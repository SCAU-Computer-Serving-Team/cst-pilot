# Web MVP

**MVP 阶段已完成。** 当前工作进入后续功能迭代、发行验证与运维完善阶段。

本文记录已交付范围和后续边界。总体需求见 [PRD](../PRD.md)，具体行为以 SPEC 为准；后续任务见 [Todo](../Todo.md)，未决选择见[议题清单](../issues.md)。

已交付现代版 Web：Chromium 111 起，Tailwind v4，使用 HeroUI v3（`@heroui/react` + `@heroui/styles`）。Web 使用工具包提供的预构建静态资源，支持 OAuth 与 APIKEY，凭据由 Pi 管理。

视觉规则见 [DESIGN.md](../../DESIGN.md)，页面和工具卡片分别对应 [Web 画布](../../src/web/design/cst-pilot-web.pen)与[工具画布](../../src/web/design/cst-pilot-tools.pen)。

## 一、承载

| 已交付能力 | 依据 |
|---|---|
| Web 扩展启动单一 HTTP 服务器，注册 `/web` 命令 | [前端设计](../design/web/frontend.md#工程边界) |
| 进程级运行容器管理共享服务、占用表和输入队列 | [共享状态](SPEC/session-runtime.md#共享状态) |
| 按会话 ID 管理独立实例，支持多会话并行 | [会话运行与并行](SPEC/session-runtime.md) |
| `/web` 后 TUI 留在原进程待机；接管已落盘会话，空会话新建；每场会话只有一个写入实例 | [写权与会话串行](SPEC/session-runtime.md#写权与会话串行) |
| 输入先落盘再投递，停止时暂停队列 | [输入收件箱](SPEC/session-runtime.md#输入收件箱) |
| `/api/*` 提供接口，静态资源与页面导航分别处理 | [静态服务](../design/web/frontend.md#静态服务与路由) |

## 二、接口

| 组 | 已交付接口 |
|---|---|
| 会话 | 列表、新建、详情、重命名、删除、进入、离开、消息与图片、停止、队列插话／编辑／删除／排序、派生、分支树与导航、压缩、事件流 |
| 模型与登录 | 模型清单、会话模型与思考强度、启用范围、APIKEY 与 Pi OAuth、专属账号状态与退出 |
| 设置 | 读写设置 |
| 运行时 | 启动快照、全局事件流 |

路径与约定见[接口](SPEC/app-router.md#接口)与[约定](SPEC/app-router.md#约定)。

## 三、页面

| 页面 | 地址 | 已交付功能 |
|---|---|---|
| 主页 | `/` | 新建对话、输入、模型选择和导航 |
| 聊天工作台 | `/s/<sessionId>` | 对话流、过程折叠、工具层级、队列和恢复 |
| 分支树 | `/s/<sessionId>/tree` | 树结构、筛选、导航与派生 |
| 设置 | `/settings` | 常规、模型服务、添加服务、配置、模型偏好和快捷键；主题与模型范围自动保存 |
| 登录页 | `/login` | CSTOA 扫码、Pi OAuth 与 APIKEY 授权 |
| 账号信息 | `/account` | 学号、姓名、登录与退出；额度集中在上下文面板 |

## 四、聊天工作台

| 部分 | 已交付功能 |
|---|---|
| 侧栏 | 品牌、新对话、会话分组与管理、当前电脑和设置 |
| 标题栏 | 会话标题、分支树入口；导出与分享保留置灰入口 |
| 消息 | 用户消息、Markdown 正文、代码高亮、表格、图片、复制与派生 |
| 过程 | 思考和工具分组可展开；特殊工具卡片独立展示，实时与历史状态一致 |
| 编辑器 | 附件、模型、上下文与额度、思考强度、发送、停止和快捷键 |
| 队列 | 拖拽排序、编辑、立即投递、暂停与失败状态 |
| 响应式窗口 | 窄屏侧栏浮层、遮罩收起、内容不被侧栏挤压 |
