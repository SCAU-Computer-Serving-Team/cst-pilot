# Web 发行装配可行性

官方 Pi 可执行文件、预构建 Web 和白名单扩展装配可承载当前功能。现场无需 Node、Python 或 npm，前端开发依赖不进入发行包。装配命令见 [pack](../../../pack/README.md)，当前方案见[便携发行设计](../../design/release.md)。

## 运行依据

| 部分 | 依据与边界 |
|---|---|
| Pi | 固定官方 0.85.1 和 hash；实际进程为 Bun 1.3.14 / Node 兼容 24.3.0 |
| Web | 浏览器运行 JS/CSS/字体，Pi 进程提供本机 HTTP/SSE；真实 read 与续答已通过 |
| 项目扩展 | TS 由官方程序加载，运行协调与 Web 复用共享 SDK；不另带后端运行进程 |
| 第三方 JS | 固定 esbuild 预打包，Pi 包保持 external，避免重复 SDK 实例 |
| 原生资源 | FFF、PowerShell、WizTree、LHM 按 Windows x64 保留必要文件与许可 |

官方的 Node 兼容接口属于内置运行时，前端构建用 Node 仅需留在构建机。原生 DLL、字体和外部诊断程序各有资源路径与许可要求。

| 开发扩展依赖 | 7375 | 54.77 |
| 开发 Web 依赖 | 39554 | 242.90 |

| Web 静态资源 | 48 | 6.03 |
| PowerShell | 602 | 244.15 |

开发依赖合计 60686 个文件，发行白名单排除了这些目录。主要体积来自运行资源，Web 静态资源约占样本 1.47%；后端保留精简源码即可维持装配边界。每次实际构建以 BUILD-INFO 和 SHA256SUMS 为准。

## 校验与现场范围

装配从当前前端源码重建，检查静态引用、字体、运行协调模块、许可、凭据与运行态。官方 exe 冒烟在独立副本执行启动、模型注册、真实 read 续答与退出；干净发行树不运行，ZIP 按清单生成并解压复核。

完整 packages 下的 TUI 接管、待机、写权、cwd、范围与独立主题由[跨端联调](../../test/shared-backend-report.md)覆盖。该结论限定于本机隔离环境；Windows 10、最低浏览器、真实 U 盘/跨机、普通权限、杀毒软件、生产授权与全部系统交互仍需按[Checkpoint 5](../../test/checkpoint5-report.md)验证。

现场验证范围见[发行前检查](../../design/release.md#发布前检查)。版本号不代表全部目标环境已验证。
