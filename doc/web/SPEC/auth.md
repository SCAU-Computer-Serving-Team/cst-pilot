# 登录与模型配置

本页定义模型服务、OAuth、API KEY、账号与启用模型的行为。接口列表见[页面地址与接口](app-router.md#模型与登录)，实现见[OAuth 设计](../../design/web/oauth.md)。

## 服务与凭据

| 项 | 规则 |
|---|---|
| 登录能力 | 取 Pi 的 `supportsApiKey`、`supportsOAuth`，不维护独立服务白名单 |
| 多个服务 | 凭据可共存，退出一个不清除其他服务 |
| 同一个服务 | 保存最近登录的一种凭据 |
| 凭据存储 | 后端保存与使用；浏览器不保存，不读取已有密钥 |
| 失效 | 明确显示需重新登录，不自动重试模型调用 |
| 已配置 | 表示本地有凭据；未经过上游校验时不保证可调用 |

设置列表中 CSTOA 置顶，OAuth 服务直接展示，其余可折叠。筛选按支持方式匹配，双方式服务进入两个结果。登录后仍保留配置入口。

## 页面与返回

| 页面 | 行为 |
|---|---|
| `/settings/provider` | 按 `provider` 与 `method=oauth|api_key` 配置，成功返回 `/settings#accounts` |
| `/login` | 固定 `cstoa / OAuth / APIKEY` 三个入口；cstoa 专属扫码，其他两项按 Pi 服务能力列出选项；返回允许的来源页 |
| 返回、取消、Esc | 结束当前授权，保留已有凭据；下拉打开时先关下拉 |
| 服务与方式切换 | 取消离开的授权流程；其他方式入口不因当前服务的能力而禁用，切换时选对应服务 |

登录成功按实际完成的服务与方式决定去向：CSTOA OAuth 返回 `/account`；从 CSTOA 入口切换到其他 OAuth 或 API KEY 后，原账号返回地址改为 `/settings#accounts`。普通入口的其他合法返回地址保持不变。取消、关闭和 Esc 仍返回原来源页，不使用成功跳转规则。

## OAuth

1. 按钮打开授权窗。支持本机回调的服务由 Pi 接收回调、交换并保存凭据；服务器确认成功后关闭本页打开的授权窗，原页面返回来源页。
2. 浏览器可能拦截弹窗或由供应商切断窗口引用；此时使用普通新标签页，原页面仍自动接收成功结果。浏览器窗口聚焦由浏览器策略决定。
3. 本机回调服务的回贴输入收在「手动输入」，用于跨机器授权或回调不可达；需要手动授权的服务直接显示该字段。
4. 设备码授权显示二维码、授权码与有效期。授权完成后后端轮询确认，无需手动提交。
5. 服务要求的账号、组织等选择仍须用户回答。过期步骤不能提交或取消新的流程。
6. 同一服务只运行一条授权流程；API KEY 登录、退出服务和停止 Web 均取消其待授权流程。

接口状态为 `idle`、`pending`、`succeeded`、`failed`、`cancelled`，状态带 `flowId` 与递增 `revision`。只接收当前流程且不早于已接收版本的数据；授权页显示成功不等于本地凭据已保存。

## API KEY

可预填 APIKEY，也可直接按 Pi 请求的步骤填写。一次密钥输入、账号 ID、网关 ID、登录方式选择与其他凭据交互都由 Pi 提供，Web 只展示步骤；秘密字段使用密码输入框，不写浏览器存储。

自定义服务地址可选，启用后地址必填；接受 HTTPS 或本机 HTTP。沿用所选服务的模型与协议；失败或取消时恢复原配置，不创建新模型。提交步骤期间禁用重复提交，成功后返回来源页。

## 启用模型

- 可用清单沿用 Pi `getAvailable()`，包含持久凭据、配置和环境变量。TUI 与 Web 共用 `settings.json`、`models.json`、`models-store.json` 和 `auth.json`，各端下次进入时读取已保存变更。
- 设置页已启用项置顶，顺序用于模型循环；输入框只列 scoped 范围，按保存顺序展示，不追加范围外当前模型，不显示比例计数。
- 修改后保存才生效；全选作用于全部搜索匹配项。
- 默认预览部分条目，可展开、收起；不可用的已保存模式明确标出。
- 全部启用或空范围提交恢复 Pi 默认范围，空选择时按钮为「恢复默认」。

## 当前模型与默认模型

| 操作 | 当前会话 | 新会话默认 |
|---|---|---|
| TUI 直接 `/model provider/id` 或选择器 Enter | 更新 | 保持 |
| TUI 模型选择器 Ctrl+S | 更新 | 保存 |
| Web 工作区选择模型 | 更新 | 保存 |
| Web 首页选择模型 | 不创建会话 | 保存 |

正在打开的会话保留当前模型身份。菜单、循环与下一次输入会重读目录、范围和凭据；服务地址更新作用于后续模型请求，不中断正在进行的调用。单模型范围循环会选中该模型，禁止继续循环到范围外；显式 CLI `--models` 范围优先。

共享配置损坏时给出文件类别与修正提示，修正后重读恢复。错误响应不包含配置原文、密钥或令牌。

## 专属账号

`/account` 只管理 CSTOA。账号退出只清除 CSTOA，其他服务保持登录。学号、姓名和额度未接入时显示明确占位，不填虚构身份或零额度。

## 验收

- 原生 Pi 回调完成登录且保存凭据，不依赖回贴；无效 state 不完成登录。
- 取消、旧步骤、断线恢复与凭据替换不误写新流程。
- 授权窗不保留 opener，凭据不进入浏览器存储或响应。
- 弹窗拦截与跨源隔离不影响原页面更新；真实供应商登录另行联调。
