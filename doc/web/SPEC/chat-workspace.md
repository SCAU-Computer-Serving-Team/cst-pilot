# 聊天工作台

本页定义消息呈现、过程折叠、图片、队列与恢复。命令见[命令规格](commands.md)，工具见[诊断卡片](diagnostic-cards.md)，实现见[流式设计](../../design/web/streaming.md)，视觉规则见 [DESIGN.md](../../../DESIGN.md)。

## 侧栏与会话列表

| 项 | 行为 |
|---|---|
| 侧栏 | 可收起并记忆；半屏默认收起，以浮层展开，导航后收起 |
| 日期分组 | 今天、昨天、一周内、更早，按自然日差划分 |
| 排序 | 按最后条目时间倒序；缺时间的空会话放末尾 |
| 主页 | 会话列表、欢迎语与新会话输入框，不显示会话内容 |

## 对话流

按模型实际输出顺序展示，同一轮可包含多条助手消息。

| 内容 | 呈现与操作 |
|---|---|
| 用户消息 | 右侧气泡，保留正文与图片 |
| 思考 | 折叠仅显示「已思考」，展开完整正文 |
| 工具 | 计数行和卡片按下节折叠 |
| 联网检索 | 独立状态行，展开关键词 |
| 正文 | Markdown；代码高亮、表格、链接；外部链接在新标签打开 |
| 末尾操作 | 复制、派生、导出与时间；只在本轮最后一条助手消息上出现 |
| 消息菜单 | 分支树入口，不显示未提供的分享 |
| 分支总结 | 独立折叠块、时间与原文；行为见[分支总结](branch-summary.md) |

## 过程折叠

一轮包含一条用户消息及后续助手消息。最后正文保持可见，中间正文、思考与工具属于可折叠过程。

| 状态 | 行为 |
|---|---|
| 运行中 | 过程区展开，显示「工作中 N 秒」 |
| 完成 | 保留同一个过程头并更新为「已工作 N 秒」，自动折叠；纯正文回复也保留工作时长，用户手动操作后保持其选择 |
| 历史 | 保留完成时长，默认折叠，耗时按条目时间近似 |
| 尚无助手内容 | 显示等待指示 |
| 停止或树导航 | 旧轮次不继续显示运行状态 |

## 工具调用的折叠

| 层 | 规则 |
|---|---|
| 计数行 | 连续普通工具收为「已完成检查 · N 次工具调用」，默认折叠 |
| 工具行 | 展开计数行后逐工具展示状态 |
| 卡片 | 参数未齐不可展开；结果到达后自动展开，历史默认折叠 |

`sys overview`、`runbook`、`web_search` 不进入普通计数行。前两者独占并自动展开，检索仅展开关键词；`read` 图片先显示图片再显示路径。工具区域与内部缩进见 [DESIGN.md](../../../DESIGN.md#尺寸与间距)。

## 图片

| 项 | 规则 |
|---|---|
| 添加 | 选择或粘贴；读取中禁止发送未完成批次 |
| 格式 | PNG、JPEG、GIF、WebP |
| 预算 | 单次原始字节合计最多 12 MiB，不另限张数 |
| 浏览 | 输入框上方横排缩略图；点击看大图，悬停或聚焦可删除 |
| 接受 | 后端保存图片后才确认消息接受；失败保留草稿 |
| 回收 | 删除、成功发送与启动时清理无引用字节；不删除其他存活页或异步写入引用 |
| 刷新 | 同页草稿恢复；关闭后的短暂刷新宽限保留引用 |

浏览器存储不可读、引用损坏或无法核实其他页面引用时暂停删除。存储、锁与回收算法见[图片与草稿设计](../../design/web/runtime.md#图片与草稿)。

## 排队与插队

后端确认的排队项显示在输入框上方；已直接投递的消息不进入队列列表。规则见[输入收件箱](session-runtime.md#输入收件箱)。

| 操作或状态 | 行为 |
|---|---|
| 插话 | 将未投递项改为下个安全边界投递，不停止当前输出 |
| 编辑、删除、排序 | 后端确认后更新；不能修改已投递项 |
| 暂停 | 显示暂停状态，提交新消息后继续 |
| 失败 | 显示投递失败；问号悬停或聚焦显示保存的原因 |
| 模型调用失败 | 已投递状态保持，错误放助手回答中 |

## 编辑器与中断

添加图片、模型、上下文和思考强度为常驻控件，不提供工具选择。模型决定可选思考档位；上下文环按占比显示并可打开用量面板。

| 键或状态 | 行为 |
|---|---|
| Enter | 提交；补全打开时选中选项 |
| Shift+Enter | 换行 |
| 输入法组合中 | Enter 只选词 |
| Esc | 先关闭补全，否则停止当前会话 |
| 正在执行且输入为空 | 发送键改为停止 |
| 正在执行且有输入 | 发送追加消息，由后端决定排队 |

DeepSeek 用量面板可显示余额，OpenCode Go / Go Plus 显示用量窗口；其他服务不显示额度区。查询失败保留原因。

## 状态恢复

| 状态 | 恢复规则 |
|---|---|
| 草稿与未发送图片 | 同标签页、同会话刷新恢复，其他页面不继承 |
| 队列、历史与已接受图片 | 从后端恢复，各页面共享 |
| 正在生成 | 恢复状态与事件订阅，不重复提交 |
| 滚动位置 | 不恢复 |

## 动效与滚动

实时内容按 DESIGN 令牌呈现；历史与减少动效时不播放非必要动画。滚动区域铺满主区，用户上翻后停止自动跟随，显示「回到底部」；返回底部后恢复跟随。

## 验收

覆盖过程折叠、工具状态、Markdown、图片、补全和队列；刷新不丢已接受输入。检查输入法不误发送、跨页图片不误删、停止只作用于当前会话。具体测试入口见[测试指南](../../test/README.md)。
