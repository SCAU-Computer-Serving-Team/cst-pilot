本文定义聊天工作台里除命令以外的呈现与交互。命令与输入框补全见[命令与功能对应](commands.md)，工具卡片见[诊断卡片](diagnostic-cards.md)，地址见[页面地址与接口设计](app-router.md)，视觉取值见 [DESIGN.md](../../../DESIGN.md)。

## 对话流

一轮回答由这些部分组成，按出现顺序排。

| 部分 | 呈现 |
|---|---|
| 用户消息 | 气泡，右对齐 |
| 思考 | 一行状态「已思考 · 摘要」，可展开看完整思考 |
| 工具调用 | 折叠成一行摘要，见下节 |
| 联网检索 | 一行状态「正在联网检索…」加检索关键词，运行时带转圈 |
| 正文 | 按 markdown 渲染，代码块做语法高亮，表格渲染成表格，链接在新标签页打开 |
| 消息末尾操作条 | 助手消息末尾一条：复制、分叉（从该回答另起分支）、导出；右端显示消息时间（如 19:35）。不做点赞与点踩 |
| 消息菜单 | MVP 暂不显示；分享未进入当前范围 |

长会话不能一次渲染全部消息。

滚动跟随：用户往上翻时停止自动跟随，出现「回到底部」按钮。回到底部后恢复跟随。

## 工具调用的折叠

工具调用按三层折叠，逐层向下展开。层级画布见 `src/web/design/cst-pilot-tools.pen` 的「工具调用 · 折叠层级 浅色」。

| 层级 | 内容 | 运行中 | 完成段 |
|---|---|---|---|
| 第 1 层 · 计数行 | 一行显示当前被折叠的调用数 | 正在调用多个工具… | 已完成检查 · N 次工具调用 |
| 第 2 层 · 工具行 | 每个被折叠的工具一行 | 正在调用 `disk` 工具… | 同左 |
| 第 3 层 · 卡片 | 单个工具的完整卡片 | 见[诊断卡片](diagnostic-cards.md) | 同左 |

各层文字的字号按 [DESIGN.md 的输出正文四层](../../../../DESIGN.md#工具调用卡片) 取值：计数行与回复正文同为第 1 层，工具行与卡片状态行同为第 2 层，卡片内容组为第 3 层，原文块为第 4 层。

规则：

1. 第 1 层默认折叠，第 2、3 层由用户逐层展开。
2. 第 3 层在结果返回后自动展开；历史回放默认折叠。
3. `sys overview` 与 `runbook` 打断折叠：单独占一行，自动展开，不进计数行。`web_search` 不进入折叠：单独占一行的联网检索行，属输出正文第 1 层（16px），展开仅显示传入关键词（12px），不弹出返回内容，例外画布见 `cst-pilot-tools.pen` 的「工具调用 · web_search · 例外」。

## 图片

未发送图片按内容 hash 保存在浏览器 IndexedDB，以 object URL 渲染。发送时将图片交给后端；后端把已接受的图片随会话或受管附件持久化，供模型、队列和历史回放使用。删除会话时按引用清理附件。

| 项 | 规则 |
|---|---|
| 草稿存储 | IndexedDB 保存字节，标签页分别维护草稿引用；启动时根据全部有效引用回收未使用图片 |
| 提交 | 选中与粘贴都支持。发送时随消息提交，后端确认已保存图片后才确认消息接受 |
| 浏览 | 输入框上方横向排列缩略图；悬停时显示删除按钮，点击看大图 |
| 多图 | 只做横向排列，不做画廊与多图对比 |
| 格式 | 白名单 `png` / `jpeg` / `gif` / `webp` |
| 体积 | 不限单张，限一次选择的合计；读取时预算递减，超预算即停 |
| 数量 | 按合计预算控制，不另设张数上限 |

## 排队与插队

会话正在执行时提交的消息进入队列。排队项以**聊天框上方的弹出组件**呈现，每条一行。

| 操作 | 说明 |
|---|---|
| 插话 | 将尚未投递的排队项改为插话，在下一个允许的模型调用边界投递；当前输出不中断 |
| 编辑 | 修改尚未投递的条目，由后端确认 |
| 删除 | 删除尚未投递的条目 |
| 排序 | 拖动调整尚未投递条目的顺序，由后端确认 |

| 情况 | 规则 |
|---|---|
| 主动停止 | 队列暂停，再提交一条才恢复 |
| 一条失败 | 卡在该条，不跳过 |
| 排队项归属 | 属于后端，不属于页面。刷新或切换页面不丢 |

队列本身的行为见[输入收件箱](session-runtime.md#输入收件箱)。

## 中断

发送按钮在会话执行且**输入框为空**时变成停止按钮。输入框有内容时按钮仍是发送，因为这时点它是插话或排队。

`Esc` 与停止按钮是同一个动作。停止不改变模型与思考强度的选择。

## 编辑器

| 部分 | 内容 |
|---|---|
| 占位文字 | 「继续提问，或补充这台电脑的情况…」 |
| 操作栏 | 添加附件、模型、思考强度、发送或停止键。**不提供工具选择入口**，工具由模型自己决定调用 |
| 模型选择器 | 带上下文进度环。环按用量占比填充，接近上限时改用警告与危险色，不写数字 |
| 下方提示 | 发送快捷键、结果核验提示「诊断建议仅供参考，请结合设备实际情况核验。」 |

文本编辑用浏览器原生行为，不复制 TUI 的按键。

| 键 | 行为 |
|---|---|
| `Enter` | 提交 |
| `Shift` + `Enter` | 换行 |
| 输入法组合中 | `Enter` 只用于选词，不提交 |

命令补全见[命令与功能对应](commands.md#输入框的交互)。

## 状态恢复

| 对象 | 恢复规则 |
|---|---|
| 草稿与未发送的图片 | 同一标签页刷新后恢复；其他标签页或浏览器不继承该页草稿，见[前端工程](frontend.md#状态归属) |
| 排队项与已提交图片 | 从后端恢复；其他标签页或浏览器可查看，页面关闭不影响已接受输入 |
| 滚动位置 | 不恢复 |
| 正在输出的正文 | 靠事件流续传补齐，见[接口约定](app-router.md#约定) |
