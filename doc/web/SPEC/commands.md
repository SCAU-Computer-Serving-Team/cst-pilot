# 命令与功能对应

状态：逐条已定。更新：2026-09-23。

本文定义 TUI 内置命令在 Web 端的承载方式，或者否决。地址见[页面地址与接口设计](app-router.md)，会话操作见[会话运行与并行](session-runtime.md)，视觉取值见 [DESIGN.md](../../../DESIGN.md)。

总原则：**Web 沿用 TUI 的工具权限。`/web` 启动后，TUI 进入待机，不再承载会话操作。**

## 两条通道

TUI 的 `/` 命名空间里有两类东西，实现路径不同。

| 通道 | 覆盖 | 前端行为 | 后端行为 |
|---|---|---|---|
| 命令道 | 内置命令 | 解析成对应接口调用 | 调 SDK 或 API |
| 消息道 | `/skill:<name>` | 提交技能指令与后续输入 | `prompt()` 内部展开技能正文 |

**命令道不允许把字符串当消息提交。** `/new`、`/settings` 这类字符串在 `AgentSession.prompt()` 下会被当普通消息发给模型。依据见 [Pi 能力清单](../research/pi-capability.md#内置命令与可用-api)。

## 承载方式

一条命令可以有多个承载方式。

| 承载方式 | 落点 | 交互特征 |
|---|---|---|
| 斜杠命令 | 输入框上方的补全面板 | 选中后在输入框内嵌为行内标记（图标 + 名称，悬停可移除），不立即执行，文字与标记同排继续输入再提交 |
| 会话末尾按钮 | 消息流末尾的操作条 | 针对整场会话的一次性动作 |
| 界面控件 | 侧栏与输入框周围的常驻控件 | 打开菜单、面板或就地编辑 |
| 独立视图 | 占地址的页面 | 有独立布局与地址 |
| 不单独承载 | — | 由其他机制覆盖，或不需要 |
| 否决 | — | Web 端不提供 |

## 逐条对照

| 命令 | 承载方式 | 备注 |
|---|---|---|
| `/new` | 界面控件 | 侧栏「新建」 |
| `/resume` | 界面控件 | 侧栏会话列表 |
| `/name` | 界面控件 | 侧栏会话右键菜单改名 |
| `/model` | 界面控件 | 输入框旁的模型菜单 |
| `/thinking` | 界面控件 | 与 `/model` 同一菜单 |
| `/scoped-models` | 界面控件 | 设置视图内的「启用模型」分区 |
| `/logout` | 界面控件 | 账号菜单 |
| `/compact` | 斜杠命令 | 后续输入作为压缩的额外提示词 |
| `/skill:<name>` | 斜杠命令 | 后续输入追加在技能正文之后。当前 7 条：disk、driver、eventlog、ls、runbook、startup、sys |
| `/fork` | **会话末尾按钮 + 斜杠命令** | 两个入口都打开「派生选择」面板：列出本会话全部用户消息，默认选中最后一条；确认后新会话在所选消息之前分支，消息文本预填新会话的输入框，可修改后再发送（对齐 TUI `/fork` 的选消息行为）。会话执行中禁止派生，空会话给空态 |
| `/copy` | 会话末尾按钮 | 用浏览器剪贴板，回环地址算安全上下文 |
| `/export` | 会话末尾按钮 | 即下载 |
| `/share` | 暂不提供 | 当前无入口与接口，见[分享](session-runtime.md#分享) |
| `/tree` | **独立视图 + 斜杠命令 + 界面控件** | 地址 `/s/<id>/tree`，见[分支树](branch-tree.md)。斜杠命令在补全面板选中即跳转（点选或回车都算选中，不折叠成标记）；界面控件是消息菜单的「分支树」项 |
| `/settings` | 独立视图 | 地址 `/settings` |
| `/login` | 独立视图 | 地址 `/login`；支持 OAuth 与 API KEY 两种方式，与 pi 的 `/login` 一致，共用登录状态展示 |
| `/session` | 不单独承载 | 会话元数据与统计由[仪表盘](dashboard.md)承载 |
| `/clone` | 不单独承载 | `/fork` 等价 |
| 提示词模板 | 否决 | Web 端不做 |
| `/reload` | 否决 | 重载会重建扩展实例，而 Web 服务器与 Web runtime 是第二套，跨两套的语义不清晰。现场不改配置，开发期重启 pi |
| `/trust` | 否决 | 项目定位决定 `defaultProjectTrust=never` 常关，不在 Web 暴露 |
| `/import` | 否决 | 会话列表已覆盖本机全部会话，导入外部 JSONL 是低频需求 |
| `/hotkeys` | 否决 | TUI 的快捷键表在 Web 上没有对应。Web 自己的表见 [Web 快捷键](#web-快捷键) |
| `/debug` | 否决 | 内核没有公开 API |
| `/changelog` | 否决 | 版本号在设置视图显示，不做变更记录视图 |
| `/quit` | 否决为斜杠命令 | 退出 Pi 会结束所有 Web 会话；浏览器关闭页面不退出程序。独立退出入口及运行中任务的处理待验证 |
| Ctrl+P 模型循环 | 否决 | Web 有模型菜单，不需要循环键 |
| `!cmd` / `!!cmd` | 否决 | 不提供 shell 直通。工具权限与 TUI 一致，不额外开执行通道 |

## 输入框的交互

| 触发 | 行为 |
|---|---|
| `/` | 弹出补全面板：定宽 400，左对齐悬浮于输入框上方；每项一行 = 图标 + 名称（定宽列）+ 紧邻名称的说明；选中行有底色；面板底部给快捷键提示 |
| `@` | 同一份面板规格，列出最近文件：图标 + 文件名 + 紧邻的路径 |
| Tab | 补全命令。与 `/` 同一份列表 |

选中后命令内嵌为输入框行内标记（图标 + 名称，悬停可移除），**不立即执行**，文字与标记同排继续输入，再提交。

| 命令 | 后续输入的含义 |
|---|---|
| `/compact` | 压缩的额外提示词 |
| `/skill:<name>` | 技能正文之后追加的对话内容 |
| `/fork` | 打开派生选择面板，不折叠成标记 |
| `/tree` | 选中即跳转分支树视图，不取后续输入，也不留标记 |

`@` 文件引用不是命令，但用同一套内嵌交互：选中后变成行内标记（`@` 随消息序列化回正文一起提交）。

补全列表来自启动快照的可用命令。**命中已知命令名才走命令道**，以 `/` 开头但不匹配任何命令时按普通消息提交，避免把路径这类内容误当命令。

## Web 快捷键

只覆盖输入框内的高频动作，其余操作都用可见控件。浏览器原生的文本编辑键不列。输入法组合中的 `Enter` 不提交、不选中。

| 键 | 行为 |
|---|---|
| `/`、`@` | 打开命令、文件引用补全面板 |
| `Tab` | 补全命令，与 `/` 同一份列表 |
| `↑` `↓` | 在补全面板中移动选项，循环，自动滚动到可见 |
| `Enter` | 补全面板打开时选中当前项，否则提交 |
| `Shift` + `Enter` | 换行 |
| `Esc` | 补全面板打开时先关面板并回输入框，否则停止当前执行 |
