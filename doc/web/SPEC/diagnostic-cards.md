# 诊断卡片

本页定义工具结果的状态与呈现要求。字段来源见[结果映射](../../design/web/tool/mapping.md)，逐工具模板见[工具设计](../../design/web/tool/README.md)，视觉规则见 [DESIGN.md](../../../DESIGN.md#工具调用卡片)。

## 覆盖范围

| 来源 | 工具 |
|---|---|
| 诊断扩展 | disk、driver、eventlog、ls、runbook、startup、sys |
| pi-web-access | web_search、source_check、fetch_content、get_search_content |
| pi-fff | ffgrep、fffind |
| Pi 内置 | read；内置 ls 由诊断扩展覆盖 |

实时与历史使用相同映射。每次调用关联参数、状态、耗时与结果；保留有效结果和解释数据所需的说明。

## 结构与交互

| 内容 | 呈现 |
|---|---|
| 状态行 | 状态、工具与耗时，可展开 |
| 结构化内容 | 概览字段、排行与提示条 |
| 原文 | 长文本、代码与日志；可查看原始数据 |
| 命令清单 | 环境、说明、命令及复制；写入失败不标为已交付 |
| 图片 | 支持的结果图片与路径 |

参数未齐时不可展开。运行中可展开查看已有信息，不显示虚构进度；结果到达后自动展开，历史默认折叠，用户折叠后保持选择。普通分组与例外规则见[工具调用的折叠](chat-workspace.md#工具调用的折叠)。

命令卡片表示该次调用内容；后续修正清单不替换历史卡片。

## 状态要求

| 情况 | 要求 |
|---|---|
| 成功 | 展示有效结果与必要口径 |
| 运行中、中断 | 保留状态和已有结果，不标为已完成 |
| 整次失败 | 显示失败原因，不能当正常 JSON |
| 部分失败、权限不足 | 保留成功字段，显示降级与采集错误 |
| 缺失或空结果 | 结合错误判断，不自动当作正常或零值 |
| 截断 | 标出范围与截断，不将局部列表视为全部 |
| 无法解析 | 回退原文，不丢失已开放工具的结果 |

大结果应限制首屏工作量，保证展开和滚动响应。模型文本、details 和界面内容各有用途，字段语义以[工具文档](../../tool/README.md)为准。

## 验收

14 个工具均有映射或明确原文回退。覆盖成功、参数流入、运行、停止、整次失败、部分降级与截断；验证实时和历史的同一结果含义一致。
