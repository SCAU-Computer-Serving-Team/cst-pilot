# 诊断卡片

状态：渲染规则与展示要求已定，内容块缺口待补。更新：2026-09-22。

工具调用按卡片呈现。视觉值与画布在 [DESIGN.md](../../../DESIGN.md#工具调用卡片) 与 `src/web/design/cst-pilot-tools.pen`。工具清单见 [PRD](../../PRD.md)，字段语义见[工具文档](../../tool/README.md)。

## 卡片结构

所有工具卡共用一套结构。画布提供概览组、排行组、原文块三种主模板，展开区域按结果选择。

| 骨架 | 内容 |
|---|---|
| 状态行 | 状态图标、调用语句、调用目的、耗时 |
| 展开内容 | 由下方内容块组合 |
| 原始数据切换条 | 展开原始数据 |
| 高度指示线 | 高度信号 |

| 内容块 | 结构 |
|---|---|
| 概览组 | 分组标题 + 若干字段行 |
| 字段行 | 字段名 + 字段值 |
| 排行组 | 若干排行行 |
| 排行行 | 名称 + 指标 |
| 原文块 | 密集长文 |
| 命令组 | 命令条目：环境与说明 + 命令 + 复制按钮 |

画布上三张通用卡分别以概览组、排行组、原文块为主。各卡可追加其他内容块。`sys overview` 与 `runbook` 沿用同一骨架，分别增加醒目展示和命令组。

## 数据来源

卡片按 `toolCallId` 关联调用参数、结果 `content`、可选 `details` 与 `isError`。实时执行和历史回放使用同一组映射规则。

卡片要覆盖当前开放的全部工具，不只是诊断工具。

| 来源 | 工具 |
|---|---|
| 诊断扩展 | `disk`、`driver`、`eventlog`、`ls`、`runbook`、`startup`、`sys` |
| pi-web-access | `web_search`、`source_check`、`fetch_content`、`get_search_content` |
| pi-fff | `ffgrep`、`fffind` |
| Pi 内置 | `read`；内置 `ls` 已被诊断扩展覆盖，其他内置工具未开放 |

| 数据 | 读取规则 |
|---|---|
| 诊断结果 | 优先读取 `details`，按工具与 scope 映射，字段语义见[工具文档](../../tool/README.md) |
| runbook 命令组 | 环境、说明与命令来自该次调用的 `items` 参数；文件路径、序号、条数和写入结果来自 `details.runbook`。写入失败时不显示为已交付 |
| 通用工具或缺少 details | 展示 `content` 与错误状态，不假定文本必为 JSON |
| 历史回放 | 读取会话原始条目，关联调用与 `toolResult`。`buildSessionContext()` 仅保留压缩后的模型上下文 |
| 结果大小 | 诊断工具的模型 JSON 最多 50 KiB，`details` 保留完整采集结果；其他工具按自身格式处理 |

命令组表示该次调用的内容。清单后来按同一序号修正时，历史卡片不自动替换为新内容。

## 渲染规则

| 项 | 规则 |
|---|---|
| 模板 | 内容块覆盖全部工具形态，不为单个工具另立卡片 |
| 字段 | 按内容块动态生成，取合适长度，不按工具写死 |
| 参数流入中 | 不能展开，参数还没齐 |
| 参数齐了、正在执行 | 可以展开。状态行显示等待指示与实时耗时，**不做进度条**（未提供可量化进度时），取消走停止键 |
| 结果返回 | 自动展开 |
| 历史回放 | 默认折叠。用户手动折叠后保持折叠 |
| 思考过程 | 默认折叠 |
| 同类合并 | 连续段折叠成一行「已完成检查 · N 次工具调用」，展开后是本段的卡片。见[聊天工作台](chat-workspace.md#工具调用的折叠) |
| 例外卡片 | `sys overview` 与 `runbook` 打断折叠，单独占一行，自动展开；状态行按输出正文第 1 层 16px 呈现，展开卡仍为 12px |
| 大结果 | 按事件流送达，用长列表虚拟滚动渲染 |

## 展示要求

| 情况 | 要求 |
|---|---|
| 成功 | 展示有效结果，以及解释数据口径所需的说明 |
| 执行中或中断 | 保留当前状态和已有结果，**不能显示为已完成** |
| 整次失败 | 展示 `isError` 与失败原因。不能假定每次返回都是正常业务 JSON |
| 部分失败或权限不足 | 保留可用数据，同时展示 `notice`、`degraded`、采集错误等说明 |
| 缺失数据 | 根据错误和说明解释 `null`、空数组，不能一律呈现为正常或零值 |
| 输出截断 | 明确标注截断和统计范围，不把裁剪后的列表当作全部结果 |
| 暂无专用模板 | 提供通用结果展示，避免读取、检索或其他已开放工具的结果丢失 |

## 约束

模型的文本输出、事件的 `details` 与卡片数据三者用途不同，各工具返回的 JSON 包装结构也不统一。**三者不能假设同构**，卡片数据来源需要逐项定义。
