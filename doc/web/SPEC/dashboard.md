状态：页面结构与口径已定，画布已备。**不属 MVP，已排入计划**，MVP 之后实现。更新：2026-09-22。

设计稿在 `src/web/design/cst-pilot-web.pen` 的「仪表盘 · 浅色」（`tdc8d`）与「仪表盘 · 深色」（`v3B33`），宽 1920px、高 1925px，保留 264px 侧栏。视觉取值见 [DESIGN.md](../../../DESIGN.md)。字段可用性与采集边界见 [Pi 能力清单](../research/pi-capability.md#用量与费用字段)。

## 页面

| 区域 | 内容 |
|---|---|
| 筛选 | 供应商、模型、日期范围；默认近 14 天 |
| 概览 | Token 总量、模型调用数、按 CNY / USD 分列的估算费用、缓存命中率 |
| 趋势 | 按日堆叠柱，区分输入、输出、缓存读取、缓存写入；预留费用视图 |
| 日志 | 请求时间、模型与供应商、所属会话、输入、输出、缓存读写、估算费用、耗时与首个输出等待、结束状态 |
| 操作 | 搜索、状态与会话筛选、列设置、详情入口、CSV 导出、分页 |

## 计数口径

**一行表示主 Agent 的一次逻辑模型调用。** 会话与单次 HTTP 尝试都不作为计数单位，工具执行不另算模型调用。

| 字段 | 口径 |
|---|---|
| Token | 输入、输出、缓存读取、缓存写入。思考量已含在输出中，不再次相加 |
| 费用 | 模型价目表估算，不是网关账单 |
| 模型调用耗时 / 首个输出等待 | 按[契约时间字段](../../contract.md#时间)读取 `durationMs` / `ttftMs`；缺失时显示 `—` |
| 结束状态 | 完成、工具调用、达到上限、失败、取消 |
| 会话 | 本地关联。不据此把会话名纳入遥测上报 |

压缩、分支摘要及工具内部的模型调用不假定都经过同一组事件，扩展覆盖范围时需单独接入。

## 呈现规则

| 情况 | 规则 |
|---|---|
| 缺失 | 显示 `—`，**不补造** |
| 明确的零 | 保留为 `0` |
| 未配置有效价格 | 显示「未定价」，不显示 `$0.00` |
| 零价格 | 不自动表示免费 |
| 缓存命中率 | `cacheRead / (input + cacheRead + cacheWrite)`；分母为零时不计算 |
| 总量 | 按可用 usage 汇总；费用按币种分列，不合计不同币种 |
| 采集层 | 区分已报告、未报告与未知。失败时的零不一定代表已确认零用量 |

本页不替代[会话遥测](../../telemetry/README.md)，也不把其中未实现的字段当作已完成能力。信息收集契约见 [contract.md](../../contract.md)。
