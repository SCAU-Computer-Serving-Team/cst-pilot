# 前端规格

本页定义浏览器支持、导航、状态归属与界面约束。工程实现见[前端设计](../../design/web/frontend.md)，视觉规则见 [DESIGN.md](../../../DESIGN.md)，当前阶段见 [MVP](../MVP.md)。

## 浏览器基线

| 范围 | 要求 |
|---|---|
| MVP 现代版 | Windows 10/11 x64，Chromium 111 起，桌面浏览器 |
| 半屏窗口 | 支持 960px 宽窗口；侧栏浮层不挤压主区 |
| 兼容版 | Chromium 86，MVP 后单独实现和验证 |
| 分发 | 随便携包提供预构建页面，现场无需安装依赖或构建 |

不支持现代版的环境继续使用 TUI。最低版本、实际窗口与系统输入法的验证状态由 [MVP](../MVP.md) 管理。

## 导航

| 场景 | 行为 |
|---|---|
| 页面入口 | 地址见[地址空间](app-router.md#地址空间) |
| 切换会话 | 客户端导航，保留离开会话的任务 |
| 刷新、前进与后退 | 恢复地址所对应的页面与后端状态 |
| 复制地址或新标签打开 | 使用真实链接；地址只在本机服务运行时有效 |
| 未命中资源 | 明确失败，不以页面入口代替资源 |
| 深色主题首屏 | 首次绘制即使用已保存主题，无浅色闪烁 |

## 状态归属

| 状态 | 规则 |
|---|---|
| 历史、执行与队列 | 后端维护，各页面显示同一份状态 |
| 草稿与未发送图片 | 按标签页与会话隔离；同页刷新恢复 |
| 菜单、展开与滚动 | 页面局部状态，不改变执行事实 |
| 登录凭据 | 后端保存；浏览器只提交新凭据与读取状态 |
| 断线恢复 | 重取状态并恢复订阅，不自动重发已接受输入 |

## 用户可见的约束

| 项 | 要求 |
|---|---|
| 页面语言 | 中文；保留工具、模型与登录方式的名称 |
| 文案 | 控件足以表达操作时不加说明。保留状态、必要限制、失败原因与恢复入口；重复描述删除 |
| 错误 | 主提示说明可理解的原因；技术详情按需展开 |
| 失联 | 显示持续断线提示，恢复后撤下；避免无限转圈 |
| 长会话 | 输入和滚动保持响应，按需加载历史 |
| 输入 | 支持键盘、系统输入法、粘贴图片与文件引用；组合输入中的 Enter 不发送 |
| 动效 | 采用 DESIGN 令牌；主页与工作台双向切换，离开主页时背景沿主区中心左右滑出，中缝柔化，内侧先透明、外侧末段淡出，品牌原位淡出；返回主页保持背景与品牌从上方进入；输入框各自在原位下方入退场，页脚同步缓入；侧栏开关使主页内容连续重新居中，中途反向不跳位；按浏览器实际节奏运行，减少动态偏好下停用非必要动画 |
| 主题 | 默认跟随系统，可在设置与账号菜单中切换，保存到本机；账号菜单切换主题后保持展开 |
| 帮助 | 快捷键放设置，命令放补全，不设独立帮助页 |

图片、队列、停止与恢复见[聊天工作台](chat-workspace.md)，命令见[命令与功能对应](commands.md)。

## 打包接入

发行包只包含运行文件、静态产物与许可，不包含前端源码、测试、开发依赖或缓存。字体来源、子集、生成与校验见[字体分发](../../design/web/fonts.md)。发行副本仍需验证零安装启动与资源完整性。

## 验收

1. 六个 MVP 页面支持直接打开、刷新与前进后退，浅深视觉对应画布。
2. 半屏无横向溢出，导航与任务相互独立。
3. 键盘和输入法不误发消息；可见控件具有可访问名称与焦点状态。
4. 断线与写失败有明确状态，恢复不重复执行。
5. 静态资源与字体由发行清单校验；现场无需开发环境。
