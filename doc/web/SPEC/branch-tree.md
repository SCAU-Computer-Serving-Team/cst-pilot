# 分支树

本页定义 `/s/<id>/tree` 的行为与结构语义。几何算法与 Pi 对照测试见[分支树实现](../../design/web/branch-tree.md)，视觉规则见 [DESIGN.md](../../../DESIGN.md)。

## 入口

| 入口 | 行为 |
|---|---|
| `/tree` 补全 | 选中即跳转，不留命令标记 |
| 消息菜单 | 「分支树」进入当前会话的树页 |
| 直接地址 | 支持刷新与前进后退 |
| 关闭或 Esc | 返回 `/s/<id>`；下拉打开时先关闭下拉 |

## 数据与导航

| 接口 | 用途 |
|---|---|
| GET `/api/sessions/<id>/tree` | 读取条目树与当前叶 |
| POST `/api/sessions/<id>/tree/navigate` | 导航到指定条目，选择语义见[分支总结](branch-summary.md) |

条目父子关系、当前叶与导航结果遵循 Pi。选中用户消息时当前位置移到其父条目，正文回填输入框；选中其他条目时移到该条目。生成中导航先停止当前生成，保留队列；压缩期间拒绝导航。

## 可见条目

| 过滤 | 保留范围 |
|---|---|
| 默认视图 | 消息、工具结果、压缩、分支总结等；隐藏设置类条目 |
| 无工具 | 默认视图再隐藏工具结果 |
| 仅用户 | 用户消息 |
| 仅标记 | 有标记的条目 |
| 全部 | 包括设置类和工具结果 |

设置类为 `label`、`custom`、`model_change`、`thinking_level_change`、`session_info`。无正文 assistant 在各档隐藏，错误、中止与当前叶除外。隐藏条目的子条目接到最近的可见祖先；几何结构以可见树为准。

先按原始树做深度优先排序：当前路径子树优先，其余按时间。过滤保留该次序，隐藏当前叶或重挂后代时不重新按后代时间排序。过滤选择持久化，换档清空折叠集合。

## 几何语义

| 标记 | 含义 |
|---|---|
| 方框 | 某个可见分叉的子分支入口，同级入口使用同一列 |
| 竖线 | 当前分支后面还有同级分支；仅在非末位子树内延续 |
| 缩进 | 分叉与分支段落层级，单子链保持同级 |
| 行底色与「当前位置」 | 当前叶条目 |
| 行尾展开控件 | 折叠或展开该段全部可见后代 |

同一列可被不同分叉复用，方框总数不能直接视为某个分叉的数量。多个可见根之间不画虚拟根连接符，各根内部的真实分叉仍绘制。结构标记不表示消息角色、执行状态或工具依赖。

方框与竖线表达分支范围，连续的父子关系不逐条绘线。当前位置与祖先路径是不同的信息；当前页面标出当前位置，Pi TUI 另外标出完整活动路径。

## 行内容与折叠

| 条目 | 内容 |
|---|---|
| 用户、助手 | 角色与正文摘要；图片消息或无文本错误有明确占位 |
| 工具结果 | 工具名与结果摘要；无结果时使用参数摘要 |
| 压缩 | 压缩前 token 数 |
| 分支总结 | 总结摘要 |
| 设置类 | 类型与相关值，按过滤规则展示 |

摘要单行截断。可折叠行须有可见子条目，并位于根或分支段首；折叠隐藏全部可见后代，显示隐藏数量。全部展开、折叠作用于全部可折叠行。

## 操作

1. 点击或 Enter 选择条目。选择当前叶时仅提示当前位置未改变；其他条目进入三选项确认。
2. ↑/↓ 移动游标，Ctrl+O 循环过滤，Shift+Ctrl+O 反向。输入框、下拉与确认卡片优先接管按键。
3. 搜索按摘要、标记与角色匹配；显示匹配条目，不改变后端树或当前叶。

## 验收

- 同一棵树与 Pi 对照可见行、排序、缩进、方框列、竖线列与折叠范围。
- 覆盖单子链、嵌套分叉、多根内部的分叉、隐藏条目重挂、隐藏当前叶与隐藏祖先的排序。
- 导航、总结、取消及生成中导航使用真实 Pi 会话测试。
- 几何一致与首次使用者的理解度分别验证；自动测试不替代用户理解测试。
