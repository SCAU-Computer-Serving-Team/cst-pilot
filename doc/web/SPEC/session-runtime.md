# 会话运行与并行

本页定义 Web 接管、并行、输入队列与数据边界。地址见[接口规格](app-router.md)，实现见[运行设计](../../design/web/runtime.md)，待验证范围见 [MVP](../MVP.md)。

## 产品要求

TUI 负责启动；执行 `/web` 后留在原进程待机，会话操作由 Web 承担。历史、配置与凭据共用隔离 home。

| 场景 | 行为 |
|---|---|
| 页面切换、刷新、断连或关闭 | 不取消正在执行的会话，不重发已接受输入 |
| 多个会话运行 | 消息、上下文、队列与取消相互隔离 |
| 返回会话 | 读取最新历史与执行状态 |
| 停止 | 只停止指定会话，不影响其他会话 |
| 数据事实 | 历史、执行与队列由后端维护，浏览器管理未提交草稿与展示 |

## 写权与会话串行

每场会话只有一个写入实例，同时只执行一轮。多个 Web 页面可以查看和提交到同一会话，按后端确认顺序执行，任何页面均可请求停止当前轮次。

1. `/web` 等待当前 TUI 任务结束。已保存会话先由 TUI 释放，再由 Web 接管；空会话由 Web 新建。
2. 有未落盘对话内容时拒绝切换并说明原因。被 TUI 或其他写入实例持有的记录不可再次写入。
3. TUI 待机输入不能发送消息、运行内置命令或退出程序。操作系统关闭宿主窗口仍会结束 Pi 进程。
4. 离开页面只取消该页订阅；运行中或有待处理输入的会话保持占用。释放前须停止写入并完成销毁。
5. 关窗通知不作为可靠的退出或释放依据；明确退出规则见[待处理议题](../../issues.md#1-承载与运行)。

## 会话可见性

Web 展示隔离 home 中已有的会话。新会话接受创建后立即具有创建时间并进入日期分组；首条消息、执行开始与结束、重命名、删除和派生触发侧栏同步。最新列表包含尚未落盘的会话名称与状态；过期请求不能覆盖新列表。

接管后由 Web 运行实例更新记录和状态，各浏览器读取同一份结果；TUI 留在待机会话，不修改 Web 运行中的记录。

## 共享状态

模型、凭据与设置在各会话间共用。会话之间共用扫描资源和命令文件目录时须协调访问，避免重复序号和状态覆盖；页面导航不得用于取消资源任务。

## 输入收件箱

后端先持久化接受消息并分配序号，再投递给模型。只有后端确认后页面才标为已接受。

| 提交方式 | 投递时机 |
|---|---|
| 直接投递 | 会话空闲且没有待处理消息 |
| 插话 | 下一个允许插话的模型调用边界，不中断当前输出 |
| 排队 | 运行中、暂停或已有待处理消息；空闲后每轮投递一条 |

| 情况 | 规则 |
|---|---|
| 重复提交 | 同一消息 ID 的会话、内容、图片与方式一致才算重试；只执行一次 |
| 编辑、删除、排序、插话 | 只作用于未投递项，后端确认；版本过期返回冲突 |
| 排序 | 默认接受顺序，拖拽后采用已确认的新顺序 |
| 停止 | 队列暂停，提交新消息后恢复 |
| 投递失败 | 停在失败项，不跳过；原因保存并通过快照与事件返回 |
| 后端重启 | 保留队列和图片，不自动重放未确认结果的请求 |
| 多会话 | 各自调度，A 的队列不阻塞 B |

工具调用只在后端执行一次，开始、进度和结果以 `toolCallId` 关联。输入中的技能指令通过专用命令语义展开，其他斜杠文本按普通消息处理。

## 能力范围

Web 覆盖本项目的会话、模型、凭据与设置操作，工具权限沿用 TUI。新增页面或修改设置均不能扩大后端开放的工具集合。

本版支持文本与图片，不提供文档解析、编辑重发或重新生成。命令覆盖与否决范围见[命令规格](commands.md)；额度、仪表盘安排见 [MVP](../MVP.md)。

## 验收

- 两场会话同时运行，停止一场不影响另一场；切页和关闭不取消执行。
- 两个页面提交顺序一致且不重复，旧队列版本不能覆盖新状态。
- 已接受消息和图片在重启后可恢复，不自动重放模型调用。
- TUI 待机覆盖内置命令、快捷键和窗口操作，交付物与未完成范围集中在 MVP。
