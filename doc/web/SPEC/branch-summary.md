# 分支总结

本页定义树导航时的选择、结果与取消。请求接线和画布状态见[分支总结实现](../../design/web/branch-summary.md)，入口见[分支树](branch-tree.md)。

## 选择

| 选择 | 结果 |
|---|---|
| 不总结 | 直接导航；目标为用户消息时正文回填输入框 |
| 总结 | 总结离开的分支后导航，完成后显示分支总结条目 |
| 用自定义提示词总结 | 返回聊天页收集提示词，提交后总结并导航 |

点击确认卡片外部、关闭按钮或 Esc 仅关闭卡片，不导航。↑/↓ 移动选项，Enter 确认；悬停同步选项位置。

## 状态流转

1. 选择「总结」或「用自定义提示词总结」后，地址携带 `branch=<entryId>&mode=summarize|custom`，刷新保留本次待办。
2. 「总结」直接开始请求；「自定义」在输入框显示标记，Enter 提交提示词。移除标记即放弃，不发送消息。
3. 生成中显示状态与取消入口，完成后由分支总结条目替代。
4. 导航实际完成前显示原分支；完成后更新当前位置与消息，并清除待办参数。
5. 取消后当前位置不变，不生成总结条目；失败保留原因与重试入口。

总结默认折叠，展开显示 Markdown 原文与原始换行。生成过程中不重复提交同一次导航。

## 接口

| 接口 | 请求 | 响应 |
|---|---|---|
| POST `/api/sessions/<id>/tree/navigate` | `{ entryId, summarize?, customInstructions? }` | `{ id, entryId, cancelled, editorText?, summaryEntryId? }` |
| POST `/api/sessions/<id>/tree/abort` | `{}` | `{ aborted: true }` |

总结与导航属于同一次操作。取消是正常结果，返回 HTTP 200 与 `cancelled: true`；取消只影响分支总结。导航前存在当前生成时先停止，排队消息保留；压缩期间拒绝导航。

## 与 TUI 的行为差异

| 项 | Web |
|---|---|
| 自定义提示词 | 在聊天输入框收集 |
| 用户消息回填 | 仅「不总结」回填；自定义输入框留给提示词 |
| 取消后 | 停在原位置，重新进入树页选择 |

## 验收

覆盖三种选择、刷新待办、移除标记、生成中取消及失败。确认取消不改变当前位置、不追加总结或普通消息；验证目标分支与总结内容一致。
