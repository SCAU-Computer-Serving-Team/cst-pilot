# 后台服务与运行协调规格

`server` 模块将业务运行时封装为三端共用的本机后台服务 `cst-server`，并配合启动器协调运行环境。模块负责单实例发现、通道读写门禁与多会话并发托管，同步维护持久化输入收件箱与跨端配置广播。内部实现见 [ARCHITECTURE.md](ARCHITECTURE.md)，专属控制接口与 SSE 帧协议见 [API.md](API.md)，详细子包设计见 [7.server.md](../rust/plan/7.server.md)。

## 启动提权与便携环境隔离

1. **启动器提权与环境净化**：正式便携启动器（当前由 `launcher.ps1` 承载，阶段 9–10 由原生软件端启动入口承接）校验管理员令牌并通过 Windows UAC 提权，拒绝授权时直接退出。启动器固定设置 `PI_CODING_AGENT_DIR=<工具包>/agent/home` 与 `PI_OFFLINE=1`，将 `TEMP` / `TMP` 重定向至 `.state/tmp/`，清除机主遗留密钥环境变量。
2. **独立调试模式**：直接运行 `cst-server --standalone-web`（如 `pi-web-rust.cmd`）时跳过 UAC 提权，按当前终端权限启动服务并如实报告权限受限状态。
3. **单实例互斥**：同一工具包数据目录同一时刻仅允许运行一个 `cst-server` 进程，仅监听回环地址 `127.0.0.1`（默认端口 `52831`，支持按需动态分配空闲端口）。

## 通道门禁与生命周期协调

后台服务将软件端存活状态（`AppPresence`）与操作通道模式（`ChannelMode`）正交分离，防止软件端断线重连覆盖当前激活通道：

| 状态或场景 | 行为要求 |
|---|---|
| 默认软件端模式（`AppActive`） | 软件端（桌面端与内置 TUI）拥有完整读写权限。浏览器仅可访问静态资源与基础状态，访问会话详情或写接口返回 `403 web_mode_inactive` |
| 开启 Web 模式（`WebActive`） | 软件端请求打开 Web 后签发 30 秒单次票据并拉起浏览器兑换会话 Cookie。Web 获得完整读写权限，软件端锁定会话写操作（返回 `409 web_mode_active`），仅保留配置、只读会话列表（携带 `X-CST-Client: app` 的 `GET /api/sessions`）与状态同步 |
| 退出 Web 模式 | 仅在软件端确认退出 Web 时切回 `AppActive`，立即作废浏览器会话 Cookie 并主动断开所有 Web SSE 连接。已在后台执行或排队的任务继续完成 |
| 软件端断线与退出 | 常规启动等待首次软件端连接 15 秒，最后一条存活连接断开后进入 6 秒宽限期，重连则恢复且不改变当前 `ChannelMode`。宽限期届满或收到显式退出请求时，暂停收件箱、停止运行任务并在共享 5 秒预算内定稿遥测后退出 |
| 独立 Web 启动模式 | 通过 `--standalone-web` 启动时初始固定为 `WebActive`，关闭软件端连接超时，响应安全退出接口或进程终止信号退出 |

## 多会话池、单写权与收件箱

1. **跨目录发现与 `cwd` 继承**：会话列表扫描会话根目录及全部工作目录分类子目录。打开历史会话时保持原文件位置，沿用记录中的 `cwd` 作为文件读取与 `@` 补全的基准目录。新建会话使用启动工作目录。
2. **单写权互斥**：每场会话同一时刻仅由一个写入实例持有，冲突打开或写入返回 `409`。同一会话同时仅执行一轮模型生成。
3. **空闲内存上限与空会话保留**：会话池在内存中最多保留 10 个空闲会话。会话正在生成、压缩、排队投递、等待本地确认，或挂有活跃 SSE 订阅时，固定常驻内存。尚未产生对话消息的空会话独立保存标题、模型、思考强度与目录元数据，经历内存淘汰或服务重启后无损恢复。
4. **安全分支派生（`fork`）**：从指定会话条目派生新会话时保持源会话写锁与叶节点不变。目标为用户消息时取其父节点之前分支，目标为其他节点时包含该节点。截断点之前尚无对话消息时同步保留空会话元数据。
5. **持久化收件箱与强杀恢复**：客户端提交的消息与图片先持久化落盘再返回接收回执，支持立即投递、排队与插话。进程异常中断重启后不自动唤醒未完成队列，将中断前正在投递的条目标为待核对状态供用户处理。

## 共享配置与三端独立外观

| 配置内容 | 存储位置 | 共享与隔离规则 |
|---|---|---|
| 新会话默认模型、启用范围、默认思考强度 | `agent/home/settings.json` | 三端共用，修改后通过全局 SSE 实时广播 |
| 自定义服务、模型目录与认证凭据 | `models.json`、`models-store.json`、`auth.json` | 三端共用。单服务退出仅清除该服务凭据，不影响其他服务或正在进行的请求 |
| TUI 外观主题 | `agent/home/settings.json` | 内置 TUI 独占 |
| Web 外观主题与空模型范围标记 | `agent/home/web-settings.json` | Web 独占，默认浅色 `light` |
| 桌面端主题、默认视图、侧栏折叠与窗口位置尺寸 | `agent/home/desktop.json` | 软件端独占，按顶层对象局部合并并保留未知扩展字段 |
| 缺密钥首次自动提示 24 小时冷却记录 | `.state/ui-hints.json` | 三端共用，原子申领占用 |

发行默认模型固定为 `deepseek/deepseek-flash`。缺少有效凭据时保留指定模型身份并返回 `409 credentials_required`，禁止静默切换至其他服务。任何配置文件语法损坏时保留原文件不变，返回 `503 configuration_unavailable` 中文修复提示，不输出配置原文或密钥。

## 验收条件

- 同一工具包重复启动后台服务被命名管道锁拒绝。请求携带非本机 `Host` 或跨站 `Origin` 时返回 `403`，写请求缺少同源头时同样返回 `403`。
- `WebActive` 期间软件端 SSE 断线重连后仍保持 `WebActive`。退出 Web 模式后旧浏览器 Cookie 与在途写请求被确定性拦截。
- 空会话修改标题、模型与思考档位后经历内存淘汰或服务重启，再次打开时全部属性完整恢复。
- 客户端停止读取 SSE 导致单连接积压超过 `8 MiB` 时，服务端主动切断该慢连接并回收内存，不影响同会话其他订阅者。
