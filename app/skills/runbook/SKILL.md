# runbook

唯一的手动修复命令方案工具，只保存版本化方案（默认位于 `data/plans/`）与导出纯文本清单（`artifacts/<日期>/runbook/`），不执行命令，不改动系统。

## 允许用途与禁区

- **允许**：队员必须亲手执行的修复动作，如清理系统临时缓存、卸载软件、关闭自启项、重装或移除驱动、重置网络配置。
- **禁区**：诊断信息采集一律用诊断工具，不写入清单。不可逆或可能破坏系统可用性的操作（格式化、`diskpart clean`、改写引导、卸载系统关键驱动、批量删注册表项）禁止写入清单，仅在对话说明风险由队员自行判断。

## 执行流程与完成判据

1. **按风险档拆批**：同批、同风险档命令合并为一个方案；不同风险档分别创建并说明执行顺序。
2. **创建方案**：调 `runbook`（`action: "plan"`，可省略），传 `title`、`level` 与完整 `items`。默认保持 `exportTxt: false`，队员在桌面端或 Web 卡片核对后可直接一键导出该卡片版本并用记事本打开，不在正文重复粘贴整段命令。
3. **修订方案**：调 `runbook`（`action: "plan"`），必须传入 `title`、`level`、完整 `items`，并成对传入原 `runbookId` 与当前最新 `baseVersion`（禁传 `version`）。`sequence` 保持不变，`version` 递增 1。
4. **处理冲突与部分成功**：
   - 版本冲突时，用已知实际数据目录的绝对路径调用 `read` 读取 `<数据目录>/plans/<runbookId>/v<最新版本>.json` 核对后再修订；实际数据目录未知或文件不可读时请队员提供当前版本，不可猜测路径或版本号。
   - 同步导出（`exportTxt: true`）若方案保存成功但导出文件失败，错误会包含已保存的 `runbookId` 与 `version`；先保留该版本，解决文件问题后只调用 `action: "export"`，不重复创建新方案。
   - 已导出的 `.txt` 若被现场修改，工具拒绝覆盖；须修订出新版本再导出。
5. **按需导出**：仅在队员要求由助手导出时，在 `plan` 传 `exportTxt: true`，或调用 `runbook({ action: "export", runbookId, version })`。模型工具导出仅支持最新版本（同内容重复导出幂等复用）。
6. **完成判据**：核对返回的 `action`、`version` 与 `items` 条数；向队员说明所需权限、主要影响与执行顺序；未导出时明确提示可在卡片核对导出；已导出时原样转述 `file` 路径与文件名，并提醒纯文本不会自动执行、须逐条复制运行。若队员已执行旧版部分条目，明确列出改动与应跳过条目。

## 风险分档

| 档位 | `level` | 判据 | 示例 |
|---|---|---|---|
| 安全 | `safe` | 只删可再生的系统或应用临时缓存，不动机主个人数据，不改配置，无需管理员权限 | 清空 `%TEMP%` 临时文件、清理应用缓存、清理缩略图缓存 |
| 较安全 | `low` | 修改可回退的配置或用户可见状态，影响范围明确 | 卸载自装软件、关闭开机自启项、重置网络栈 |
| 需确认 | `confirm` | 涉及机主个人数据或系统关键行为，执行前须经机主知情同意 | 删除大文件或重复文件、清空回收站（先核对内容与备份）、禁用系统服务、删除还原点 |

清理 Windows 更新缓存等可能涉及管理员权限、服务启停或更新状态的操作，按实际权限与影响归入 `low` 或 `confirm`，不按“缓存”字面归入 `safe`。

## 命令与说明写法

1. **单行无控制字符**：每方案 `1–20` 条；每条命令去空白后 `1–2000` 字，禁止换行、Unicode 行分隔符及除 Tab 外的控制字符。
2. **同类合并**：同一目的、同一影响的动作合并成一条，不同目的分开写。
3. **无脚本与注释**：不写 `if`、变量赋值、函数定义，不写 `#` 或 `rem` 注释，说明放 `summary`。
4. **连接符与恢复**：`cmd` 用 `&&` 要求前步成功，`&` 无条件继续；PowerShell 的 `;` 不会因前步失败自动停止，有前后依赖时拆条由队员核查。使用机主电脑上的真实路径，路径含空格或特殊字符时加完整引号。临时停止服务或进程须安排恢复，单行无法保证失败后恢复时拆成清晰分步。
5. **`summary` 与环境字段**：`summary` 去空白后 `1–300` 字单行，动词开头，写清动作对象与实际后果。合格示例：`删除当前用户临时文件夹内容，释放 C 盘空间；使用中的文件会报错跳过，已删除临时文件不可恢复。` `shell` 仅填小写 `cmd` 或 `powershell`；`admin` 默认 `false`，需提权时显式设 `true` 并在 `summary` 写明「需要管理员权限」。

## 参数与返回契约

| 模式 | 参数硬约束 |
|---|---|
| `action: "plan"`（默认） | 必填 `title`（去空白后 1–48 字单行，文件名非法字符会被净化，以返回 `title` 与 `file` 为准）、`level`、`items[]`（`summary`、`command`、`shell`、`admin?`）；可选 `date`（`YYYY-MM-DD`，修订不可改）、`runbookId`（规范 UUID）与 `baseVersion`（小于 `9007199254740991` 的正整数，成对传入）、`exportTxt`（默认 `false`）；禁止传 `version` |
| `action: "export"` | 必填 `runbookId`（规范 UUID）与最新 `version`（`1–9007199254740991`）；省略编辑字段与 `exportTxt`（传编辑字段或 `exportTxt: true` 报错） |

返回结构为 `{ "runbook": { ... }, "elapsedMs": N }`：

- 公共字段：`runbookId`、`sequence`（当天整数序号 `1–999`，导出文件名按至少两位补零）、`version`、`day`、`createdAt`、`timeText`、`title`、`level`、`levelLabel`、`items`（条数）、`commands[]: { summary, command, shell, admin }`、`action`（`planned` / `exported`）、`notice`。
- 导出附加字段：`file`、`dir`、`name`、`bytes`、`encoding`（`utf-8-bom`）。导出路径固定为 `artifacts/<YYYY-MM-DD>/runbook/<序号:02>-<风险档>-<标题>-v<版本>.txt`（UTF-8 BOM + CRLF）。
- 前置 Schema 校验拦截发生在工具执行前，不附 `elapsedMs`；执行期校验、版本冲突、序号达 999 或目录锁占用返回 `isError: true`（`{"error", "elapsedMs"}`）。工具会等待写入锁，无独立 30 秒超时。
