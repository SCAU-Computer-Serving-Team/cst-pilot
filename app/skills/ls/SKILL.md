# ls

只读目录大小工具，按归属字节倒序展示目标目录的直接子项与占比。

## 场景选择

| 现象 | 调用 | 结束条件 |
|---|---|---|
| 已知目标目录，查看哪几个子项占空间 | 直接调用 `ls({ path })` | 列出前 N 项体积、扫描方式与是否完整 |
| 需要全盘跨深度大文件排行 | 改用 `disk({ scope: "usage", path })` | 按 `disk` 技能判读整树排行 |
| 需要看具体文本、截图或跨目录找文件 | 改用 `read` 或 `fffind` | 拿到目标文件内容或路径 |

## 参数

| 参数 | 约束与默认值 |
|---|---|
| `path` | 必填，目标目录路径；裸盘符 `C:` 按 `C:\` 解析，不可为符号链接或重解析点 |
| `top` | 可选，返回前 N 项，默认 `20`，上限 `50` |

## 返回字段与判读

| 字段 | 含义与判读 |
|---|---|
| `path` | 规范化目录路径 |
| `totalChildren` / `totalSize` | 可见直接子项总数与已统计大小合计；结果不完整时 `totalSize` 为下界 |
| `method` | 全部直接子目录命中同卷有效 120 秒快照且实际使用快照时返回 `native-index`；其余场景整次走并行遍历并返回 `walk`，不混用两套口径 |
| `entries[]` | 按已知归属字节降序排列：`name`、`type`（`dir` / `file` / `unknown`）、`bytes`、`size`、`pct`。文件通常使用实时枚举值，但返回 `bytes` 是归属大小：同目录重复硬链接可归属 0 字节，部分 `unknown` 项在索引分支可由快照补齐。不可打开或跳过项保留 `bytes: null` |
| `omitted` | 可见项超出 `top` 时出现，含 `count`、`unknownCount`、`size`、`note`。`unknownCount > 0` 时不可将省略项视为小文件 |
| `childrenTruncated` | 可选布尔值，直接子项枚举触及预算上限时为 `true` |
| `degraded` / `degradedFrom` | 整卷索引回退或任一子项不完整时为 `true`，回退原因见 `degradedFrom`。仅索引回退不表示遍历本身也不完整，须看 `pct` 与 `notice` |
| `notice` / `elapsedMs` | 不完整原因或敏感路径隐藏说明 / 顶层整数毫秒耗时 |

## 缓存、去重与超时规则

1. 管理员查询本地 NTFS 卷根且无缓存时尝试建立 120 秒卷缓存（索引阶段最多 180 秒），缓存按卷身份与有效期校验，切换查询路径不会刷新缓存。
2. 硬链接去重范围随引擎不同：`walk` 在本次查询范围内去重（直接文件与兄弟子目录共享去重表），`native-index` 采用整卷归属。禁止拿两次扫描结果直接做精确差分。
3. 跳过符号链接、目录联接与云占位目录。任一子项不完整或总量为 0 时全部 `pct` 置 `null`。工具包敏感路径名在明细中隐去，体积仍计入 `totalSize`。
4. 外层超时上限 215 秒；超时、目录不可读或扫描期间卷身份变化返回 `isError: true`（`{"error", "elapsedMs"}`）。结果不完整时明确标注下界，缩小目录层级逐级查看。
