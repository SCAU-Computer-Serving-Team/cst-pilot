# ls

只读目录占用工具，按体积倒序返回目标目录的直接子项与占比，不产生临时文件。

## 排查路径

1. 先用 `disk(usage)` 找出高占比大目录，再用 `ls` 逐层下钻定位具体子目录或大文件。
2. 需要查看具体文本日志或截图时转 `read`；需要跨多层找文件时转 `fffind`。
3. 每次返回后核对 `entries`、`omitted`、`degraded`、`notice` 与顶层 `elapsedMs`。结果不完整时明确标出下界口径，避免把未知项判为小文件。

## 参数

| 参数 | 约束与默认值 |
|---|---|
| `path` | 必填，目标目录路径；裸盘符 `C:` 按 `C:\` 解析，不可为符号链接或重解析点 |
| `top` | 可选，返回前 N 项，默认 `20`，上限 `50` |

## 返回字段与判读

| 字段 | 含义与判读规则 |
|---|---|
| `path` | 规范化后的目录路径 |
| `totalChildren` / `totalSize` | 可见直接子项总数与已统计体积合计；结果不完整时 `totalSize` 仅为下界 |
| `method` | `native-index`（全部直接子目录命中同卷 120 秒整卷索引缓存）或 `walk`（并行目录遍历） |
| `entries[]` | 按已知字节降序排列：`name`、`type`（`dir` / `file` / `unknown`）、`bytes`、`size`、`pct`。不可打开或跳过项 `bytes` 与 `size` 为 `null` |
| `omitted` | 可见项超出 `top` 时出现，含 `count`、`unknownCount`、`size`、`note`。`unknownCount > 0` 时不能将省略项视为小文件 |
| `childrenTruncated` | 可选布尔值，直接子项枚举触及预算上限时为 `true` |
| `degraded` / `degradedFrom` | 整卷索引失败回退或任一子项不完整时为 `true`；回退原因见 `degradedFrom` |
| `notice` / `elapsedMs` | 不完整或敏感路径隐藏说明 / 顶层整数毫秒耗时 |

## 缓存与边界规则

1. 管理员权限查询本地 NTFS 盘根且无缓存时自动建立 120 秒卷缓存，同卷子目录优先复用；换盘或路径变动立即失效。
2. 仅全部直接子目录均命中缓存时返回 `native-index`；任一子目录未命中则整次统一走 `walk`，不混用两套口径。
3. 直接文件始终保留实时字节数（含 0 字节）；本地 NTFS 跨直接文件与兄弟子目录执行确定性硬链接去重。
4. 跳过符号链接、目录联接与云占位目录。不可打开项保留 `type: "unknown"` 或 `bytes: null`，不标为 0 字节；任一子项不完整或总量为 0 时全部 `pct` 置 `null`。
5. 工具包敏感路径名在明细中隐去，其体积仍计入 `totalSize`。
6. 超时上限 215 秒；`elapsedMs` 偏高说明目录项极多或磁盘响应缓慢。整次失败返回 `isError: true`（如目录不可读或扫描期间卷身份变化），如实转达原因。
