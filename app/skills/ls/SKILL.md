# ls 工具说明

列出目录的直接子项（文件 + 子文件夹），按占用大小从大到小排序，每项带大小和占比。本工具以同名覆盖内置 `ls`。

## 参数

1. `path`（必填）：要浏览的目录路径
2. `top`（可选）：返回前 N 项，默认 20，上限 50

## 输出字段定义

1. `path`：实际浏览的路径，`totalChildren`：直接子项总数，`totalSize`：已统计子项的大小合计（不完整时为下界）
2. `entries`：按大小倒序的子项列表。`type` 为 `file` / `dir` / `unknown`，大小未知时 `size` 与 `bytes` 为 `null`，数据不完整或合计为 0 时 `pct` 为 `null`
3. `omitted`：未展示项的数量、已知大小合计与 `unknownCount`，不能把未知项视为小文件
4. `method`：`native-index` 表示命中进程内共享卷索引缓存，`walk` 表示使用原生并行目录遍历
5. `notice`：出现时表示部分子项大小未统计完整（预算、链接、云占位或无权限），所示大小为下界

## 大小引擎

1. **默认并行原生遍历**：每次调用在单一调用级预算（50 万条目、30 秒）内实时枚举目标目录直接子项，使用受控并发 Win32 `FileIdBothDirectoryInfo`（回退 `FindFirstFileExW`）一次并行统计全部直接子目录，并在本地 NTFS 上让直接文件与全部兄弟子目录共用同一张查询范围确定性硬链接去重表。目录根不可读时该项保持 `bytes: null`，不混淆为 `0` 字节。达到预算或访问限制后停止遍历，返回统计下界与 `notice`。
2. **实验 `$MFT` 共享缓存（默认关闭）**：仅在显式开启 `CST_ENABLE_MFT=1`（且未设 `CST_DISABLE_MFT=1`）时生效。命中同卷有效快照（120 秒有效，换盘即失效）且全部直接子目录均通过 `FileReference` 与 `PathPolicy::LIVE` 路径核验时，返回 `method: "native-index"`；任一子目录未命中则整次统一走 `walk`，不混用全卷与局部归属口径。

## 边界情况

1. 直接文件始终保留实时读到的真实字节（含 `0` 字节文件），不以旧缓存覆盖实时读到的 `0`
2. 跳过符号链接、junction 与带 `RECALL_ON_DATA_ACCESS` 的云占位目录，避免环路与云端回拉
3. 无法读取元数据的项保留 `type: unknown`、`bytes: null`，并标记结果不完整
4. UNC 网络路径不建立共享缓存，直接使用原生目录遍历
