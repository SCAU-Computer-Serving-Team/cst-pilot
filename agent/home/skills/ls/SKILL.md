# ls 工具说明

列出目录的直接子项（文件 + 子文件夹），按占用大小从大到小排序，每项带大小和占比。本工具以同名覆盖 pi 内置 ls。

## 参数

1. `path`（必填）：要浏览的目录路径
2. `top`（可选）：返回前 N 项，默认 20，上限 50

## 输出字段定义

1. `path`：实际浏览的路径；`totalChildren`：直接子项总数；`totalSize`：已统计子项的大小合计，不完整时为下界
2. `entries`：按大小倒序的子项列表。`type` 为 file / dir / unknown；`size` 与 `bytes` 在大小未知时为 null；数据不完整或合计为 0 时，`pct` 为 null
3. `omitted`：未展示项的数量、已知大小合计与 `unknownCount`，不能把未知项视为小文件
4. `method`：`wiztree-index` 表示命中共享缓存；`walk` 表示递归统计
5. `notice`：出现时表示部分子项大小未统计完整（熔断或无权限），所示大小为下界

## 大小引擎

1. 缓存路径：查询 `wz-index` 进程内共享缓存。缺少缓存时可能触发 WizTree 全盘扫描；后续仅复用已扫描路径，同卷文件变化不会实时刷新。`disk usage` 也会更新该缓存
2. 递归路径：共用 50 万条目、30 秒预算，目录与文件都计入；达到任一限制后停止遍历，返回统计下界与 `notice`

## 边界情况

1. `pagefile.sys` 等系统独占文件读取到大小 0 时，会尝试用大文件缓存补充。命中缓存不代表数据来自 NTFS MFT
2. 递归统计跳过符号链接 / junction，避免环路
3. stat 失败的项依次尝试异步补查、查询目录或大文件缓存；仍不可读则保留 `type: unknown`、`bytes: null`，并标记不完整
4. UNC 网络路径不建立共享缓存，使用递归统计
