# ls

列出目录的直接子项（文件与子目录），按占用大小倒序返回并附占比。本工具以同名覆盖内置 `ls`，全程只读。

## 参数

| 参数 | 约束与默认行为 |
|---|---|
| `path` | 必填，要浏览的目录路径 |
| `top` | 可选，返回前 N 项，默认 `20`，上限 `50` |

## 输出字段与判读

| 字段 | 含义与判读规则 |
|---|---|
| `path` | 规范化后的目录路径 |
| `totalChildren` / `totalSize` | 直接子项总数与已统计大小合计；结果不完整时为下界 |
| `method` | 固定为 `walk`（逐文件递归统计） |
| `entries[]` | 按大小倒序排列：`name`、`type`（`file` / `dir` / `unknown`）、`size`、`bytes`、`pct`。大小未知时 `size` 与 `bytes` 为 `null`；数据不完整或合计为 0 时 `pct` 为 `null` |
| `omitted` | 超出 `top` 截断时存在，含 `count`、`size`、`unknownCount`、`note`；不能将未知项当作小文件 |
| `notice` | 部分子项因熔断、链接或无权限未统计完整时出现，提示大小为下界 |

## 边界规则

1. 递归统计共用 50 万条目与 30 秒预算，目录与文件均计入；达到任一上限立即停止并标注下界。
2. 跳过符号链接与 junction，避免目录环路。
3. 元数据不可读的项保留 `type: unknown`、`bytes: null`，并触发全量 `pct: null`。
